# Cuan

Agentic project management for self-hosted teams: connect a repository, assign
work to an agent on your server, and review changes with verification evidence.

## Status

Pre-implementation planning. There is no installable application or published
installer yet. The repository is private during preparation for an OSS release;
the license and release gates are part of Sprint 1 planning.

## Sprint 1

The goal is to use Cuan to develop Cuan, from a task through agent execution,
verified changes, a GitHub PR, staging, and an update of the stable instance.

See [Sprint 1 scope, dependencies, and acceptance criteria](docs/sprints/S1.md).
The sprint is in **planning**, pending explicit Product Owner approval.
