Laporan Inspeksi Visual: Tombol Aksi Kontekstual & Eliminasi Redundansi (#23A0A7)

Evaluasi Peningkatan UX/UI Sesuai Definisi Selesai (DoD) Zero Cognitive Fatigue & Standar Things 3 / Bear Notes
Ringkasan Evaluasi Kualitas & Perbaikan Masalah Redundansi
  • Akar Masalah Teridentifikasi: Pada implementasi sebelumnya, kartu task di chat stream maupun board menampilkan tombol ganda (Detail dan Open task / View result) yang mengarah ke tujuan rute URL yang persis sama (detailUrl), membingungkan pengguna tanpa perbedaan fungsi nyata.
  • Pemisahan Peran Navigasi vs Aksi Langsung:
    • Tombol Sekunder (Kiri): Lihat Detail / Detail Diagnostik → untuk inspeksi mendalam (SlideDrawer / halaman detail, log eksekusi, diff code). Tombol ini kini hanya muncul saat task membutuhkan penanganan (Needs attention) atau saat review PR belum diterapkan.
    • Tombol Primer Kontekstual (Kanan): Sesuai status spesifik task:
      • Status Needs attention: Menampilkan tombol Retry (Coba lagi) dengan indikator loading spinner animasi RefreshCw dan teks Retrying... (Mencoba lagi...). Memicu re-run 1-klik tanpa memaksa pengguna membuka halaman task.
      • Status Running (Working/Queued): Menampilkan tombol Live Terminal tunggal.
      • Status Completed / Answered: Menampilkan tombol tunggal View result (atau Open task).
  • Penyederhanaan Tampilan (Single-CTA Clarity): Pada kondisi normal (task tidak gagal/tanpa PR tertunda), seluruh tombol ganda telah dieliminasi. Pengguna hanya melihat satu tombol aksi yang jelas dan tidak ambigu.
  • Umpan Balik Galat: Apabila re-run gagal, pesan galat kontekstual (retryError) langsung ditampilkan di bawah kartu dengan teks merah teredam yang informatif.
  • Aksesibilitas & Ergonomi Jempol: Seluruh target sentuh memenuhi standar WCAG 2.1 AA ≥ 44x44px (min-h-11 min-w-[44px]).
  • Verifikasi Otomatis: 410/410 test unit lulus 100% tanpa regresi.
