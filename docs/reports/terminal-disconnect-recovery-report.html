Laporan Inspeksi Visual: Penanganan Disconnect Terminal & Auto-Reconnect Mobile

Evaluasi Kualitas Desain, Zero Cognitive Fatigue, dan Standar Bear Notes & Things 3
Kriteria Penerimaan & Definition of Done (DoD) Quality Gate
  • Zero Cognitive Fatigue: Mengeliminasi pesan error merah statis "Could not connect to this terminal. The task was not restarted" yang memicu kepanikan pengguna saat layar ponsel terkunci atau tab diminimalkan.
  • Banner Informatif yang Bersahabat: Menginformasikan secara jelas dan menenangkan bahwa proses eksekusi task di server tetap berjalan aman di latar belakang.
  • Tombol Aksi Sambungkan Ulang: Tombol aksi "Sambungkan Ulang" (Reconnect) dengan kontras teredam (low visual noise) dan animasi spinner saat reconnecting.
  • Pemulihan Otomatis Saat Tab Aktif: Mekanisme auto-retry bertahap (exponential backoff) dan event listener pada visibilitychange, focus, dan online untuk langsung menyambung kembali seketika pengguna kembali ke layar.
  • Pengambilan State Terakhir & Snapshot Log: Mengambil snapshot buffer log terminal terbaru (tasksApi.logs) dan pembaruan status eksekusi tanpa me-refresh seluruh halaman (zero page-reload).
  • Verifikasi Kompilasi & Targeted Test: Build frontend (tsc && vite build) tuntas dengan 0 error, dan 52/52 targeted tests PASS 100%.
