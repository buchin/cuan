# Distance Converter

A fully offline distance converter that runs directly in your browser — no installation, internet connection, or server required.

## What it does

Enter a distance in **kilometres (km)** and the converter instantly shows the equivalent value in:

- **Miles**
- **Meters**

The output updates as you type, so there is no button to press.

## Conversion factors used

| From | To | Factor |
|------|----|--------|
| 1 km | miles  | × 0.621371 |
| 1 km | meters | × 1,000    |

## How to open it

1. Locate the file `distance-converter.html` on your computer.
2. Double-click it — your default browser will open it automatically.

   *Alternatively*, right-click the file and choose **Open with** → your preferred browser (Chrome, Firefox, Edge, Safari, etc.).

3. The converter loads immediately. No internet connection is needed.

## Requirements

Any modern desktop or mobile browser (Chrome 90+, Firefox 88+, Edge 90+, Safari 14+). No plugins or extensions are required.
