# Keyboard shortcuts

Press **?** outside a text field, or choose **Keyboard shortcuts** from the account
menu, to open the guide. Shortcuts are available across signed-in pages.

| Keys | Action |
| --- | --- |
| G, then H | Studio |
| G, then I | Inbox |
| G, then P | Projects |
| G, then C | Contacts |
| G, then N | Notifications |
| G, then S | Settings |
| C | Focus the visible message or Studio input |
| N | Use the current page's New action, when present |
| Ctrl/Cmd + K | Universal search |
| ? | Shortcut guide |

Press the second navigation key within one second. Single-key shortcuts pause
while typing, composing text, using a terminal, or interacting with a dialog.
Browser shortcuts retain their normal behavior. Escape closes the guide.
