1. SCOPE IMPLEMENTASI DISTILLER ENGINE & AGENT EXECUTION HOOK (S07.3)
================================================================================
A. Discussion-to-Task Distiller Engine Service (internal/studio/distiller.go):
   - Parser cerdas ekstraksi konteks diskusi room menjadi proposal task terstruktur:
     * Title: Ekstraksi padat dan jelas. Prioritas: explicit override -> regex header in-message (# Task: ..., Task: ..., Sprint ...: ...) -> room title ("Task: <Room.Title>") -> room topic -> generic fallback ("Distilled Task from Discussion").
     * Description berkonteks: Menyusun transkrip kronologis pesan berformat '[author_type - author_name]: content' disertai prefix Room Topic dan dukungan filtering MessageIDs spesifik.
     * DoD Checklist minimal 3 butir kriteria terverifikasi (Jaminan DoD >= 3):
       - Ekstraksi markdown checkboxes: '- [ ]', '- [x]', '- [X]', '* [ ]', '* [x]', '+ [ ]', '+ [x]' dengan penanda status completed yang tepat.
       - Ekstraksi inline criteria: 'DoD: ...', 'dod: ...', 'DOD: ...', 'Acceptance Criteria: ...', 'Kriteria Penerimaan: ...', 'AC: ...', serta numbered list di bawah blok kriteria.
       - Deduplikasi case-insensitive untuk mencegah duplikasi butir checklist.
   - Intelligent Inference Mechanism:
     * Jika jumlah butir DoD eksplisit < 3 butir, engine menganalisis topik room dan korpus pesan chat untuk menginferensikan kriteria teknis terverifikasi yang relevan:
       - Keyword backend/API/endpoint/handler -> "Implement backend endpoints and request handlers adhering to REST contract standards"
       - Keyword database/migration/schema/sql -> "Ensure database schema operations and queries maintain backward compatibility and data retention"
       - Keyword frontend/UI/component/react -> "Implement user interface components with clear navigation and intuitive error feedback"
       - Keyword SSE/stream/event/broker -> "Validate real-time event broadcasting and streaming lifecycle cleanup"
       - Keyword security/auth/validation -> "Enforce strict payload validation and authorization security gates"
       - Universal Baseline -> "Implement core functional requirements and business logic discussed in the room", "Verify behavior with targeted automated tests (100% PASS rate)", "Record audit trail evidence and verify zero regressions against existing modules"
     * Hasil: Selalu terjamin len(DoDChecklist) >= 3 butir kriteria terverifikasi.

B. Agent Execution Hook & Runner Queue Dispatching:
   - Interface AgentExecutionHook (internal/studio/distiller.go):
     * OnTaskStatusChanged(ctx context.Context, t *db.ProjectTask, oldStatus, newStatus string) (*ExecutionDispatchResult, error)
   - Implementasi DefaultAgentExecutionHook:
     * Mendeteksi transisi status task ke 'doing' (baik dari 'backlog' maupun siklus revisi dari 'review').
     * Mengabaikan transisi status yang tidak beralih ke 'doing' ('doing' -> 'doing', 'doing' -> 'review', dsb.).
     * Mendukung pendaftaran listener notification post-dispatch.
   - RunnerTaskBridgeDispatcher (Bridge ke Runner Daemon):
     * Menghubungkan db.ProjectTask ke antrean runner internal/task (task.Store & runner.RunnerService).
     * Memastikan entitas task pendukung ada di task.Store dan membuat TaskAttempt baru berstatus 'queued' dengan penomoran attempt inkremental.
     * Memungkinkan runner daemon latar belakang (RunnerService.Claim) secara otomatis mengklaim dan menjalankan attempt via adapter agen (e.g. 'agy').

C. Integrasi Endpoint REST & Real-Time Event Streaming:
   - Endpoint POST /api/projects/rooms/{id}/distill & POST /api/rooms/{id}/distill:
     * Memanggil s.distillerEngine.DistillWithResult(...) untuk menghasilkan proposal task dan metrics ekstraksi.
     * Menyimpan task ke database via projectStudioRepo.CreateTask.
     * Memancarkan event SSE 'task.distilled' ke seluruh client yang tersambung pada room.
     * Mengembalikan response 201 Created dengan DTO task, hitungan pesan, explicit_dod_count, dan inferred_dod_count.
   - Endpoint PATCH /api/tasks/{id}/status & PUT /api/tasks/{id}:
     * Terintegrasi dengan s.agentExecutionHook: saat status beralih ke 'doing', hook otomatis terpicu untuk men-dispatch attempt eksekusi agen.
     * Informasi dispatch disertakan pada event SSE 'task.status_changed' dan response payload HTTP.
   - Backward Compatibility:
     * Fungsi DistillTaskFromMessages dipertahankan sebagai wrapper ke studio.DefaultDistiller.Distill untuk menjamin kompatibilitas 100% terhadap pemanggil terdahulu.
