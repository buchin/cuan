   - Migrasi Down: migrations/000012_project_discussions_tasks.down.sql
   - Tabel Dibuat:
     * project_rooms:
       - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
       - project_id VARCHAR(64) NOT NULL REFERENCES projects(id) ON DELETE CASCADE
       - title VARCHAR(255) NOT NULL
       - topic TEXT NOT NULL DEFAULT ''
       - created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
       - updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
       - Indeks: idx_project_rooms_project_id, idx_project_rooms_created_at
     * project_messages:
       - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
       - room_id UUID NOT NULL REFERENCES project_rooms(id) ON DELETE CASCADE
       - author_type VARCHAR(50) NOT NULL DEFAULT 'user'
       - author_id VARCHAR(255) NOT NULL DEFAULT ''
       - author_name VARCHAR(255) NOT NULL DEFAULT ''
       - content TEXT NOT NULL
       - reply_to_id UUID REFERENCES project_messages(id) ON DELETE SET NULL
       - created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
       - updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
       - Indeks: idx_project_messages_room_id, idx_project_messages_reply_to_id, idx_project_messages_author_id, idx_project_messages_created_at
     * project_tasks:
       - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
       - project_id VARCHAR(64) NOT NULL REFERENCES projects(id) ON DELETE CASCADE
       - room_id UUID REFERENCES project_rooms(id) ON DELETE SET NULL
       - title VARCHAR(255) NOT NULL
       - description TEXT NOT NULL DEFAULT ''
       - status VARCHAR(50) NOT NULL DEFAULT 'backlog' (backlog, doing, review, done)
       - priority VARCHAR(50) NOT NULL DEFAULT 'normal' (low, normal, high, urgent)
       - dod_checklist JSONB NOT NULL DEFAULT '[]'::jsonb
       - assignee_id VARCHAR(255)
       - parent_task_id UUID REFERENCES project_tasks(id) ON DELETE SET NULL (Fan-Out Hierarchy)
       - batch_id VARCHAR(255) (Multi-Project Batch Grouping)
       - tags JSONB NOT NULL DEFAULT '[]'::jsonb (Tag Selector Array e.g. ["wordpress", "adsense"])
       - created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
       - updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
       - Indeks: idx_project_tasks_project_id, idx_project_tasks_room_id, idx_project_tasks_status, idx_project_tasks_priority, idx_project_tasks_parent_task_id, idx_project_tasks_batch_id, idx_project_tasks_tags (GIN index), idx_project_tasks_created_at
   - Jaminan 100% Data Retention: Migrasi murni aditif tabel baru tanpa modifikasi/alterasi kolom Sprint 1–6 (owners, projects, tasks, sponsors, deployments, servers, custom_domains, health_checks, server_metrics, alert_channels, alert_incidents).
