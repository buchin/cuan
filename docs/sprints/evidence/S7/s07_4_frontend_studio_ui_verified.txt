1. SCOPE IMPLEMENTASI FRONTEND STUDIO PROJECT HUB (S07.4)
================================================================================
A. Project Discussions View (web/src/components/studio/ProjectDiscussionsView.tsx):
   - Ruang obrolan interaktif real-time per project dengan selector room dan pembuatan room baru via modal.
   - Real-time Server-Sent Events (SSE) listener terhubung ke endpoint `/api/projects/rooms/{id}/events`:
     * Event handling otomatis: message.created (append/update), message.deleted (filter), task.created/task.distilled (notifikasi status).
     * Reconnection handler dan heartbeat listener berketahanan tinggi.
   - Multi-role bubble chat UI dengan badge identitas:
     * 'user': User avatar / operator human.
     * 'agent': Scrum Master / AI Worker robot avatar dengan styling badge khusus.
     * 'system': System alert notification card.
   - Rich message rendering:
     * Markdown parsing (code snippet pre/code blocks dengan tombol 'Copy code' sekali klik, bold, italic, inline code, blockquotes, checklist boxes).
     * Threaded replies UI: tombol 'Balas' untuk mengaitkan parent_id pada percakapan sub-thread.
   - Tombol 'Distill to Task':
     * Terintegrasi pada level room header ('Distil Diskusi ke Task').
     * Terintegrasi per baris chat bubble untuk mendistil pesan spesifik beserta konteksnya.

B. Distill Task Modal (web/src/components/studio/DistillTaskModal.tsx):
   - Modal ekstraksi chat percakapan ke draf task ber-Definition of Done (DoD).
   - Integrasi 1-klik 'Auto-Distill with AI':
     * Memanggil POST /api/projects/rooms/{id}/distill untuk ekstraksi title, konteks transkrip, dan inference DoD otomatis.
   - Form editor draf task komprehensif:
     * Title (required)
     * Description (markdown preview/editor)
     * Priority selector: low, medium, high, urgent
     * Tags input (interaktif chips builder)
     * Batch ID (opsional untuk orkestrasi batch)
     * Parent Task UUID (opsional untuk struktur hierarkis subtask)
   - Interactive DoD Criteria Checklist Builder:
     * Garansi minimal >= 3 butir kriteria terverifikasi sebelum draf dapat disimpan.
     * Indikator validasi visual: counter jumlah kriteria dengan badge hijau jika >= 3 atau peringatan merah jika < 3.
     * Penambahan, pengeditan teks, dan penghapusan butir kriteria dinamis.
   - Task Persistence:
     * Mengirim POST /api/projects/{id}/tasks dan mengembalikan task terbuat ke parent view.

C. Project Tasks Board (web/src/components/studio/ProjectTasksBoard.tsx):
   - Kanban Board 4 Kolom Status Utama:
     * Backlog (slate/gray badge)
     * Doing (amber/yellow badge dengan indikator aktivitas agen)
     * Review (blue/sky badge dengan tombol transisi ke Done atau Re-doing)
     * Done (emerald/green badge dengan checklist komplit)
   - Filter & Pencarian Multi-Dimensi:
     * Text search (title, description, tags)
     * Filter Tag (chips selector)
     * Filter Batch ID
     * Filter Subtask Parent UUID
     * Filter Priority
   - Visualisasi DoD Checklist & Progress:
     * Progress bar persentase penyelesaian kriteria per card (e.g. 3/3 - 100%).
     * Interactive checklist item toggle langsung dari card tanpa membuka modal:
       - Memperbarui status checklist dan mengirim PUT /api/tasks/{id}.
   - Mutasi Status Kanban:
     * Tombol aksi cepat: 'Mulai Kerja' (ke doing), 'Kirim Review' (ke review), 'Approve & Selesai' (ke done), 'Revisi' (review ke doing).
     * Pemanggilan PATCH /api/tasks/{id}/status yang otomatis memicu backend Agent Execution Hook saat berpindah ke 'doing'.

D. Integrasi Navigasi & Drawer Studio (web/src/components/studio/):
   - types.ts:
     * Definisi antarmuka TypeScript: ProjectRoomDTO, ProjectMessageDTO, DoDItem, ProjectTaskDTO, DistillTaskPayload, DistillResult, CreateProjectTaskPayload, UpdateProjectTaskPayload.
   - StudioDashboard.tsx:
     * Penambahan tab 'Discussions' dan 'Tasks' pada navigation header desktop dan mobile drawer.
     * Routing URL hash/activeTab: `/studio/discussions` dan `/studio/tasks`.
     * Dropdown selector active project pada header tab diskusi & task untuk berpindah antar project secara instan.
   - ProjectDrawer.tsx:
     * Tab switcher internal: 'Overview & Logs', 'Discussions', 'Tasks'.
