1. SCOPE IMPLEMENTASI BACKEND REST & SSE ENGINE (S07.2)
================================================================================
A. Project Rooms HTTP Handlers (internal/server/project_discussions_handlers.go):
   - POST /api/projects/{id}/rooms: Pembuatan room diskusi baru terikat pada project_id.
   - GET /api/projects/{id}/rooms: Listing seluruh room diskusi milik suatu project.
   - GET /api/rooms/{id} & /api/projects/rooms/{id}: Pengambilan detail data room spesifik.
   - PUT /api/rooms/{id} & /api/projects/rooms/{id}: Pembaruan judul (title) dan topik (topic) room.
   - DELETE /api/rooms/{id} & /api/projects/rooms/{id}: Penghapusan room (cascading ke messages & set null tasks).

B. Project Messages HTTP Handlers (internal/server/project_discussions_handlers.go):
   - POST /api/rooms/{id}/messages & /api/projects/rooms/{id}/messages: Pengiriman pesan chat dalam room.
     * Mendukung multi-aktor (author_type: 'user', 'agent', 'system').
     * Mendukung threaded replies via reply_to_id (self-referencing UUID).
   - GET /api/rooms/{id}/messages & /api/projects/rooms/{id}/messages: Pengambilan riwayat percakapan kronologis.
   - DELETE /api/messages/{id}: Penghapusan pesan secara spesifik.

C. Real-Time Event Streaming Engine via SSE (Server-Sent Events):
   - GET /api/rooms/{id}/events & /api/projects/rooms/{id}/events:
     * Header standar HTTP SSE: Content-Type: text/event-stream, Cache-Control: no-cache, Connection: keep-alive, X-Accel-Buffering: no.
     * Handshake awal: event 'connected' dengan JSON payload status dan room_id.
     * Heartbeat ticker berkala (15 detik default, konfigurabel untuk testing cepat): mengirim ': heartbeat\n\nevent: ping\ndata: {"timestamp":"..."}\n\n'.
     * Real-time event broadcasting ke seluruh subscriber aktif room:
       - 'room.created', 'room.updated', 'room.deleted'
       - 'message.created', 'message.deleted'
       - 'task.created', 'task.updated', 'task.status_changed', 'task.deleted', 'task.distilled'
     * Graceful connection cleanup: saat klien memutus koneksi (context canceled / tab browser ditutup), deferred channel unregistration otomatis membersihkan channel subscriber dan mencegah memory leak.

D. Discussion-to-Task Distiller Engine Helper:
   - POST /api/rooms/{id}/distill & /api/projects/rooms/{id}/distill:
     * Menganalisis obrolan room dan menyulingnya menjadi draft ProjectTask terstruktur.
     * Otomatis mengekstrak markdown checklist ('- [ ]', '- [x]', 'DoD: ...') menjadi item DoDChecklist.
     * Menghasilkan task berstatus 'backlog' dan memicu broadcast SSE 'task.distilled'.

E. Project Tasks HTTP Handlers (internal/server/project_tasks_handlers.go):
   - POST /api/projects/{id}/tasks: Pembuatan task baru dengan dukungan DoD checklist, tags, batch_id, dan parent_task_id.
   - GET /api/projects/{id}/tasks: Listing task dengan kapabilitas query filtering canggih:
     * ?parent_task_id= (Fan-Out hierarchy subtasks)
     * ?batch_id= (Multi-project batch grouping)
     * ?tag= / ?tags= (Tag selector array e.g. ["wordpress", "adsense"])
     * ?status= (backlog, doing, review, done)
     * ?priority= (low, normal, high, urgent)
     * ?room_id= & ?assignee_id=
   - GET /api/tasks/{id} & /api/projects/tasks/{id}: Pengambilan detail task spesifik.
   - PUT /api/tasks/{id} & /api/projects/tasks/{id}: Pembaruan detail atribut task.
   - PATCH /api/tasks/{id}/status & /api/projects/tasks/{id}/status: Transisi status kanban (backlog -> doing -> review -> done).
   - DELETE /api/tasks/{id} & /api/projects/tasks/{id}: Penghapusan task.

F. Pendaftaran Rute & Integrasi Server (internal/server/server.go):
   - Seluruh rute didaftarkan di root router (/api/...) dan alias group (/api/v1/...).
   - Server struct diperkaya field roomEventBroker (*RoomEventBroker) beserta getter/setter.
   - Kompatibilitas mundur (backward-compatibility) 100% terjaga dengan rute Sprint 1–6 (termasuk fallback lookup di handleGetTask).
