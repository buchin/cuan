5. CLI HEALTHCHECK FLAG (--healthcheck)
--------------------------------------------------------------------------------
Purpose: Embedded healthcheck for minimal Docker Alpine containers without requiring curl/wget.
Command:
  $ /app/cuan-server --healthcheck
  $ echo $?
  0

When server is running: Exit Code 0 (Success)
When server is stopped or unhealthy: Exit Code 1 (Failure)
