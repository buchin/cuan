1. DNS Verification Engine (internal/domain/resolver.go):
   - DNSResolver Interface:
     * Full mockable interface for hermetic testing: LookupCNAME(ctx, host), LookupTXT(ctx, name), LookupIP(ctx, network, host).
     * NetDNSResolver: Production implementation wrapping Go net.DefaultResolver with configurable lookup timeouts and context cancellation.
     * MockDNSResolver: Thread-safe in-memory test implementation for simulating CNAME, TXT, IP lookups, NXDOMAIN, and network timeouts.
   - DNSVerifier Multi-Tier Verification Strategy:
     * Tier 1 (CNAME): Resolves incoming domain CNAME and matches against canonical Cuan hosts (e.g. cuan.app, cuan.dojo.cc, or baseDomain).
     * Tier 2 (TXT Challenge): Queries `_cuan-challenge.<domain>` and root `<domain>` for verification token match.
     * Tier 3 (A-Record Fallback): Fallback check for root / apex domains where DNS providers (e.g. Cloudflare, Route53) enforce CNAME flattening; verifies if resolved IP matches platform server IPs.
     * Generates structured VerificationResult containing verification boolean, method ("cname" | "txt" | "a_record"), matched targets, diagnostic messages, and error context.

2. Background DNS Health Poller (internal/domain/poller.go):
   - DNSHealthPoller:
     * Periodically inspects registered custom domains in the background.
     * Automatically verifies DNS status and updates domain state in DomainRepository (e.g. pending -> verified / failed).
     * Dynamic Caddy Route Sync: When a custom domain transitions to 'verified', automatically configures dynamic reverse proxy route in CaddyRouter (mapping host/SNI to local port or remote BYOS runner).
     * Lifecycle management: Safe Start(ctx) and Stop() with graceful cancellation, configurable polling interval, and optional state change callbacks.

3. Custom Domain REST API Handlers (internal/server/domain_handlers.go):
   - POST /api/deployments/{id}/domains (and /api/v1/deployments/{id}/domains):
     * Validates deployment existence (404 if missing).
     * Validates RFC 1123 domain syntax (400 if invalid).
     * Prevents duplicate registrations (409 Conflict).
     * Generates secure 32-character hex verification token and records custom_domain in DomainRepository.
     * Returns 201 Created with domain DTO and interactive DNS setup instructions (CNAME, TXT challenge, A-record fallback).
   - GET /api/deployments/{id}/domains (and /api/v1/deployments/{id}/domains):
     * Retrieves all custom domains linked to a specific deployment.
   - GET /api/domains (and /api/v1/domains):
     * Lists platform custom domains, supporting optional ?deployment_id={id} query filter.
   - GET /api/domains/{id} (and /api/v1/domains/{id}):
     * Retrieves domain metadata, current status, and copyable DNS setup instructions.
   - POST /api/domains/{id}/verify (and /api/v1/domains/{id}/verify):
     * Triggers instant on-demand DNS verification probe.
     * Updates domain status to 'verified' or 'failed'.
     * If verified, registers dynamic route to CaddyRouter (zero downtime, no server reload).
     * Returns 200 OK with detailed verification diagnostics and route registration status.
   - DELETE /api/domains/{id} (and /api/v1/domains/{id}):
     * Removes custom domain from repository.
     * Dynamically removes route from CaddyRouter with zero downtime.
