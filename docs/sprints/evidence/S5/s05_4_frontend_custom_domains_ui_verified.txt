      - Form input for registering new custom domain (POST /api/deployments/{id}/domains).
      - Target deployment selector when opened globally from DomainsView, or pre-locked when opened from a specific deployment.
      - Strict client-side RFC 1123 domain validation:
        * Auto-normalizes whitespace and lowercase.
        * Strips accidental http://, https://, trailing paths, and port numbers.
        * Rejects spaces, @ characters, single-label domains, and labels exceeding 63 characters.
        * Rejects hyphens at the start or end of domain labels.
        * Rejects purely numeric TLDs (e.g. IP addresses).
        * Real-time visual feedback with green check / red error indicator.
      - Interactive Zero-Friction DNS Setup Guide (Step 2 upon registration):
        * Option 1 (Recommended Subdomains): CNAME Record (Host name & Target canonical host with 1-click Copy).
        * Option 2 (Ownership Verification): TXT Record (Host `_cuan-challenge.<domain>` & Token with 1-click Copy).
        * Option 3 (Apex / Root Domains): A Record Fallback (Host `@` & Target Server IP with 1-click Copy).
        * Immediate "Verify DNS Now" button directly inside modal for zero-friction verification probe.
