3. LOGIN GATE SCREEN & SESSION CONTEXT
--------------------------------------------------------------------------------
1. `web/src/components/auth/LoginScreen.tsx`:
   - Tokyo Night dark/light card design with centered brand iconography.
   - Username / Email field and Password field with reveal toggle.
   - Error banner with informative messages when credentials fail.
   - Quick default credentials helper button:
     - Auto-fills default admin (`admin` / `whosyourdaddy`) seeded by migration 000019.
   - Back button to public Landing Page.

2. `web/src/context/AuthContext.tsx`:
   - Centralized authentication state management:
     - `user`: OwnerInfo | null
     - `token`: string
     - `isAuthenticated`: boolean
     - `isLoading`: boolean
     - `setupRequired`: boolean | null
     - `login(identifier, password)`: POST /api/v1/auth/login
     - `logout()`: POST /api/v1/auth/logout
     - `changePassword(current, new)`: POST /api/v1/auth/password
     - `refreshUser()`: GET /api/v1/auth/me
     - `getAuthHeaders()`: Authorization Bearer header generator
   - Dual session handling: HttpOnly cookie + Bearer token in localStorage.

3. `web/src/components/auth/AuthGate.tsx`:
   - Route guard protecting private dashboard and studio views.
   - Shows elegant loading spinner when session is verifying.
   - Automatically renders LoginScreen when unauthenticated.
   - Renders AppShell / Sidebar07Layout when authenticated.

4. `web/src/App.tsx` Integration:
   - Root application wrapped with `ThemeProvider` and `AuthProvider`.
   - Public routes bypass authentication: `/terms`, `/privacy`, `/marketing`, `/landing`, `/sponsor`, `/sponsors`, `/sponsor/pending`, and root `/` in marketing mode.
   - Private routes (`/studio`, `/tasks`, `/deployer`, `/wordpress`, `/servers`, `/domains`, `/observability`, `/admin/sponsors`) are protected by AuthGate.
   - When authenticated, renders `Sidebar07Layout` housing `StudioDashboard` (with `hideHeader={true}`) or `AdminSponsorPanel`.
