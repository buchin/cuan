2. DATABASE MIGRATION 000019 (000019_auth_and_multiproject)
--------------------------------------------------------------------------------
Up Migration: migrations/000019_auth_and_multiproject.up.sql
Down Migration: migrations/000019_auth_and_multiproject.down.sql

Verified Schema Changes:
- projects table:
  - Added column: is_archived BOOLEAN NOT NULL DEFAULT FALSE
  - Performance index: idx_projects_is_archived ON projects(is_archived)
- task_projects table (Many-to-Many Task-Project Association):
  - task_id TEXT NOT NULL REFERENCES tasks(id) ON DELETE CASCADE
  - project_id TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE
  - PRIMARY KEY (task_id, project_id)
  - Performance indexes:
    - idx_task_projects_task_id ON task_projects(task_id)
    - idx_task_projects_project_id ON task_projects(project_id)
- owners table & Default Admin Seeding:
  - Added column: username VARCHAR(100) (with unique index idx_owners_username)
  - Auto-seeded default admin credentials when table is empty:
    - username: 'admin'
    - email: 'admin@cuan.local'
    - password: 'whosyourdaddy'
    - bcrypt hash: '$2a$10$sGcQkuIKOs1j7.lrnh.HzO.5/nm.8sPY2gHjofWzd.vxdyTw3F6/u'
- Fully Reversible Down Migration:
  - Removes default admin record seeded by migration 000019
  - Drops table task_projects CASCADE and associated indexes
  - Drops index idx_projects_is_archived and column is_archived from projects
  - Drops index idx_owners_username and column username from owners

Dry-run & Embedded Migration Verification:
