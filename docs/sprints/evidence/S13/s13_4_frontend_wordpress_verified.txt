1. SCOPE & IMPLEMENTATION DETAILS

Component Architecture & Implementation Files:

1. web/src/components/studio/wordpress/WordPressDeployerModal.tsx (and alias WordPressLaunchpadModal):
   - Multi-step interactive deployment wizard for Turnkey WordPress Cloud:
     * Step 1: Site Profile & Admin Credentials (site_title, admin_email, admin_username, admin_password).
       - Cryptographically strong 24-character password auto-generator.
       - Password reveal/masking toggle with copy-to-clipboard functionality.
       - Form validation with informative error alerts.
     * Step 2: Domain & Database Configuration (domain, db_name, db_user, db_password, table_prefix, wp_version, permalink_structure, server_id).
       - AES-256-GCM vault security protection disclaimer.
       - Pre-flight slug derivation and SEO permalink presets (/%postname%/).
     * Step 3: Staged Theme & Plugin ZIP Upload (Pre-launch Assets).
       - Drag & Drop zone supporting .zip files (max 50 MB).
       - Kind selector ('theme' vs 'plugin'), custom slug input, and auto-activate toggle.
       - Staged assets queue with remove/clear controls.
     * Step 4: Live Launch & Bootstrapping Console.
       - 4-phase step tracker (Database Provisioning -> WP-CLI Core Install -> Caddy SSL -> Live Health Probe).
       - Real-time terminal streaming execution logs.
       - Post-launch credentials disclosure card with password unmask toggle and copy buttons for username, password, site URL, and wp-admin URL.

2. web/src/components/studio/wordpress/WordPressDashboardView.tsx:
   - Full-featured Turnkey WordPress management view:
     * Workspace project switcher and active status hero bar (Running/Healthy, Degraded, Stopped).
     * Quick actions: "Visit Site" (external link), "Open WP-Admin" (wp-login.php), "Restart Container", "Stop Container", and "Delete Deployment".
     * Admin & Database Credentials Vault card with AES-256-GCM password masking toggle (•••••••• vs plaintext), eye toggle, 1-click copy buttons, and "Copy All Credentials" shortcut.
     * Health check probe status (HTTP 200 OK, latency < 50ms, alive status).
     * Sub-tab switcher seamlessly toggling between "Overview & Credentials Vault" and "AI Webmaster Studio".
     * Empty state for projects without WordPress, explaining key benefits with a direct 1-click deploy CTA.

3. web/src/components/studio/wordpress/WordPressWebmasterPanel.tsx (and alias WordPressWebmasterConsole):
   - Central AI Webmaster Studio panel with 4 specialized management tabs:
     * Tab 1: Themes & Plugins Manager:
       - ZIP dropzone supporting drag-and-drop file upload (multipart/form-data).
       - Kind selector, custom slug derivation, and auto-activation toggle.
       - Table of installed assets with live status toggling (Active/Inactive) and deletion controls.
     * Tab 2: Safe Script Injector (mu-plugins):
       - Zero-risk script injection into wp_head or wp_footer via cuan-webmaster.php.
       - Presets for Google Tag Manager (GTM), Google Analytics 4 (GA4), Meta Pixel, and Custom Code.
       - Code editor textarea with monospace formatting.
       - Table of active scripts with toggle on/off, code viewer drawer, and delete controls.
     * Tab 3: Configuration Tweaker (wp-config.php):
       - Interactive constant switches: WP_DEBUG, WP_DEBUG_LOG, WP_DEBUG_DISPLAY, SCRIPT_DEBUG.
       - Memory limit dropdowns: WP_MEMORY_LIMIT (128M - 1024M) and WP_MAX_MEMORY_LIMIT (256M - 1024M).
       - Pre-save PHP syntax verification preventing White Screen of Death (WSOD).
     * Tab 4: Webmaster Audit Action History:
       - Chronological timeline of all executed webmaster actions.
       - Filter by action type (All, inject_script, install_asset, config_tweak, toggle_script).
       - Expandable JSON payload viewer with syntax formatting.

4. web/src/components/studio/wordpress/WordPressControls.tsx:
   - Kanban board quick controls bar:
     * WordPress status badge (Healthy / Degraded / Stopped / Deploying).
     * Quick links to live site and wp-admin.
