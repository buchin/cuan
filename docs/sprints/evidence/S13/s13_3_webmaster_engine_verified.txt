1. SCOPE & IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------
Component Architecture & Implementation Files:

1. internal/wordpress/asset_manager.go:
   - WordPress ZIP Asset Manager with automated theme and plugin inspection.
   - Header Parsers:
     * ParseThemeHeader: Scans style.css for Theme Name, Theme URI, Author, Author URI, Description, Version.
     * ParsePluginHeader: Scans PHP files for Plugin Name, Plugin URI, Author, Author URI, Description, Version.
     * Auto-detects kind ("theme" or "plugin") and derives slug safely.
   - Canonical ZipSlip Attack Mitigation:
     * CheckZipSlipEntry: Rejects path traversal sequences (..), absolute paths, null bytes, and root escapes.
     * ExtractAssetZip: Resolves destination path canonically against destBaseDir and verifies clean path prefix.
     * Protects wp-content/themes/{slug} and wp-content/plugins/{slug}.
     * Decompression limits (100MB per file, 500MB total) to guard against zip-bombs.
   - Asset Activation:
     * Registers theme/plugin record in wordpress_plugins_themes table.
     * Supports automatic activation flag (is_active) and theme mutual exclusivity deactivation.

2. internal/wordpress/script_injector.go:
   - Safe Tracking & Analytics Script Injector via isolated WordPress mu-plugins.
   - Eliminates WSOD (White Screen of Death) risk by keeping WordPress core PHP untouched.
   - Writes isolated loader: wp-content/mu-plugins/cuan-webmaster.php.
     * Hooks into wp_head (priority 1) for head scripts (GA4, GTM, Meta Pixel, Schema).
     * Hooks into wp_footer (priority 99) for footer/body scripts (chat widgets, noscript tags).
     * Reads scripts dynamically from cuan-webmaster-scripts.json.
     * Safe HTML comment tagging: <!-- [cuan-webmaster: {name}] -->.
   - Script management: Add, Update, List, Toggle (enable/disable), and Delete scripts without theme updates overwriting them.
   - Built-in generators: BuildGA4Snippet, BuildGTMSnippets, BuildMetaPixelSnippet.

3. internal/wordpress/config_tweaker.go:
   - Safe WordPress Configuration Tweaker modifying wp-config.php constant directives.
   - Supported constants: WP_DEBUG, WP_DEBUG_LOG, WP_DEBUG_DISPLAY, WP_MEMORY_LIMIT, WP_MAX_MEMORY_LIMIT,
     WP_POST_REVISIONS, DISABLE_WP_CRON, EMPTY_TRASH_DAYS, FS_METHOD, and custom defines.
   - Pre-Save PHP Syntax Integrity Check:
     * Integrates with php -l CLI linter.
     * Built-in pure-Go syntax validator (verifyBalancedTokens) checking <?php header, balanced quotes,
       parentheses, brackets, and braces outside comments.
     * ZERO WSOD RISK: If syntax validation fails, the file is NEVER written to disk, preserving 100% config integrity.
   - Atomic disk write with automatic backup creation (wp-config.php.bak).
   - ParseCurrentConfigTweaks to inspect active constant values.

4. internal/wordpress/webmaster.go:
   - Central WebmasterEngine orchestrating asset management, script injection, and config tweaking.
   - Comprehensive audit logging recording every webmaster action in wordpress_webmaster_actions table
     (action_type: install_asset, inject_script, config_tweak with structured JSONB payloads).

5. internal/server/wordpress_handlers.go & internal/server/server.go:
   - REST API Endpoints wired into Cuan Server and /api/v1 router:
     * POST   /api/v1/projects/{id}/wordpress/assets/upload   (multipart ZIP upload & JSON)
     * GET    /api/v1/projects/{id}/wordpress/assets          (list installed themes/plugins)
     * POST   /api/v1/projects/{id}/wordpress/assets/{asset_id}/status (toggle status)
     * DELETE /api/v1/projects/{id}/wordpress/assets/{asset_id}        (delete asset)
     * POST   /api/v1/projects/{id}/wordpress/scripts         (inject tracking script)
     * GET    /api/v1/projects/{id}/wordpress/scripts         (list active scripts)
     * POST   /api/v1/projects/{id}/wordpress/scripts/{script_id}/toggle (toggle script)
     * DELETE /api/v1/projects/{id}/wordpress/scripts/{script_id}        (delete script)
     * POST   /api/v1/projects/{id}/wordpress/config          (tweak wp-config.php)
     * GET    /api/v1/projects/{id}/wordpress/config          (get active config tweaks)
     * GET    /api/v1/projects/{id}/wordpress/actions         (get webmaster audit trail)
