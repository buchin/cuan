2. ARSITEKTUR & KOMPONEN TEKNIS:
   a. PTY Process & Shell Spawning Engine (internal/terminal/pty.go):
      - Berbasis library standar github.com/creack/pty (v1.1.24).
      - Deteksi shell host otomatis (/bin/bash, /usr/bin/bash, fallback ke /bin/sh).
      - PTYProcess membungkus slave TTY dan master PTY descriptor dengan manipulasi ukuran window dinamis (pty.Setsize & SIGWINCH).
      - Graceful termination: pengiriman sinyal SIGHUP ke process group, penutupan master descriptor, dan eskalasi SIGKILL jika proses tidak keluar dalam timeout, diikuti wait async pencegah zombie process (<defunct>).
      - Sanitasi Environment Variables (SanitizeEnvironment):
        * Whitelist variabel lingkungan aman: TERM (xterm-256color), LANG/LC_ALL (en_US.UTF-8), COLORTERM, TASK_ID, PWD, WORKSPACE_DIR, PATH, HOME, USER, SHELL.
        * Redaksi dan blokir otomatis seluruh variabel bernilai rahasia: SECRET, PASSWORD, TOKEN, KEY, CREDENTIAL, AUTH, PRIVATE, AWS_, DOJO_, DATABASE_URL, RESEND, TINYFISH, NERD_, S3_.

   b. Multi-Client Session & Operational Modes (internal/terminal/session.go):
      - Mode Operasional:
        * Watch Mode (ModeWatch): Read-only output streaming untuk observasi langsung pengerjaan kode oleh agent. Input stdin dari client diblokir dengan ErrReadOnlySession.
        * Interactive Take-Over Mode (ModeInteractive): Bidirectional streaming di mana input keyboard pengguna langsung dipompa ke stdin PTY dan output di-broadcast secara real-time.
        * Dynamic Mode Switching / Take-Over: Client dapat berpindah dari mode watch ke interactive take-over secara langsung melalui pesan WebSocket {"type": "takeover"} atau {"type": "mode", "mode": "interactive"}.
      - Circular Scrollback Ring Buffer (128 KB):
        * Setiap client baru yang tersambung langsung menerima snapshot buffer riwayat terminal sebelumnya sehingga tampilan tidak kosong saat reload/sambung ulang.
      - Broadcast Fan-Out:
        * Satu sesi task mendukung banyak subscriber bersamaan (misal operator lain yang sedang mengamati).

   c. Workspace Isolation & Session Lifecycle Manager (internal/terminal/manager.go):
      - Isolasi Direktori Kerja Task:
        * ResolveTaskWorkspace memvalidasi task ID dengan strict alphanumeric regex.
        * Memblokir seluruh upaya path traversal (../, ..\\, etc.) dan mengunci workspace di dalam base workspaces directory.
      - Thread-Safe Registry & Lifecycle:
        * Pembuatan dan pemakaian ulang sesi aktif berdasarkan task ID.
        * Auto-cleanup hook: jika seluruh client disconnect, grace period timer (30s) akan membersihkan sesi.
        * Background Sweeper (idleSweeper): membersihkan sesi idle/terbengkalai secara periodik (15 menit).

   d. WebSocket Gateway & Server Integration (internal/terminal/handler.go & internal/server/terminal_handlers.go):
      - Routing:
        * GET    /api/tasks/{id}/terminal
        * DELETE /api/tasks/{id}/terminal
        * GET    /api/v1/tasks/{id}/terminal
        * DELETE /api/v1/tasks/{id}/terminal
        * GET    /api/projects/tasks/{id}/terminal
        * GET    /api/terminal/sessions
      - Autentikasi Fleksibel:
        * Header: Authorization: Bearer <token>
        * Query Param: ?token=<token> (ramah WebSocket browser native)
        * Subprotokol WebSocket: Sec-WebSocket-Protocol: token.<token> atau cuan-terminal
      - Protokol Pesan:
        * Control JSON: {"type": "resize", "cols": 120, "rows": 40}, {"type": "mode", "mode": "watch"}, {"type": "takeover"}, {"type": "ping"} / {"type": "pong"}, {"type": "connected"}, {"type": "error"}.
        * Raw I/O: Mendukung frame binary dan raw text string stdin langsung dari @xterm/xterm tanpa overhead serialization berlebih.
        * Heartbeat: Ping/pong periodik 15 detik untuk menjaga koneksi tetap hidup melalui Caddy / Nginx reverse proxy.
