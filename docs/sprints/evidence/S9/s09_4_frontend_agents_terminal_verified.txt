2. ARSITEKTUR & KOMPONEN TEKNIS FRONTEND:
   a. In-Browser Interactive Terminal Engine (TaskTerminal.tsx):
      - Library: @xterm/xterm (v6.0.0), @xterm/addon-fit, @xterm/addon-web-links.
      - WebSocket Transport:
        * URL: ws[s]://<host>/api/tasks/<taskId>/terminal?mode=<mode>&cols=<cols>&rows=<rows>&token=<token>
        * Protocols: ['cuan-terminal'] dan token subprotocol negotiation.
        * Frame Decoding: BinaryMessage untuk raw byte chunks output dari PTY stdout/stderr (zero overhead).
        * TextMessage: JSON control messages (connected, mode, status, resize, ping/pong, error).
      - Dual Operational Modes:
        * Watch Mode: Observasi output agent; ketikan keyboard pengguna dicegah dengan notifikasi ramah agar tidak mengganggu alur eksekusi agent yang sedang berjalan.
        * Interactive Take-Over Mode: Ketikan keyboard pengguna dipompa langsung ke stdin master PTY pada direktori kerja Git task.
      - Dynamic Window Resizing:
        * FitAddon dipadukan dengan ResizeObserver pada container terminal.
        * Setiap kali container berubah ukuran (resize browser window, drawer expand, atau toggle fullscreen), ukuran rows & cols dihitung ulang dan dikirimkan secara instan via WebSocket: {"type": "resize", "cols": c, "rows": r}.
      - WebSocket Lifecycle & Resiliency:
        * Status indicator visual: Connected (green pulse), Connecting (blue spin), Reconnecting (amber spin with retry counter), Disconnected (red alert).
        * Automatic reconnect dengan exponential backoff jika koneksi WebSocket terputus tidak terduga.
        * Heartbeat 15 detik ping/pong menjaga koneksi tetap hidup melalui reverse proxy Caddy / Nginx.
      - User Experience:
        * Fitur Copy Selection buffer, Clear screen, Reconnect manual, dan Toggle Fullscreen.

   b. Agents Hub Catalog & Management (AgentsHubView.tsx & AgentCard.tsx):
      - Route: /studio/agents dan /agents
      - Katalog persona agen dengan card visual yang menampilkan nama, role, avatar, model Google Gemini yang digunakan, system prompt preview (collapsible), dan status agen.
      - Form pendaftaran & edit agen persona:
        * Nama agen, role (dengan tombol quick-suggestion: Fullstack Architect, Backend Go Specialist, Frontend UI/UX Craftsman, DevOps & SRE, QA & Test Automation, Product Facilitator).
        * Pemilihan avatar emoji interaktif.
        * Model selector: gemini-1.5-pro (Recommended: reasoning mendalam & 2M token context), gemini-1.5-flash (Iterasi cepat), dan gemini-2.0-flash (Ultra low latency).
        * System prompt starter template.
        * Status toggle: active, inactive, archived.
      - Integrasi REST API backend: GET /api/agents, POST /api/agents, PUT /api/agents/{id}, DELETE /api/agents/{id}.

   c. Gemini Connection & Zero Credential Leakage (AgentConnectionModal.tsx):
      - Form input API Key Google Gemini Pro dengan link langsung ke Google AI Studio (aistudio.google.com/app/apikey).
      - Immediate Verification (verify_now: true) memanggil /api/agent-connections untuk enkripsi AES-256-GCM dan probe status kuota.
      - Re-verify Connection memanggil /api/agent-connections/{id}/verify untuk mendeteksi model yang tersedia (gemini-1.5-pro, gemini-1.5-flash, gemini-2.0-flash) dan mengukur latensi (ms).
      - Zero Credential Leakage: Plaintext secret key tidak pernah disimpan di state setelah save dan tidak pernah dikembalikan oleh API backend. Tampilan UI menyajikan indikator aman `AES-256-GCM Vault ••••••••`.

   d. Kanban Board Quick-Access Integration (ProjectTasksBoard.tsx):
      - Kartu task Kanban kini memiliki tombol akses cepat terminal (`PTY`) pada header card dan footer control bar.
      - Mengklik judul task membuka Task Detail Drawer yang dilengkapi tab "Detail & DoD" dan tab "Terminal (PTY)" terintegrasi.
