2. ARSITEKTUR & IMPLEMENTASI:
   a. Enkripsi Kredensial Simetris AES-GCM 256-bit:
      - File: internal/crypto/aes.go
        * Enkripsi dan dekripsi berbasis AES-256-GCM dengan nonce 12-byte kriptografis (crypto/rand).
        * Domain-separated SHA-256 key derivation (DeriveKeySHA256).
        * Authentication tag verification otomatis untuk menjamin integritas data ciphertext (tamper detection).
      - File: internal/agent/crypto.go
        * EncryptCredential & DecryptCredential untuk penyimpanan aman API Key / OAuth tokens di database.
        * MaskAPIKey untuk redaksi aman tampilan UI / logs (e.g. AIzaSy...0XYZ).

   b. Provider Layer & Google Gemini Pro / Flash Auth Engine:
      - File: internal/agent/provider.go
        * Interface Provider: Name(), Type(), VerifyConnection(ctx, credentials), ListModels(ctx, credentials).
        * Entitas ModelInfo (ID, Name, DisplayName, Description, InputTokenLimit, OutputTokenLimit, SupportedGenerationMethods, IsDefault).
        * Entitas ConnectionProbeResult (Valid, Provider, PlanHint, LatencyMs, AvailableModels, ErrorMessage, TestedAt).
        * ProviderRegistry: thread-safe registration dan lookup provider.
        * MockProvider: implementasi mock deterministic untuk testing offline & fault-injection.
      - File: internal/agent/gemini.go
        * GeminiProvider: client HTTP Google Gemini API endpoint (/v1beta/models).
        * Probe koneksi otomatis memverifikasi ketersediaan model flaghsip: gemini-1.5-pro (default), gemini-1.5-flash, gemini-2.0-flash.
        * Mode mock / fallback otomatis saat offline atau test environment sehingga testing tidak flakiness.

   c. REST API Handlers & Zero Credential Leakage:
      - File: internal/server/agent_handlers.go & internal/server/server.go
        * Agent Personas:
          - GET    /api/agents (query: provider, status, role, search, limit, offset)
          - POST   /api/agents (create persona)
          - GET    /api/agents/{id} (get persona)
          - PUT    /api/agents/{id} (update persona)
          - DELETE /api/agents/{id} (delete persona)
        * Agent Connections:
          - GET    /api/agent-connections (list connections)
          - POST   /api/agent-connections (create connection with encrypted storage & optional immediate verify)
          - GET    /api/agent-connections/{id} (get connection details)
          - DELETE /api/agent-connections/{id} (delete connection)
          - POST   /api/agent-connections/{id}/verify (probe and verify connection quota)
        * 100% Backward Compatibility:
          - Tersedia di /api/agents, /api/agent-connections

          - Tersedia di alias /api/agents/connections dan /api/v1/agents/connections
        * Zero Credential Leakage:
