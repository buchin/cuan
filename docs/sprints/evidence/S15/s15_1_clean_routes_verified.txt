2. ROUTE INSPECTION & ZERO-MARKETING OVERHEAD
--------------------------------------------------------------------------------
A. Root Path '/' & App-First Gateway:
  - Unauthenticated access to '/' atau rute privat:
    Langsung diarahkan ke Tokyo Night Auth Gatekeeper (LoginScreen).
  - Authenticated access to '/' atau '/dashboard':
    Langsung merender Dashboard Workspace (StudioDashboard) di dalam Sidebar07Layout.
  - Akses '/login' saat authenticated otomatis redirect ke '/dashboard'.

B. Eliminasi Rute Marketing & Sponsor:
  - Rute pemasaran dihapus/dinonaktifkan:
    * /marketing (Dihapus dari routing)
    * /landing (Dihapus dari routing)
  - Rute sponsorship dihapus/dinonaktifkan:
    * /sponsor (Dihapus dari routing)
    * /sponsors (Dihapus dari routing)
    * /sponsor/pending (Dihapus dari routing)
    * /sponsors/pending (Dihapus dari routing)
    * /sponsor/status (Dihapus dari routing)
    * /admin/sponsors (Dihapus dari routing dan layout)
  - Unused component imports dihapus dari web/src/App.tsx:
    * LandingPage
    * SponsorShowcase
    * SponsorArchive
    * SponsorPending
    * AdminSponsorPanel

C. Eliminasi State APP_MODE & Tombol Navigasi Marketing:
  - State APP_MODE (marketing/studio toggle) dihapus dari web/src/App.tsx.
  - Tombol 'Mode: studio/marketing' dihapus dari header navbar web/src/components/layout/Sidebar07Layout.tsx.
  - Tombol 'Beranda' dihapus dari header navbar web/src/components/layout/Sidebar07Layout.tsx.
  - Tombol 'Landing Page' dihapus dari header web/src/components/auth/LoginScreen.tsx.
  - Menu item 'Moderasi Sponsor' dihapus dari sidebar navigasi global web/src/components/layout/Sidebar07Layout.tsx.
  - Banner 'Studio Mode Active (APP_MODE=studio)' dan tombol 'Lihat Landing Page (/marketing)' dihapus dari web/src/components/studio/StudioDashboard.tsx.
  - Tombol 'Switch to Marketing' / 'Landing Page' dihapus dari tabs row web/src/components/studio/StudioDashboard.tsx.
  - Tombol '← Kembali ke Landing Page' pada setup pertama diubah menjadi '← Kembali ke Halaman Login'.
