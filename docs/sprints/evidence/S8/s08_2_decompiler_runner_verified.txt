1. Fan-Out Decompiler Engine (internal/campaign/decompiler.go & model.go):
   - Package: internal/campaign
   - Source Files:
     * internal/campaign/model.go
     * internal/campaign/decompiler.go
   - Kemampuan:
     * TargetCriteria Parsing: Mendukung format JSON objek (project_ids, tags, all, exclude_ids) dan format array string (["proj-1", "tag:wordpress"]).
     * Resolusi Target Proyek (ProjectResolver):
       - Berdasarkan daftar ID proyek eksplisit.
       - Berdasarkan filter tags (e.g. "wordpress", "adsense") mencocokkan tags proyek, nama proyek, repo, dan query task yang terasosiasi via ProjectStudioRepository.
       - Fallback All dan filter Exclude IDs.
     * Generasi Subtasks project_tasks:
       - Terikat pada project_id target.
       - Terikat pada batch_id (UUID kampanye induk).
       - Terikat pada parent_task_id (Parent Epic task yang terintegrasi di PostgreSQL).
       - Pemetaan tags terdeduplikasi dan terintegrasi dari kampanye, kriteria, dan template.
       - Format Title kustom dengan template {{project_name}} dan {{project_id}} atau format standar.
       - Deskripsi lengkap memadukan deskripsi kampanye, petunjuk instruksi, dan script payload.
     * Garansi Kriteria DoD Minimal >= 3 Butir:
       - Template checklist DoD dari pengguna dipertahankan seutuhnya.
       - Bila kriteria yang diberikan kurang dari 3 butir (termasuk 0 atau 1 butir), decompiler secara otomatis melengkapi dengan kriteria verifikasi standar:
         1) Verifikasi environment dan dependensi proyek target.
         2) Penerapan payload/skrip modifikasi kampanye tanpa kesalahan sintaks.
         3) Eksekusi pengujian validasi terarah 100% PASS tanpa regresi.
         4) Validasi smoke test dan konfirmasi HTTP 200 OK.
       - Setiap butir DoD dilengkapi UUID unik dan status completed: false.
     * Persistence (DecompileAndPersist):
       - Membuat parent epic task di studio repository bila belum ada parent_task_id.
       - Menyimpan seluruh subtasks ke tabel project_tasks dengan foreign key valid tanpa pelanggaran constraint database.

2. Multi-Project Isolated Runner Engine (internal/campaign/runner.go):
   - Source File: internal/campaign/runner.go
   - Kemampuan:
     * Worker Pool Konkurensi Terkontrol:
       - Batas default 5 worker paralel (DefaultMaxWorkers = 5), dapat dikonfigurasi melalui WithMaxWorkers.
       - Semaphore concurrency guard mencegah spike beban CPU/RAM pada host VPS.
       - Pelacakan metrik PeakWorkers memastikan konkurensi aktual tidak pernah melampaui batas yang ditentukan.
     * Isolasi Kesalahan (Fault Isolation / Isolated Blast Radius):
       - Eksekusi subtask per proyek diisolasi sepenuhnya pada goroutine terpisah.
       - Panic recovery guard menangkap runtime panic atau error tanpa menghentikan worker lain atau membatalkan seluruh kampanye.
       - Kegagalan di satu proyek menandai subtask tersebut 'failed', sementara subtask proyek lain tetap diproses hingga selesai ('done').
     * Siklus Hidup Eksekusi & Pembaruan Status:
       - Transisi task: backlog -> doing -> done / failed.
       - Pembaruan checklist DoD: menandai butir DoD selesai saat eksekusi berhasil.
       - Transisi status kampanye di database: draft/pending -> running -> completed (atau failed jika seluruh tugas gagal).
     * Runner Lifecycle Listeners:
       - Callback hooks OnTaskStart, OnTaskComplete, OnTaskFail, OnCampaignComplete siap diintegrasikan dengan Rollup Aggregator dan SSE streaming pada Sprint S08.3.

3. REST Endpoints & Server Integration:
   - Handler File: internal/server/campaign_handlers.go
   - Integrasi Server: internal/server/server.go
   - Endpoint Terpasang & Teruji:
     * POST /api/campaigns & POST /api/v1/campaigns (HTTP 201 Created):
       Membuat entitas BatchCampaign baru dengan validasi title, status, dan JSON payload.
     * GET /api/campaigns & GET /api/v1/campaigns (HTTP 200 OK):
       Mendapatkan daftar kampanye dengan filter query (?status=, ?search=, ?limit=, ?offset=).
     * GET /api/campaigns/{id} & GET /api/v1/campaigns/{id} (HTTP 200 OK / 404 Not Found):
       Mendapatkan detail kampanye beserta daftar child subtasks dan task_count.
     * POST /api/campaigns/{id}/execute & POST /api/v1/campaigns/{id}/execute (HTTP 200 OK):
       Memicu eksekusi kampanye melalui decompiler dan runner engine worker pool, mengembalikan ringkasan eksekusi, total_tasks, completed_tasks, failed_tasks, peak_concurrency, dan duration_ms.
   - Kompatibilitas 100%: Seluruh endpoint terdaftar di root /api dan /api/v1 secara backward-compatible.
