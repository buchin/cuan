2. Integrasi Form Waiting List & Dojo Webhook:
   - Frontend Form: Dua titik konversi (Hero Form & Bottom CTA Form) dengan validasi regex ketat seketika, status loading spinner, dan handling pesan error.
   - Backend Endpoint:
     * Primary: POST /api/waiting-list
     * Alias: POST /api/v1/waiting-list, POST /api/leads
   - Validasi Email Ketat (Backend):
     * Format RFC 5322 via net/mail.ParseAddress
     * Trim whitespace otomatis
     * Pengecekan domain dan dot (.) minimal
     * Maksimal panjang 254 karakter
     * Input invalid atau kosong ditolak secara tegas dengan HTTP 400 Bad Request.
   - Persistence Database: Disimpan ke PostgreSQL tabel `waiting_list_leads` (id, email, source, status, created_at).
   - Dojo Webhook Dispatcher:
     * Event payload: {"event": "waiting_list.signup", "lead_id": "...", "email": "...", "source": "...", "action": "send_welcome_email", "trigger_email": true}
     * Header autentikasi: X-Dojo-Secret, Authorization: Bearer, Content-Type: application/json
     * Configurable via DOJO_WAITING_LIST_WEBHOOK_URL dengan graceful fallback jika URL tidak disetel/offline.
