1. SCOPE & IMPLEMENTATION VERIFICATION
--------------------------------------------------------------------------------
A. Dynamic Sidebar & Navbar with Modular Workspace OS:
   - Module Filter Engine (StudioDashboard.tsx):
     * Dynamically filters Desktop and Mobile navigation tabs based on `activeProject.enabled_modules`.
     * Supported modules: 'tasks', 'discussions', 'repositories', 'servers', 'publishing', 'support'.
     * Dedicated view routing and fallback safety when active tab is toggled off.
   - Interactive Project Switcher (Dropdown & Presets):
     * Smoothly switches between preset workspaces:
       - SaaS / Dojo: ['tasks', 'discussions', 'repositories', 'servers']
       - Creator Hub: ['tasks', 'discussions', 'publishing']
       - Blank Workspace: ['tasks', 'discussions']
     * Displays connected/imported projects from backend API (/api/v1/projects).
   - In-App "+ Add Modules" Toggle Modal (ModuleToggleModal.tsx):
     * Allows activating/deactivating any of the 6 workspace modules at any time.
     * Persists updates to backend via PATCH /api/v1/projects/{id}/modules.
     * Preserves preset configurations with 1-click quick preset buttons.

B. Creator Wizard & AI Script ZIP Onboarding:
   - Interactive Drag-and-Drop Dropzone (ZipUploadWizardModal.tsx):
     * Visual drag-and-drop dropzone supporting .zip files up to 150MB.
     * Real-time upload and extraction progress indicators.
   - AI Tech Stack Inspector Integration:
     * Inspects uploaded ZIP via /api/v1/inspector/inspect-zip before project creation.
     * Displays informative detection cards:
       - Detected Tech Stack (PHP/Laravel/WordPress/Node/Python/Go) with confidence match percentage.
       - Environment Configuration (.env files with required/optional keys).
       - Database Schemas (.sql migration files, table counts, database engines).
       - Auto-Generated Kanban Setup Tasks (DoD checklists, priority, tags).
   - Project Instantiation via /api/v1/projects/from-zip:
     * Instantiates workspace with auto-generated setup tasks and extracted code.
     * Seamlessly redirects to Kanban Tasks board upon creation.
   - Cross-Linking:
     * Integrated banner in CreatorWizardModal.tsx and StudioDashboard.tsx.

C. Task Detail Drawer & 1-Click WordPress Publishing:
   - CMS Publisher Tab in Task Detail Drawer (ProjectTasksBoard.tsx):
     * Secure credential configuration via HTTP Basic Auth (Application Password).
     * Backend encryption with AES-256-GCM (zero plaintext leakage in logs/storage).
     * Status selector: 'draft' vs 'publish'.
     * Markdown-to-semantic-HTML conversion toggle.
     * 1-Click publish execution via POST /api/v1/tasks/{id}/publish.
     * Displays live, clickable publication permalink URL upon success.
   - Visual Indicators:
     * Kanban cards display WordPress publication badges and external links when published.

D. Fullscreen Teleprompter Studio (TeleprompterModal.tsx):
   - Modal View with Auto-Scroll Engine:
     * Smooth scrolling via requestAnimationFrame engine.
     * Adjustable scroll speed (1x to 10x).
     * Adjustable font size (20px to 72px) for various display distances.
     * Horizontal Mirror Mode (flip-x) for physical teleprompter glass beamsplitters.
     * Reset, Pause, and Play controls.
   - Comprehensive Keyboard Shortcuts:
     * [Space]: Toggle Play / Pause
     * [Up / Down Arrow]: Increase / Decrease Scroll Speed
     * [+ / -]: Increase / Decrease Font Size
     * [M]: Toggle Horizontal Mirror Mode
     * [R]: Reset to Top
     * [Esc]: Exit Fullscreen Teleprompter
