1. SCOPE & IMPLEMENTATION VERIFICATION
--------------------------------------------------------------------------------
A. WordPress REST API Client (internal/publisher/wordpress_client.go):
   - Authentication: HTTP Basic Auth with WordPress Application Password (username:password).
   - Strict Zero Credential Leakage:
     * Credentials masked via fmt.Stringer and fmt.GoStringer ([REDACTED]).
     * sanitizeError intercepts network/HTTP errors (401 Unauthorized, 403 Forbidden,
       500 Server Error) to strip and mask raw passwords and base64 tokens.
   - Connection Test Helper:
     * Queries GET /wp/v2/users/me?context=edit.
     * Verifies user roles and capabilities with zero leakage.
   - Post Publisher:
     * Calls POST /wp/v2/posts.
     * Supports status: 'draft', 'publish', 'pending', 'private'.
     * Converts markdown content to clean semantic HTML.
     * Resolves and creates tags dynamically via GET/POST /wp/v2/tags.
     * Parses post ID, status, permalink (publication_url), and date (published_at).

B. Multi-Format Exporter & Teleprompter Backend (internal/publisher/formatter.go):
   - CleanMarkdown: strips LLM artifact wrappers (```markdown ... ```), UTF-8 BOM,
     null bytes, and normalizes line breaks.
   - MarkdownToHTML: converts markdown headers (# to ######), bold, italic, code blocks,
     inline code, blockquotes, horizontal rules, lists (ordered/unordered), links, and images
     into clean semantic HTML.
   - MarkdownToPlainText: strips all markdown and HTML tags into clean, human-readable
     plain text with standardized bullet points, ideal for Teleprompter view and speech.
   - FormatContent: multi-format exporter supporting:
     * format=md: text/markdown; charset=utf-8
     * format=html: text/html; charset=utf-8 (standalone HTML5 document with styling)
     * format=txt: text/plain; charset=utf-8

C. Publisher Engine & Vault Integration (internal/publisher/engine.go):
   - SetupWordPressIntegration:
     * Validates and normalizes connection settings.
     * Tests connection pre-flight.
     * Encrypts credentials using AES-256-GCM via crypto.EncryptStringAES256GCM.
     * Stores encrypted payload in project_integrations table.
     * Returns public ProjectIntegrationDTO with has_config: true and zero password leakage.
   - PublishTask:
     * Fetches task deliverable (agent_output, falling back to description).
     * Decrypts project's WordPress credentials from AES-256-GCM vault.
     * Publishes post to WordPress REST API.
     * Updates task in project_tasks table with publication_url and published_at.
   - ExportTask:
     * Fetches task content and formats into md, html, or txt.

D. Server HTTP Endpoints (internal/server/publisher_handlers.go & server.go):
   - POST /api/v1/projects/{id}/integrations/wordpress (setup & connection test)
   - GET /api/v1/projects/{id}/integrations/wordpress (integration status DTO)
   - POST /api/v1/tasks/{id}/publish (publish task agent_output to WordPress)
   - GET /api/v1/tasks/{id}/export?format={md|html|txt} (multi-format task export)
   - Real-time SSE broadcast: emits 'task.published' to project discussion room.
