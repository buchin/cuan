1. SCOPE & IMPLEMENTATION VERIFICATION
--------------------------------------------------------------------------------
A. Safe Unpacker (internal/inspector/unpacker.go):
   - Isolated extraction with filepath.Clean and relative path sanitization.
   - Strict Zip Slip protection: rejects absolute paths, Windows drive letters,
     path components containing '..', and attempts to escape destination directory.
   - Symlink protection: disallows symlinks in uploaded archives to prevent link-traversal.
   - Size quota protection: enforces 150MB (150 * 1024 * 1024 bytes) uncompressed limit.
   - Guard against zip bombs with spoofed uncompressed sizes via io.LimitReader.
   - Automatic cleanup of destination directory on unpack errors.

B. Multi-Stack Tech Signature Detector (internal/inspector/detector.go):
   - Laravel: detects 'artisan' and 'composer.json' (with 'laravel/framework').
   - WordPress: detects 'wp-config.php', 'Plugin Name:' headers in PHP files, and 'Theme Name:' in style.css.
   - Node / Next / React / Express: detects 'package.json', 'next.config.js', dependencies ('next', 'react', 'express'), and tsconfig.json.
   - Python / Django / Flask: detects 'manage.py', 'requirements.txt' ('django', 'flask'), 'app.py' (Flask import), Pipfile, and pyproject.toml.
   - Static HTML: detects 'index.html' when no backend framework is present.
   - Resolves single top-level directory archives seamlessly.

C. Env, SQL Schema & Documentation Parser (internal/inspector/parser.go):
   - Environment variables: parses '.env.example', '.env.sample', '.env.template', etc.
     Categorizes keys into all_keys, required_keys, database_keys, and security_keys.
   - SQL schema detection: recursively scans for '*.sql' files, captures file size,
     and detects database dialect (mysql, postgres, sqlite, generic).
   - Documentation parser: reads 'README.md', 'install.txt', 'SETUP.md' to extract title
     and installation instructions excerpt.

D. Auto-Generation Pipeline & Project Factory (internal/inspector/pipeline.go & engine.go):
   - Sets source_type to 'zip'.
   - Activates relevant modular workspace modules:
     ["tasks", "discussions", "servers", "repositories"].
   - Stores rich inspection details in projects.source_metadata.
   - Atomically generates:
     1. Project record (with localPath pointing to unpacked project directory).
     2. Project collaboration room ("Script Setup & Onboarding").
     3. Agent Persona ("DevOps Setup Assistant", role "DevOps & Script Setup Specialist").
     4. 4 Actionable setup tasks in project_tasks with Definition of Done (DoD) checklists:
        - Task 1: Setup Environment & .env Configuration
        - Task 2: Database Setup & SQL Import
        - Task 3: Dependency Installation (composer/npm/pip)
        - Task 4: Local Verification & Server Deployment

E. Server API Endpoints (internal/server/inspector_handlers.go & server.go):
   - POST /api/v1/projects/from-zip (and alias /api/projects/from-zip):
     Multipart upload, extracts zip, inspects stack, creates project, room, agent, and setup tasks.
     Returns HTTP 201 Created with full payload.
   - POST /api/v1/inspector/inspect-zip (and alias /api/inspector/inspect-zip):
     Fast pre-flight analysis of zip file in temp sandbox without saving project.
     Returns HTTP 200 OK with tech stack, env vars, sql files, and recommended tasks.
