1. Atomic Port Allocator Pool (internal/deployer/port_pool.go):
   - Range: 9000 s/d 9999 (DefaultMinPort = 9000, DefaultMaxPort = 9999).
   - Thread-safe atomic lease allocator dilindungi sync.Mutex.
   - Pengecekan ketersediaan socket TCP riil pada 127.0.0.1 (via net.Listen) sebelum memberikan lease.
   - Anti-collision / zero-collision: teruji secara concurrent melalui 100 goroutine simultan tanpa duplikasi port.
   - Pembebasan port otomatis (Release / ReleasePort) saat proses deployment dihentikan (Stop/Restart).
   - Penanganan kehabisan alokasi port (ErrPortPoolExhausted) dengan batasan konfigurasi dinamis.

2. Isolated Sandbox Process Runner (internal/deployer/local_driver.go):
   - PHP Executor:
     * Command: `php -S 127.0.0.1:{port} -t {appDir}`.
     * Root document terisolasi pada direktori data/deployments/<id>/app/.
     * Pengujian live HTTP responsif menghasilkan 200 OK.
   - Node.js Executor:
     * Deteksi cerdas file entri aplikasi (server.js, index.js, app.js, main.js, atau npm start via package.json).
     * Injeksi environment variable PORT={port}, HOST=127.0.0.1, dan custom env_vars.
     * Pengujian live HTTP responsif menghasilkan 200 OK.
   - Static File Server Executor:
     * Dedicated Go static HTTP server (cmd/static-server/main.go) menggunakan net/http standard library.
     * Auto-compile on demand ke /tmp/cuan-static-server atau fallback aman ke PHP/Python 3.
     * Pengujian live HTTP request /index.html menghasilkan 200 OK dengan konten HTML statis.
   - Process Subtree Isolation:
     * cmd.SysProcAttr = &syscall.SysProcAttr{Setpgid: true} untuk mengisolasi process group child.

3. Process Lifecycle Controller:
   - Start:
     * Alokasi port dinamis bebas konflik dari PortPool (9000-9999).
     * Spawn child process di latar belakang.
     * Catat Process PID & Internal Port ke tabel deployments dan DB store.
     * Transisi status deployment menjadi 'running'.
     * Menjalankan goroutine exit watcher untuk deteksi otomatis jika proses mati tak terduga.
   - Stop:
     * Penghentian bertingkat (graceful SIGTERM ke process group -> timeout 2 detik -> force SIGKILL).
     * Bebaskan port kembali ke PortPool.
     * Update status deployment di tabel deployments menjadi 'stopped' dan ProcessPID = 0.
   - Restart:
     * Hentikan proses lama dengan aman, jeda stabilisasi, dan nyalakan ulang dengan alokasi port segar.
   - Health Check:
     * Verifikasi liveness OS PID menggunakan syscall.Kill(dep.ProcessPID, 0).
     * Verifikasi konektivitas TCP socket pada 127.0.0.1:{internal_port}.
     * Mengembalikan struktur HealthStatus (Alive, PID, Port, PortResponding, Error).

4. Real-Time Log Streamer (internal/deployer/log_streamer.go):
   - Menangkap stream stdout dan stderr secara non-blocking dari pipe proses child.
   - Menyimpan ke dalam in-memory ring buffer (default 1.000 log) untuk streaming latensi rendah.
   - Menyimpan seluruh log stream secara persisten ke tabel deployment_logs via Store interface.
   - Mendukung pub/sub real-time subscription via channel untuk live log streaming di UI.
