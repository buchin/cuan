3. Service KeyVault Terenkripsi (internal/crypto/vault.go):
   - Package: internal/crypto
   - Algoritma: Simetris AES-256-GCM dengan 12-byte cryptographically secure random nonce (rand.Reader).
   - Format Serialisasi: Base64 standard (nonce + ciphertext + 16-byte authentication tag).
   - Master Key Management: Mengambil secret dari env VAULT_MASTER_KEY dengan key derivation SHA-256 domain-separated. Menyediakan fallback deterministik untuk lingkungan pengujian/dev lokal.
   - SSH Key Fingerprint Calculation:
     * Menghitung fingerprint standar OpenSSH SHA256 (SHA256:...) dari private key (Ed25519, RSA, ECDSA) maupun public key format authorized_keys.
     * Menggunakan library resmi golang.org/x/crypto/ssh.
