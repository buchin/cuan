1. Frontend Servers Management Hub (web/src/components/studio/ServersView.tsx):
   - Halaman / Sub-view "Servers (BYOS)" pada Studio Dashboard (`/studio/servers`):
     * Menampilkan daftar remote server yang terdaftar di PostgreSQL melalui endpoint API `GET /api/servers`.
     * Menampilkan metadata server secara lengkap: nama alias, host/IP, SSH port, username, status badge (Online, Offline, Error, Pending), spesifikasi hardware (Distro/OS, CPU cores, kapasitas RAM, SSH latency), dan key fingerprint.
     * Summary metric cards: Total Remote Servers, Online & Siap Pakai, Total Kapasitas CPU Aktif (vCPU), Total Kapasitas RAM Online (GB).
     * Search & Filter bar: Pencarian instan berdasarkan nama, host/IP, username, atau fingerprint; filter status (All Status, Online, Offline, Error).
     * Aksi Interaktif Server:
       - Test Connection: Menjalankan probe konektivitas instan via `POST /api/servers/{id}/test` dengan loading spinner dan feedback toast berisi latency & hardware specs.
       - Re-sync Fingerprint: Menjalankan probe ulang untuk menyinkronkan fingerprint SSH dan spesifikasi hardware terbaru dari remote server.
       - Delete Server: Dialog konfirmasi penghapusan, mengeksekusi `DELETE /api/servers/{id}`, menutup connection pool SSH, dan memperbarui daftar server.
     * Zero-Friction Onboarding Empty State: Panduan ramah pengguna saat belum ada server terhubung dengan tombol CTA "Hubungkan Server Pertama Anda".

2. Modal "Connect Server" (web/src/components/studio/ConnectServerModal.tsx):
   - Form input intuitif mengikuti tema Cuan shadcn/ui:
     * Nama Server pengenal.
     * Host / IP address remote host.
     * SSH Port (default 22).
     * Username SSH (default `ubuntu` atau `root`).
   - Opsi Autentikasi Fleksibel:
     * Paste Private Key: Textarea untuk OpenSSH / RSA Private Key dengan jaminan enkripsi AES-256-GCM via Cuan KeyVault at-rest.
     * Salin Cuan Public Key: Panduan penambahan public key Cuan ke `~/.ssh/authorized_keys` di remote server dengan tombol 1-click copy snippet script.
   - Interaktif Test Connection Real-time:
     * Tombol "Test Connection" mandiri memicu alur pendaftaran dan live probe via `POST /api/servers/{id}/test`.
     * Status indicator real-time saat probe berlangsung (handshake SSH, query OS/hardware specs).
     * Hasil tes responsif: Alert hijau dengan rincian OS/Distro, CPU Cores, RAM, dan latency jika sukses; alert merah dengan pesan error spesifik jika gagal.
