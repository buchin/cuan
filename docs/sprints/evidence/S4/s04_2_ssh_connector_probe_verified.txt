1. Implementasi SSH Connector & Connection Pooling:
   - File: internal/deployer/ssh_client.go
   - Library: golang.org/x/crypto/ssh
   - Batas Timeout: Strict 5 detik connection timeout (DefaultSSHTimeout = 5 * time.Second).
   - Handshake Safety: Timeout deadline diterapkan pada net.Conn untuk menjamin handshake tidak hang jika server membuka port namun tidak merespons banner SSH.
   - Keepalive Mechanism: Background ticker berkala (DefaultKeepaliveInterval = 30 * time.Second) mengirimkan global keepalive request (keepalive@openssh.com). Jika koneksi mati/terputus, client otomatis menutup diri secara rapi.
   - Connection Pooling (ClientPool): Thread-safe manager dengan sync.RWMutex untuk caching koneksi SSH per server ID, auto-reconnect bila koneksi tertutup, serta CloseServer dan CloseAll untuk pembersihan soket.
   - Zero Leakage: Goroutine keepalive memiliki stopChan terisolasi, channel session ditutup aman, dan memori private key di-parse langsung tanpa disimpan dalam variabel global.

2. Health Probe & Remote Fingerprinting Engine:
   - Script Probe Komposit (posix-compliant):
     * Deteksi OS: /etc/os-release dengan parsing PRETTY_NAME, NAME, VERSION_ID, ID distro, dengan fallback ke uname -a.
     * Deteksi Kernel & Arsitektur: uname -s -r -m (mengekstrak kernel version dan CPU arch x86_64 / aarch64).
     * Deteksi CPU Cores: nproc dengan fallback ke /proc/cpuinfo processor count.
     * Deteksi RAM: free -m (mengekstrak Mem total dalam MB) dengan fallback ke /proc/meminfo MemTotal.
     * Deteksi Hostname: hostname sistem target.
     * Pengukuran Latensi: Mengukur round-trip ping latency dalam milidetik (PingMS).
   - Struktur Data: deployer.SystemSpecs dengan method ToMap() yang menghasilkan format serialisasi terstandar untuk kolom JSONB os_info di PostgreSQL.

3. HTTP Handlers & Routing Server Management:
   - File: internal/server/server_handlers.go & internal/server/server.go
   - Endpoint Terdaftar (mendukung path /api/servers dan /api/v1/servers):
     * GET /api/servers : Mengembalikan seluruh server terdaftar via ServerDTO (field EncryptedKey terisolasi tag json:"-" sehingga kredensial SSH 100% aman dari kebocoran publik).
     * POST /api/servers : Mendaftarkan server remote baru. Memvalidasi field name, host, private_key, menghitung fingerprint OpenSSH (SHA256:...), mengenkripsi private key menggunakan AES-256-GCM KeyVault, dan menetapkan status awal 'pending'.
     * GET /api/servers/{id} : Mengambil detail spesifikasi server terdaftar (404 bila tidak ditemukan).
     * POST /api/servers/{id}/test : Menjalankan uji koneksi dan health probe instan. Mendekripsi kredensial via KeyVault, dial SSH dengan timeout 5s, mengeksekusi probe, dan mengupdate database dengan status 'online' (atau 'error' / 'offline' jika gagal), last_ping_at, dan os_info.
     * DELETE /api/servers/{id} : Memutus koneksi aktif di SSHManager dan menghapus record server dari database (404 bila tidak ditemukan).
