1. ARCHITECTURAL OVERVIEW & FRONTEND IMPLEMENTATION
--------------------------------------------------------------------------------
Task S10.4 brings the full creator-focused value proposition of Cuan to life across
both the marketing showcase and the Studio operational environment:

1. Creator Project Wizard (CreatorWizardModal.tsx):
   - Interactive modal accessible via the "Creator Wizard" button in the Studio header
     and via a dedicated quick launcher banner in the Studio Projects view.
   - Fetches the blueprint catalog dynamically from GET /api/v1/creator/templates
     (with seamless fallback to built-in templates if offline).
   - Displays 4 interactive archetype cards:
     * Blog Publisher (SEO Specialist persona, #SEO Research room, 3 pipeline tasks)
     * YouTube Channel (YouTube Scriptwriter persona, #Channel Production room, 4 pipeline tasks)
     * Online Shop / Digital Product (Direct-Response Copywriter persona, #Sales Funnel room, 3 pipeline tasks)
     * Affiliate Site (Affiliate Reviewer persona, #Niche Affiliate room, 3 pipeline tasks)
   - Displays real-time breakdown of assigned AI Agent persona, linked discussion room,
     and pipeline tasks with DoD checklist item counts.
   - Triggers atomic backend instantiation via POST /api/v1/creator/projects/instantiate.
   - Seamlessly guides the creator directly to the generated project tasks board upon creation.

2. In-Task Agent Runner (ProjectTasksBoard.tsx):
   - Every Kanban card features a prominent "Run with Agent" button with Sparkles icon.
   - Live execution indicator reflects task.execution_status:
     * 'idle': Ready to run
     * 'running': Spinning loader animation, pulsing purple badge, disabled state preventing duplicate execution
     * 'completed': Green "Output Ready" badge with direct shortcut to the Agent Output tab
   - Trigger endpoint: POST /api/v1/tasks/{id}/execute-agent.
   - Graceful Error Handling:
     * Catches 422 Unprocessable Entity (MISSING_GEMINI_KEY) if Google Gemini API key
       is not configured in Key Vault.
     * Displays a friendly, actionable alert banner and notification directing the creator
       to connect their API key in Agent Hub (/studio/agents).
   - Live state updates:
     * Replaces local task data with updated status, auto-completed DoD checklist,
       execution_status, and full Markdown agent_output.

3. Agent Output Drawer Tab & Markdown Viewer (MarkdownViewer.tsx):
   - Integrated as a first-class tab in the Task Detail Drawer / Modal alongside
     "Detail & DoD" and "Terminal (PTY)".
   - Features an active indicator dot when agent_output is available.
   - Top action bar includes deliverable status badge, "Run Again" button, and One-Click
     "Copy to Clipboard" with instant feedback state ("Tersalin ke Clipboard!").
   - MarkdownViewer renders headers (H1-H4), blockquotes, lists (bullet & numbered),
     interactive checklists, syntax-styled code blocks with copy snippet buttons, and tables.
   - Friendly empty state with prominent "Run with Agent Now" CTA if the task has not
     been executed yet.

4. Landing Page Overhaul (LandingPage.tsx):
   - Transformed 100% of copy, headline, and narrative into "Agentic Project Management for Creators".
   - Hero Section:
     * Headline: "Kelola Proyek Kreator & Eksekusi Konten Tanpa To-Do List Mati."
     * Subtitle: Positioning Cuan for Blogger, YouTuber, Olshop, and Affiliate creators.
     * CTAs: "Buka Studio Sekarang" (zero-friction entrance to Studio) & "Eksplor 4 Blueprint".
   - Pain Points Section:
     * Problem 1: To-Do List Mati di Backlog (kartu task pasif tanpa tim asisten)
     * Problem 2: Overwhelmed Multi-Channel (riset SEO, skrip video, dan sales funnel bersamaan)
     * Problem 3: Tools AI Terfragmentasi (berlangganan belasan SaaS tanpa alur kerja terpadu)
   - Agitation Section:
     * Kehilangan Momentum Tren, Biaya Langganan Bocor, dan Creative Burnout.
   - Solution Section:
     * 6 Feature Cards: Blueprint Templates, In-Task Agent Runner, Key Vault (BYOK),
       Markdown Viewer & One-Click Copy, Auto-Updated Definition of Done, 100% Self-Hosted.
   - Interactive Blueprint Catalog Showcase:
     * Dedicated section displaying the 4 creator templates with persona details and direct
       Studio activation CTA.
   - Maintained full sponsor bridge, legal navigation, and waiting list resilience.
