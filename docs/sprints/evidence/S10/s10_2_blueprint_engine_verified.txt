--------------------------------------------------------------------------------
The Creator Blueprint Engine defines 4 specialized instant project blueprints designed specifically for modern creators:

1. Blog Publisher (ID: blog, Aliases: blog_publisher, blogger, web_publisher)
   - Category: content | Icon: book-open
   - Room:
     * Title: "SEO Research"
     * Topic: "SEO keyword research, content planning, and pillar article drafts"
   - Agent Persona:
     * Name: "SEO Specialist"
     * Role: "Search Engine Optimization Specialist & Content Strategist"
     * Model: "gemini-1.5-pro" | Provider: "google" | Status: "active"
   - Pipeline Tasks (3 structured tasks with concrete DoD checklists):
     1) Keyword research (Priority: high, Tags: [seo, research, keywords])
        DoD:
        - Identified primary keyword and 5+ secondary LSI keywords
        - Analyzed top 3 SERP competitor headings and word count
        - Mapped user search intent (informational/commercial) and target audience
        - Structured recommended H2/H3 article outline
     2) Content drafting (Priority: urgent, Tags: [content, drafting, article])
        DoD:
        - Engaging introduction with hook and clear thesis statement
        - Comprehensive H2/H3 body sections covering all topical sub-questions
        - Actionable takeaways, examples, or data points included
        - Natural inclusion of primary and secondary keywords without stuffing
        - Clear conclusion with compelling call-to-action (CTA)
     3) On-page SEO (Priority: normal, Tags: [seo, optimization, metadata])
        DoD:
        - Meta title formulated under 60 characters with primary keyword
        - Meta description under 155 characters with compelling click trigger
        - SEO-friendly URL slug defined
        - Image alt-text and schema markup recommendations documented

        DoD:

2. REST API ENDPOINTS SPECIFICATION
--------------------------------------------------------------------------------
1. GET /api/v1/creator/templates (and alias /api/creator/templates)
   - Returns full catalog of 4 creator templates with rooms, tasks, and personas.
   - Status: 200 OK
   - Response structure:
     {
       "status": "success",
       "count": 4,
       "templates": [...]
     }

2. GET /api/v1/creator/templates/{id} (and alias /api/creator/templates/{id})
   - Returns a single blueprint template by canonical ID or alias.
   - Status: 200 OK (or 404 Not Found if invalid)
   - Response structure:
     {
       "status": "success",
       "template": {...}
     }

3. POST /api/v1/creator/projects/instantiate (and alias /api/creator/projects/instantiate)
   - Atomically instantiates a complete creator project pipeline:
     1. Creates Project record with project_type set to template ID and metadata.
     2. Creates Collaboration Room with default topic.
     3. Creates or links the corresponding Agent Persona.
     4. Creates all pipeline tasks with DoD checklists, assigned to the agent persona.
     5. Posts an initial Markdown welcome message into the room.
   - Rollback guarantee: If any step fails, all previously created tasks, room, and project are completely cleaned up.
   - Status: 201 Created
   - Response structure:
     {
       "status": "success",
       "template_id": "blog",
       "project": {...},
       "room": {...},
       "agent": {...},
       "tasks": [...]
     }
