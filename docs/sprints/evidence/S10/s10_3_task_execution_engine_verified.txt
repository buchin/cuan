1. ARCHITECTURAL OVERVIEW & ENDPOINT SPECIFICATION
--------------------------------------------------------------------------------
The In-Task Agentic Execution Engine turns stagnant Kanban cards into active,
autonomous delivery channels. Instead of copying prompts between fragmented tools,
creators trigger agent executions directly on tasks to generate complete, high-quality
deliverables in Markdown format.

Primary Endpoint:
  POST /api/v1/tasks/{id}/execute-agent

Supported Endpoint Aliases (100% Backward & Forward Compatibility):
  - POST /api/tasks/{id}/execute-agent
  - POST /api/projects/tasks/{id}/execute-agent
  - POST /api/v1/projects/tasks/{id}/execute-agent

Execution Lifecycle:
  1. Task & Context Inspection:
     - Validates task UUID and loads title, description, tags, priority, room_id, and DoD checklist.
     - Resolves assigned agent persona or derives it from the project blueprint template (SEO Specialist, YouTube Scriptwriter, Conversion Copywriter, Affiliate Strategist).
  2. Vault Decryption & Credential Hygiene:
     - Retrieves the user's active Google Gemini Pro connection from the database.
     - Decrypts the stored API key using the AES-256-GCM symmetric Key Vault.
     - Enforces ZERO credential leakage: plaintext keys are NEVER exposed in API responses, logs, or stored task records.
     - Graceful guardrail: if no key is connected, returns an informative 422 Unprocessable Entity directing the creator to the Agent Hub (/studio/agents).
  3. Creator-Specific Prompt Synthesis:
     - Automatically classifies the pipeline: Blog, YouTube, Olshop, Affiliate, or General Creator.
     - Formulates targeted system instructions and a structured prompt requiring complete, production-ready deliverables.
     - Injects the explicit Definition of Done (DoD) checklist items into the prompt constraints.
  4. LLM Content Generation (Google Gemini Pro):
     - Sets task execution_status to "running" and broadcasts a real-time event.
     - Invokes Google Gemini Pro (gemini-1.5-pro / gemini-1.5-flash) via generateContent API (with offline mock fallback for offline/test environments).
  5. Persistence, Auto-DoD Completion & Room Syncing:
     - Stores the full Markdown deliverable in the `agent_output` column on `project_tasks`.
     - Sets execution_status to "completed" and transitions task status to "review".
     - Automatically marks every satisfied item in the task's DoD checklist as `Completed: true`.
     - Posts a summary notification and deliverable preview message to the linked discussion room.
     - Broadcasts `task.updated` and `message.created` SSE events across the project room.

2. TARGETED PIPELINE EXECUTION SPECIALIZATIONS
--------------------------------------------------------------------------------
The engine provides domain-specific prompt engineering and output structures for the 4 creator archetypes:

1. Blog Publisher Pipeline:
   - Keyword Research: Primary keyword, 5+ secondary LSI keywords table, search intent mapping (informational/commercial), competitor SERP gap analysis, recommended H2/H3 outline.
   - Content Drafting: Complete 1,500+ word pillar article, hook introduction, comprehensive H2/H3 body, actionable takeaways/data, natural keyword density, conclusion & CTA.
   - On-Page SEO: Meta title (<60 chars), meta description (<155 chars), URL slug, image alt-tags, JSON-LD schema markup.

2. YouTube Channel Pipeline:
   - Ideation & Hook: 5 high-CTR titles scored for curiosity gap, opening 30-second retention hook script, thumbnail concept & text overlay.
   - 10-Min Scriptwriting: Full spoken voiceover script (>1,200 words), explicit bracketed [Visual: ... / B-Roll: ...] cues, 4-minute mid-roll engagement hook, outro.
   - Description & Tags: First 2 lines CTR hook, timestamped chapters (00:00 Intro), 3 hashtags, 15 targeted search tags.

3. Online Shop / Digital Product Pipeline:
   - Sales Page Copy: Problem-Agitate-Solution (PAS) framework, magnetic headline & subheadline, pain agitation, product benefit breakdown, social proof placeholders, risk reversal guarantee, urgency CTA.
   - 3-Part Email Nurture: Email 1 (Welcome & value), Email 2 (Case study transformation), Email 3 (Direct pitch & deadline reminder), high-open-rate subject lines and preview text.
   - FAQ & Objections: Top 5-7 objections addressed (price, time, trust, complexity) in accordion-ready Q&A markdown.

4. Affiliate Site Pipeline:
   - Product Comparison Matrix: 3-5 competing products compared across 5 criteria, Markdown comparison matrix table with winner badges, budget/premium verdicts.
   - Hands-On Product Review: Experiential testing narrative, balanced Pros & Cons list with at least 3 genuine drawbacks, rating out of 10.
   - CTA & Disclaimer: High-CTR contextual CTA button copy, above-the-fold FTC-compliant affiliate disclosure, rel='nofollow sponsored' link tagging rules.
