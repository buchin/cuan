## Sprint goal dan demo outcome

### Sprint Goal
Mentransformasi antarmuka dan fondasi multi-proyek Cuan menjadi **"Clean Slate UI: Tokyo Night Theme, shadcn Sidebar-07 Shell, Auth Gatekeeper & Multi-Project Task Linking"**, yang mencakup:
1. **Multi-Project Schema Migration (000019):** Memperluas skema database dengan kolom `is_archived` pada tabel `projects`, tabel relasi many-to-many `task_projects`, indeks performa teroptimasi, dan auto-seed kredensial default admin (`admin` / `whosyourdaddy`).
2. **Backend Auth Layer & Session Management:** Handler otentikasi berbasis token session terenkripsi/terhash bcrypt, support dual session (cookie `cuan_session` & header `Authorization: Bearer`), REST endpoints lengkap (`/api/v1/auth/login`, `/api/v1/auth/logout`, `/api/v1/auth/me`, `/api/v1/auth/password`), serta Middleware `AuthGuard` dengan bypass rute publik.
3. **Multi-Project Task Linking Data Layer:** Menghubungkan satu tugas (task) ke beberapa proyek sekaligus secara fleksibel tanpa batasan 1:1, mempermudah manajemen backlog terpusat lintas repository/monorepo.
4. **Tokyo Night Theme Engine:** Menghadirkan palet warna premium Tokyo Night (`#1a1b26` background, `#24283b` card/sidebar, `#7aa2f7` primary blue, `#bb9af7` purple, `#7dcfff` cyan, `#e0af68` yellow, `#9ece6a` green) dengan kontras tinggi yang nyaman di mata untuk developer dan digital solopreneur.
5. **Modern shadcn Sidebar-07 Shell:** Mengganti layout legacy dengan arsitektur navigasi modern shadcn Sidebar-07: collapsable collapsible panels, active project switcher dropdown, status badge proyek aktif/arsip, dan status profil user terotentikasi.
6. **Frontend Auth Gatekeeper:** Proteksi rute SPA frontend dengan login modal/screen yang elegan, persistensi token aman di session/cookie, interceptor auto-refresh & auto-redirect ke login saat 401 Unauthorized, serta form ubah password di pengaturan profil.
7. **Strict 100% Data Retention & Zero Regression:** Mempertahankan keutuhan seluruh data dan fitur Sprint 1–13 (Docker Deployer, BYOS Server, Custom Domains, Observability, Studio Discussions, PTY Terminal, Blueprints, Script Deployer, WordPress Cloud).

### Demo Outcome
1. Pengguna membuka aplikasi Cuan di browser; jika belum login, pengguna disambut oleh **Tokyo Night Auth Gatekeeper** yang bersih dan responsif.
2. Pengguna memasukkan kredensial default (`admin` / `whosyourdaddy`) atau email pemilik:
   - Login berhasil, token session disimpan di cookie HttpOnly dan state client.
   - Layar langsung berganti ke **Clean Slate UI Shell** berbasis layout **shadcn Sidebar-07**.
3. Di Sidebar-07:
   - Pengguna dapat melihat daftar workspace proyek aktif dan proyek terarsip (`is_archived`).
   - Switcher proyek di sidebar header memungkinkan pergantian konteks proyek secara instan tanpa reload halaman.
   - Footer sidebar menampilkan badge profil user aktif (`admin`) dan tombol ubah password (`POST /api/v1/auth/password`).
4. Pada Task Board / Kanban:
   - Pengguna membuat task baru dan dapat menautkan task tersebut ke satu atau lebih proyek (`task_projects`).
   - Badge multi-proyek muncul pada kartu task untuk membedakan keterikatan proyek secara visual.
   - Filter board mendukung penyaringan berdasarkan proyek terkait maupun status arsip.
5. Di menu pengaturan profil, pengguna dapat memperbarui password admin dengan memverifikasi password lama, dan perubahan password langsung aktif pada sesi berikutnya.

### S14.1 — Auth Layer, Session Management & Multi-Project Schema Migration (000019)
- **Scope:**
  - Migrasi database 000019 (`000019_auth_and_multiproject.up.sql` dan `.down.sql`):
    - Tambah kolom `is_archived BOOLEAN NOT NULL DEFAULT FALSE` dan indeks `idx_projects_is_archived` pada tabel `projects`.
    - Buat tabel relasi many-to-many `task_projects` (`task_id TEXT REFERENCES tasks(id) ON DELETE CASCADE`, `project_id TEXT REFERENCES projects(id) ON DELETE CASCADE`, `created_at TIMESTAMP`, `PRIMARY KEY (task_id, project_id)`).

## Out of Scope Eksplisit
* Multi-tenant user RBAC permission matrix (Cuan tetap menganut model Single-Owner / Private Developer Platform).
* OAuth2 / Social login pihak ketiga (Google, GitHub OAuth login).
* Sinkronisasi task eksternal dua arah dengan Jira atau Trello (fokus pada database internal Cuan).

## Risiko & Mitigasi

| Risiko | Dampak | Mitigasi |
| :--- | :--- | :--- |
| **Lockout Akun Admin Default Pasca-Migrasi** | Pengguna tidak bisa login ke dashboard | Auto-seed baris admin default (`admin` / `whosyourdaddy`) pada migrasi 000019 dan verifikasi saat startup |
| **Kebocoran Password / Insecure Hash** | Risiko pembajakan akses server | Hashing wajib menggunakan bcrypt dengan DefaultCost; token session menggunakan random hex cryptographically secure |
| **Integritas Relasi Many-to-Many `task_projects`** | Orphaned records saat task atau project dihapus | Relasi foreign key dengan `ON DELETE CASCADE` di kedua sisi |
| **Regresi Terhadap Endpoint Sprint 1–13** | Kerusakan fungsionalitas runner, studio, atau deployer | Middleware `AuthGuard` menyertakan bypass rute publik esensial (`/healthz`, `/readyz`, `/api/info`, `/api/mode`, `/api/caddy/ask`) dan backward compatibility session headers |
| **Integritas Database Pasca-Migrasi 000019** | Kerusakan data historis proyek dan task | Skema 000019 murni aditif non-destruktif dengan verifikasi data retention 100% |
