## 1. Sprint Goal dan Demo Outcome

### Sprint Goal
1. Memperbaiki tampilan dan interaksi **Mobile Chat Composer**: pada perangkat mobile (< md / 360px–414px), saat percakapan chat aktif, Mobile Bottom Navigation Bar otomatis disembunyikan (mengikuti UX WhatsApp / Telegram) sehingga 100% layar ponsel dialokasikan untuk percakapan. Terapkan viewport dinamis (`h-[100dvh]`) dan pastikan input textarea serta tombol kirim selalu berada di dasar layar dengan padding yang presisi tanpa tertutup nav bar. Saat tombol Back (`<`) ditekan, Bottom Navigation Bar muncul kembali secara mulus.
2. Menghadirkan **Add Agent & CLI Login UI (Model Fural — No API Key)**: modal pendaftaran dan otorisasi agent baru tanpa meminta API Key mentah. Pengguna memilih nama/handle agen (contoh: `@sm`, `@dev`, `@assistant`), runtime/provider (Antigravity CLI / Gemini CLI / Claude CLI), dan alur otorisasi sesi akun/CLI (CLI Session Token / Device Auth / Google OAuth) layaknya di Fural. Kredensial sesi disimpan secara aman di backend/DB Cuan, dan kontak chat agen menampilkan badge status `"Connected"` / `"Online"`.
3. Membangun **Chat-to-Agent Execution Loop & Response**: ketika user (PO) mengirim pesan ke kontak tipe `'agent'`, backend memicu runner runtime agent (Antigravity CLI `agy` / subprocess adapter terotorisasi) dengan prompt percakapan, menangkap output teks responsif, menyimpannya ke `chat_messages` (sebagai pengirim agen), dan menampilkannya secara langsung di jendela percakapan user.
4. Menjalankan pengujian staging E2E pada port 8081, menjaga 19 migrasi database PostgreSQL utuh (zero DB regression), memastikan endpoint publik `/chat/widget.js` tetap prima, membangun bundle produksi, mendeploy ke `https://cuan.dojo.cc`, dan menyusun panduan operasional mandiri berdiagram D2 TALA beserta berkas audit bukti.

## 2. Target Market dan Pertimbangan Kepuasan DoD (§4)

### Target Market
* **Solopreneur & Pengelola Bisnis Mandiri (Dojo Creators On-The-Go):** Mengakses Cuan melalui smartphone untuk mengobrol langsung dengan agen AI mereka, meminta bantuan coding, konsultasi bisnis, atau menjalankan sprint tanpa perlu laptop.
* **Pengembang / Operator Agentic Scrum:** Ingin menghubungkan agen CLI lokal/cloud tanpa kerumitan menyalin dan memperbarui API key berbayar secara manual.

### Mengapa Target Market Bakal Senang dengan DoD Ini?
* **Zero Composer Frustration:** Di HP, tidak ada lagi tombol Send yang tertutup Bottom Nav Bar atau textarea yang terpotong. Pengalaman chat terasa mulus seperti WhatsApp atau Telegram.
* **No API Key Friction:** Model otorisasi Fural / CLI login menghilangkan ketakutan membocorkan API key atau kehabisan kredit API raw; agen terhubung langsung via sesi akun yang aman.
* **Obrolan Nyata Dua Arah:** Pesan yang dikirim ke agen AI benar-benar dieksekusi dan dijawab oleh mesin agen AI Antigravity, bukan teks statis placeholder.

## 4. Arsitektur Chat-to-Agent Execution Loop (D2 TALA)

```d2
direction: right

user: "User (PO via Web / Mobile Chat)"
server: "Cuan Go Backend Server"
db: "PostgreSQL Database (chat_messages)"
agent_runner: "Agent Runtime Runner (agy CLI / Adapter)"

user -> server: "POST /api/v1/chat/conversations/{id}/messages"
server -> db: "Save User Message"
server -> agent_runner: "Trigger CLI Execution (Prompt & Context)"
agent_runner -> server: "Capture Response Output"
server -> db: "Save Agent Response Message"
server -> user: "Return User Msg & Agent Reply (Realtime/HTTP)"
```

## 8. Risiko & Mitigasi

| Risiko | Dampak | Mitigasi |
| :--- | :--- | :--- |
| **Keyboard Mobile Menutupi Input Composer** | Pengguna tidak bisa melihat teks yang diketik di HP | Gunakan `h-[100dvh]`, sembunyikan bottom nav bar saat chat aktif, dan berikan padding dasar yang fleksibel |
| **CLI Runner Membutuhkan Waktu untuk Merespons** | Request HTTP chat terasa lambat jika menunggu sinkron | Batasi timeout eksekusi CLI (contoh 15s) dan simpan respons ke database sehingga polling/realtime langsung mengambilnya |
| **Kerusakan Migrasi DB saat Deploy** | Skema database produksi korup | Mengunci migrasi pada 19 migrasi yang sudah stabil dan memverifikasi tabel sebelum & sesudah deploy |
