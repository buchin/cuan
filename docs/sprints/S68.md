## 1. Ringkasan Eksekutif & Sasaran Sprint 68

Sprint 68 menggabungkan dua inisiatif penting untuk meningkatkan kecepatan pengembangan (*Developer Velocity*) dan kenyamanan pengguna (*Zero Cognitive Fatigue* sesuai standar Things 3 & Bear Notes):

1. **High-Speed & Fail-Fast Deploy Pipeline (DevOps / DX Optimization):**
   - Mengeliminasi kegagalan build tersembunyi dengan menyematkan `tsc --noEmit` di gate awal pengujian (fail-fast dalam 3-5 detik jika ada error tipe/variabel tak terpakai).
   - Memparalelkan kompilasi 3 binary Go (`cuan-server`, `cuan-migrate`, `cuan-runner`) untuk memangkas durasi kompilasi hingga 50%.
   - Mengganti pengiriman aset `scp -q -r` dengan direct SSH delta `rsync`, memangkas waktu transfer rilis ke VPS `cuan.dojo.cc`.
   - Mengoptimalkan eksekusi pengujian backend dengan opsi `-short` untuk pre-deploy sanity check.

2. **Calm Navigation & Unified Preferences Architecture (UI/UX):**
   - **MoreVertical Diet (Header Kanan Atas):** Menghapus link navigasi global (`/agents`, `/schedules`, `/settings`) dari dropdown titik tiga pojok kanan atas. Menjadikannya murni menu aksi kontekstual halaman (*contextual overflow*) atau tersembunyi saat tidak ada aksi halaman.
   - **Unified Preferences SlideDrawer:** Menyatukan dualisme rute `/account` dan `/settings` ke dalam satu SlideDrawer terpadu yang tenang dan elegan, diakses langsung dari Avatar Profil (`NavUser`). Menggunakan pola *Apple-style Inset Grouped Rows* (`GroupedSection`).
   - **Mobile Bottom Navigation & Ergonomi:** Pertahankan akses `Projects` tetap ada sesuai kebutuhan operasional, sembari merapikan target sentuh jempol ($\ge 44\times 44$px) dan menyelaraskan integrasi `NavUser` agar membuka `PreferencesDrawer` secara mulus tanpa dropdown glitchy.

## 2. Backlog Task Sprint 68

### S68-T1: High-Speed & Fail-Fast Deploy Pipeline
- **Scope:**
  1. Tambahkan `tsc --noEmit -p web` ke dalam test script `web` dan gate awal `scripts/deploy.sh` agar error tipe langsung terdeteksi di detik-detik awal.
  2. Paralelkan kompilasi Go di `scripts/deploy.sh`:
     ```bash
     CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build ... ./cmd/server &
     CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build ... ./cmd/migrate &
     CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build ... ./cmd/runner &
     wait
     ```
  3. Optimasi transfer file rilis ke VPS menggunakan delta transfer `rsync` langsung via SSH.
  4. Sediakan opsi pengujian kilat untuk Go (`go test -short ./...`).
- **DoD:**
  - `deploy.sh` mendeteksi error TypeScript dalam <5 detik jika ada `tsc` error.
  - Durasi kompilasi Go backend berkurang minimal 40%.
  - Transfer payload rilis ke VPS terbukti hemat bandwidth dan lebih cepat.

### S68-T3: Unified Preferences SlideDrawer & NavUser Architecture
- **Scope:**
  1. Bangun komponen `PreferencesDrawer` menggunakan `SlideDrawer` dan `GroupedSection` (Things 3 / Apple Inset Groups).
  2. Kelompokkan pengaturan menjadi 4 seksi tenang:
     - **Akun & Profil:** Avatar, Nama, Role, Password.
     - **Mesin AI (@cuan):** Status AI Providers & Kuota, Model Default, Fallback.
     - **Memori & Tim:** Memori Agen (Taste / Panduan Gaya) & Manajemen Anggota Tim.
     - **Aplikasi:** Bahasa (Indonesian/English), Tema Gelap/Terang, Shortcut, Sign Out.
  3. Hubungkan klik Avatar `NavUser` (baik di desktop sidebar maupun mobile) langsung membuka `PreferencesDrawer`.
  4. Pertahankan backward-compatibility URL (`/settings`, `/account`) dengan me-redirect atau membuka drawer secara mulus.
- **DoD:**
  - Dualisme `/account` vs `/settings` terselesaikan menjadi satu pengalaman terpadu.
  - Zero disruption: pengguna dapat mengubah preferensi tanpa meninggalkan alur kerja halaman aktif.
  - Bebas dari nested card box di dalam box.
