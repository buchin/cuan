## Sprint goal dan demo outcome

### Sprint Goal
Mengembangkan Cuan menjadi **"Turnkey WordPress Cloud & Agentic Webmaster Engine"**, memperluas kapabilitas deployment mandiri Sprint 12 menjadi platform penerbitan web WordPress berstandar enterprise yang mampu:
1. **Automated WordPress Container & Database Provisioning:** Menyediakan container WordPress terisolasi yang terhubung otomatis ke MySQL/MariaDB terisolasi serta alokasi port dinamis dan reverse proxy Caddy dengan penerbitan SSL/TLS otomatis.
2. **Environment & Admin Secrets Vault (AES-256-GCM):** Menyimpan kredensial admin WordPress (`admin_password_encrypted`) dan password database (`db_password_encrypted`) di brankas terenkripsi AES-256-GCM dengan zero plaintext leakage pada API JSON publik.
3. **Turnkey WP-CLI Bootstrapping:** Mengotomasi konfigurasi `wp-config.php`, instalasi core WordPress (`wp core install`), permalink setting (`/%postname%/`), dan default hardening tanpa intervensi manual web installer.
4. **Theme & Plugin ZIP Manager:** Menyediakan dropzone upload ZIP untuk theme dan plugin kustom dengan ekstraksi otomatis ke direktori `wp-content/themes` atau `wp-content/plugins` serta auto-activation instan.
5. **Agentic AI Webmaster Action Engine:** Asisten AI cerdas yang bertindak sebagai *AI Webmaster* untuk inject tracking script (Google Analytics, Meta Pixel, dsb.), tweaking konfigurasi `wp-config.php`/`functions.php`, dan audit performa/keamanan web yang tercatat rapi di tabel audit `wordpress_webmaster_actions`.
6. **Interactive 1-Click Launchpad & Webmaster Studio Console:** Antarmuka visual di Studio/Kanban untuk setup WordPress 1-klik, quick action copy credential dengan perlindungan mask, live health monitor, dan riwayat aksi webmaster.
7. **Strict Data Retention & Dokumentasi Mandiri:** Menjaga keutuhan 100% data Sprint 1–12 dan menyusun panduan operasional mandiri di `docs/guides/wordpress_turnkey_webmaster_guide.md` berstandar diagram D2 TALA.

### Demo Outcome
1. Pengguna membuka project bertipe WordPress atau menekan tombol **"1-Click WordPress Deploy"** di Cuan Studio.
2. Muncul wizard peluncuran WordPress:
   - **Step 1 (Site & Admin Profile):** Judul web (`site_title`), admin email, admin username, serta password admin (dengan opsi *Auto-generate Strong Password*).
   - **Step 2 (Database & Domain Configuration):** Domain kustom/subdomain, database host, nama DB, dan DB password terenkripsi AES-256-GCM.
   - **Step 3 (Theme & Plugins Pre-Install):** Upload ZIP theme (misal: Astra, GeneratePress, atau theme kustom) serta plugin esensial.
   - **Step 4 (Launch & Bootstrapping Console):** Progress bar & streaming logs saat container di-spin up, WP-CLI mengeksekusi instalasi core, dan Caddy mengonfigurasi SSL.
3. Begitu instalasi selesai, web langsung berstatus `running` dan `healthy` (HTTP 200).
4. Pengguna dapat membuka **"Open Live Site"** dan **"Open WP-Admin"** langsung dari dashboard.
5. Melalui chat studio, pengguna memerintahkan: *"Tolong pasang script Google Tag Manager GTM-XXXX di header"*. AI Webmaster mengeksekusi aksi `inject_script`, mencatat perubahan di audit log, dan script langsung aktif di frontend WordPress.

## Target market dan pertimbangan kepuasan DoD (§4)

### Persona Target Market
1. **Blogger & Affiliate Marketer Non-Teknis:**
   - Ingin meluncurkan blog niche AdSense atau website review affiliate dalam hitungan detik tanpa harus repot menyewa cPanel, membuat database MySQL manual, atau upload via FTP.
   - *Kebutuhan:* Alur 1-klik yang mengurus instalasi WordPress, database, SSL HTTPS, dan konfigurasi permalink SEO.
2. **Digital Agency & Freelancers:**
   - Memiliki koleksi theme premium dan plugin berbayar (format ZIP) yang harus diinstal pada puluhan website klien.
   - *Kebutuhan:* Upload ZIP theme/plugin instan dengan aktivasi otomatis dan manajemen kredensial terpusat yang aman.
3. **Kreator Konten & Solopreneur:**
   - Memerlukan integrasi tracking script (Google Analytics, TikTok Pixel, Meta Pixel) atau modifikasi script tanpa risiko merusak file PHP inti website.
   - *Kebutuhan:* AI Webmaster yang dapat menginjeksi script secara aman dan melakukan rollback jika terjadi kesalahan.

### Pertimbangan Kepuasan Target Market (DoD Focus)
- **Zero-Friction WordPress Launch:** Dari input judul web hingga live HTTPS hanya memakan waktu < 60 detik tanpa layar instalasi wp-admin manual.
- **Zero Credential Leakage (AES-256-GCM Vault):** Kredensial login admin dan database tidak terekspos di API publik dan selalu tersimpan dalam bentuk ciphertext terotentikasi.
- **Aman dari Kerusakan Kode (Safe Script Injection):** Injeksi script oleh AI Webmaster dilakukan melalui hook terisolasi dan tercatat dalam audit log yang dapat dibatalkan sewaktu-waktu.
- **Strict Data Retention (100% Data Integrity):** Skema database 000018 murni aditif non-destruktif; seluruh data Sprint 1–12 tetap utuh 100%.

## Out of Scope Eksplisit
* Multi-site WordPress network (WPMU) clustering across multiple servers.
* Custom DNS nameserver hosting (menggunakan domain yang sudah diarahkan DNS A-record/CNAME ke server).
* Pembelian lisensi berbayar plugin/theme komersial pihak ketiga secara otomatis.

## Risiko & Mitigasi

| Risiko | Dampak | Mitigasi |
| :--- | :--- | :--- |
| **Kegagalan Koneksi Database MySQL saat Bootstrapping** | WordPress masuk ke error db connection | Health check polling pada database container sebelum menjalankan WP-CLI |
| **Plugin / Theme Rusak atau Tidak Kompatibel** | Fatal error WSOD (White Screen of Death) | Validasi pra-ekstraksi dan isolasi instalasi via sandbox WP-CLI dengan opsi rollback |
| **Port Collision pada Multi-Container WordPress** | Service gagal start atau bentrok port | Alokasi port dinamis via `port_pool.go` dengan pre-flight availability check |
| **Kebocoran Kredensial Admin WordPress** | Risiko pengambilalihan akun web | Enkripsi AES-256-GCM pada level at-rest dan zero-leakage masking pada DTO |
| **Integritas Database Pasca-Migrasi 000018** | Kerusakan data historis Sprint 1–12 | Skema migrasi 000018 murni aditif non-destruktif dengan verifikasi 100% data retention |
