# Cuan Sprint 41 — Dedicated Schedules Hub, Agent Automation Trigger, and Settings & Account Menu Polish

## Rekomendasi untuk PO (diajukan SM)

**Rekomendasi:** Setujui scope Sprint 41 untuk membangun pusat otomasi tugas terjadwal (*Schedules Hub*) terpadu serta merapikan struktur menu Pengaturan dan navigasi dropdown akun (*NavUser*). Sprint ini mencakup 4 pilar:
1. **Dedicated Schedules Hub**: Halaman khusus (`/schedules` & `/settings/schedules`) bagi pengguna non-developer untuk melihat, mengaktifkan/menjeda, dan memicu eksekusi tugas background agen secara visual.
2. **Persistent Scheduled Tasks API & Engine**: Dukungan penyimpanan persisten tugas terjadwal yang dibuat oleh pengguna atau agen melalui chat Studio, dengan interval ramah manusia (*human-friendly*).
3. **Pembersihan & Penataan Ulang `SettingsView`**: Menghilangkan kartu-kartu duplikat di tab *General* (kontak dan agen yang sudah punya tab mandiri) dan menambahkan tab *Schedules*.
4. **Perapian Dropdown Akun (`NavUser`)**: Pengelompokan logis antara Alur Kerja Otomasi (*Schedules, Contacts*) dan Preferensi Akun (*Settings, Profile, Keyboard*).

**Alasan:** Pengguna bisnis non-developer memerlukan transparansi terhadap apa yang dikerjakan agen Cuan secara otonom di belakang layar. Selain itu, perapian navigasi menghilangkan kebingungan (*cognitive load*) akibat kartu-kartu redundan di halaman Pengaturan.

## Rincian Scope & Deliverables

### 1. S41.1 — Persistent Scheduled Tasks Engine & REST API (Backend)
- Perluasan paket `internal/scheduler` untuk mendukung tugas pengguna (`ScheduledTask`):
  - Model: `id`, `title`, `prompt`, `project_id`, `schedule_type`, `time_of_day`, `day_of_week`, `enabled`, `next_run_at`, `last_run_at`, `last_status`.
  - Penyimpanan persisten di berkas aman `data/scheduled_tasks.json`.
  - Endpoints REST API:
    - `GET /api/system/scheduler/tasks`: Daftar semua tugas terjadwal pengguna.
    - `POST /api/system/scheduler/tasks`: Membuat tugas terjadwal baru (bisa dipanggil UI atau alat agen).
    - `DELETE /api/system/scheduler/tasks/{id}`: Menghapus tugas terjadwal.
    - `PATCH /api/system/scheduler/tasks/{id}/toggle`: Menjeda atau mengaktifkan kembali tugas.
    - `POST /api/system/scheduler/tasks/{id}/trigger`: Menjalankan tugas secara instan (*on-demand*).
