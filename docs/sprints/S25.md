### 3. Dependency, Risiko & Mitigasi
* **Dependency:** Ketersediaan binary `agy` di host VPS untuk menangani interaksi stdin/stdout pada proses login.
* **Risiko 1 (Timeout pada Proses OAuth):** User membutuhkan waktu untuk membuka browser dan login ke akun Google.
  * *Mitigasi:* Backend `StartAntigravityAuthSession` sudah dirancang asynchronous dengan channel timeout 15 detik untuk mendapatkan auth URL, dan sesi auth disimpan di memory hingga user menempelkan kode otorisasi.
* **Risiko 2 (Regresi Database):** Perubahan UI ke List View berpotensi memengaruhi filter query task.
  * *Mitigasi:* Menggunakan endpoint REST `/api/v1/tasks` yang sudah ada tanpa mengubah skema tabel (strictly 19 PostgreSQL migrations intact).
