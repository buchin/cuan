# Sprint S28

## T2 — Subscription and BYOK connection lifecycle UX

Outcome: Team/Settings lets users understand and control subscription and BYOK connections without exposing secrets or terminal setup.

Scope: factual connected/login required/invalid/quota/unavailable states with timestamps; reconnect, cancel/retry, disconnect, delete, and BYOK replacement; reload and repeated-click idempotency; 360/390 responsive accessibility; targeted lifecycle tests and user documentation.

Dependency: T1 provider abstraction is complete. T2 precedes T3 routing polish.

Gates: targeted web and server tests, build, responsive/accessibility evidence, and no plaintext credential or subscription terminal instructions.

Out of scope: provider billing changes, new providers, credential migration, and T3 routing policy.
