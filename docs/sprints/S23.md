## 1. Sprint Goal dan Demo Outcome

### Sprint Goal
Mengadopsi penuh arsitektur Fural BYO Agent ke dalam platform Cuan:
1. Menyederhanakan modal tambah agen (hanya pilih Harness + input nama `@handle` + connect session).
2. Mengeliminasi konsep peran kaku (CS Toko, Admin, dll.) dari penyimpanan profil agen. Agen murni didefinisikan oleh Nama (`@handle`), Harness (`agy`, `claude`, `codex`, `custom`), dan Sesi Koneksi.
3. Agen merespons secara dinamis sesuai konteks pesan obrolan (bertindak sebagai **Scrum Master** saat diajak koordinasi sprint/planning/review/evaluasi/DoD; bertindak sebagai **Developer** saat diajak ngoding/teknis/fix bug; ramah dan natural saat sapaan umum).
4. Mengintegrasikan eksekusi task PTY runner dengan akun BYO Agent yang dipilih serta menampilkan avatar dan status eksekusi secara konsisten.
5. Menjamin zero database migration regression (strictly 19 PostgreSQL migrations intact), deploy ke VPS `cuan.dojo.cc`, dan menyusun panduan operasional lengkap dengan diagram D2 TALA.

### Demo Outcome
1. **Fural-Style Agent Registry & Backend API (S23.1):**
   - Entitas agen dan DTO distandarisasi ke format Fural: `{ id, name, harness, connection_id, enabled }`.
   - REST endpoints: `GET /api/v1/agents`, `POST /api/v1/agents`, `GET /api/v1/agents/{id}`, `PATCH /api/v1/agents/{id}`, `DELETE /api/v1/agents/{id}`.
   - Unit tests pass 100%. Audit evidence di `docs/sprints/evidence/S23/s23_1_agent_registry_verified.txt`.
2. **Fural-Style Add Agent Modal UI (S23.2):**
   - Modal Tambah Agen di `web/src/features/team/TeamView.tsx` disederhanakan:
     * Pilihan Harness: Antigravity (`agy`), Claude (`claude`), Codex (`codex`), Custom Model (`custom`).
     * Input field Agent Name: mention handle dengan prefix `@` dan auto-sanitasi.
     * Panel status sesi akun / API Key jika custom model.
     * Menghapus dropdown pilihan peran bisnis kaku.
   - Frontend build pass (0 TypeScript/Vite error). Audit evidence di `docs/sprints/evidence/S23/s23_2_fural_style_add_modal_verified.txt`.
3. **Dynamic Chat Role & Contextual Prompt Dispatcher (S23.3):**
   - Context classifier dan prompt dispatcher di `internal/server/chat_handlers.go`.
   - Saat agen di-mention (`@handle`) atau diajak chat di kamarnya:
     * Konteks koordinasi sprint / planning / review / evaluasi / DoD -> Persona **Scrum Master**.
     * Konteks instruksi teknis / ngoding / bugfix / endpoint / test -> Persona **Developer**.
     * Sapaan umum / casual greeting -> Persona **Friendly & Natural**.
   - Unit tests pass 100%. Audit evidence di `docs/sprints/evidence/S23/s23_3_dynamic_chat_roles_verified.txt`.
4. **BYO Agent Task Runner Integration (S23.4):**
   - Menghubungkan pemilihan agen di Papan Tasks dan Task SidePeek dengan binary runner PTY sesuai harness agen (`agy`, `claude`, `codex`, atau interactive shell).
   - Menampilkan avatar bot, handle agen, dan status eksekusi (`running` dengan pulse hijau, `completed`, `failed`, `idle`) secara konsisten.
   - Audit evidence di `docs/sprints/evidence/S23/s23_4_byo_runner_integration_verified.txt`.
5. **Staging Drill, Zero DB Regression & VPS cuan.dojo.cc Deployment (S23.5):**
   - Staging automated drill pada port 8081.
   - Strictly 19 migrasi database PostgreSQL utuh (0 migrasi baru).
   - Build frontend bundle & binary Go, rilis ke host VPS `cuan.dojo.cc`, restart service `cuan.service`, dan lolos smoke test.
