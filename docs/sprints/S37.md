# Cuan Sprint 37 — Context-Aware Project Routing & Dynamic Room Binding

## Rekomendasi untuk PO (diajukan SM)

**Rekomendasi:** Approve scope S37 — mengimplementasikan *Context-Aware Project Routing* cerdas di mana opsi `Auto` / `Otomatis` tidak lagi kaku terpaku pada `default` project, melainkan secara cerdas mendeteksi project target dari konteks pesan/goal obrolan pengguna (mencocokkan nama project, ID, repo name, atau variasi normalisasi kata), mengikat obrolan room ke project yang tepat secara langsung, serta meng-update room binding secara dinamis ketika delegasi task yang disetujui mengarah ke workspace project tertentu.

**Alasan:** PO secara visioner mengusulkan: *"Auto nggak harus default project tapi bergantung konteks obrolan, ide bagus ga? -> Gas"*. Langkah ini mengangkat kapabilitas Cuan menjadi Asisten AI Proaktif Sejati yang menghilangkan beban pikiran non-developer untuk memilih folder/repo sebelum berbicara.

## Log Eksekusi & Hasil Pengujian

1. **Mesin Contextual Project Matching ([`internal/server/inbox_project.go`](file:///home/dev/repos/cuan/internal/server/inbox_project.go)):**
   - Menambahkan fungsi `resolveContextualProject(ctx, text)` yang mencocokkan teks pesan/goal dengan repositori project aktif (mengabaikan `default` dan project terarsip).
   - Mendukung pencocokan nama project normal (*case-insensitive*), ID project, nama repository GitHub, serta variasi pemisah kata tanda hubung dan spasi (misal `"toko-sepatu"` vs `"toko sepatu"`).
   - Bila terdeteksi tepat 1 project non-default yang cocok secara tanpa keraguan (*unambiguous*), sistem langsung mengembalikan ID project tersebut.

2. **Integrasi Studio Goal Submission ([`internal/server/studio.go`](file:///home/dev/repos/cuan/internal/server/studio.go)):**
   - Saat request goal studio diterima dengan `project_id: ""` (mode Otomatis), server memanggil `resolveContextualProject(ctx, req.Goal)`.
   - Jika konteks goal menyebut project tertentu, percakapan room Studio langsung diikat ke project tersebut sejak turn pertama, sehingga analisis arsitektur dan git log langsung relevan.
   - Jika goal bersifat umum / tidak menyebut project spesifik, fallback tetap aman ke project default.

3. **Dynamic Room Binding on Delegation ([`internal/server/inbox_delegation.go`](file:///home/dev/repos/cuan/internal/server/inbox_delegation.go) & [`internal/db/project_studio.go`](file:///home/dev/repos/cuan/internal/db/project_studio.go)):**
   - Menambahkan kapabilitas pembaharuan `project_id` pada method `UpdateRoom` baik di SQL database maupun Memory repository.
   - Ketika rencana pengerjaan didelegasikan ke project tertentu (`d.ProjectID != "default"`), status `room.ProjectID` yang sebelumnya `"default"` otomatis di-upgrade dan disimpan ke target project yang disetujui.

4. **Pengujian & Validasi:**
   - Menambahkan unit test backend integrasi [`TestStudioGoalContextAwareProjectRouting`](file:///home/dev/repos/cuan/internal/server/studio_test.go#L89-L119) yang memvalidasi bahwa pengiriman goal dengan teks kontekstual otomatis mengikat room ke ID project yang relevan meskipun parameter `project_id` dikirim kosong (Auto).
