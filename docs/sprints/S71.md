## 1. Ringkasan Eksekutif & Sasaran Sprint 71

Sprint 71 mengeksekusi penyelarasan antarmuka dan kestabilan runtime pada fitur **Project Terminal** di Cuan web app sesuai mandat dan persetujuan PO Mas Buchin:

1. **Auto-Launch Interactive Agent CLI (Backend & PTY):**
   - Menggantikan default `/bin/bash` login shell mentah pada terminal project dengan auto-detection harness agent aktif (`agy`, `commandcode`, `claude`).
   - Terminal PTY langsung menjalankan CLI agent interaktif di workspace project (`--dangerously-skip-permissions --prompt-interactive`) dengan fallback aman ke shell standar jika harness belum terpasang.

2. **Inbox-Parity Terminal Composer (Frontend):**
   - Menyelaraskan tampilan composer terminal 1:1 dengan kapsul composer Inbox yang bersih, ergonomis, dan tenang.
   - Menggunakan token, radius, padding, dan struktur kapsul yang sama (`wa-input-capsule`, `Composer`, `ComposerAccessory`, `ComposerSendButton`).
   - Mengeliminasi tombol Stop/Ban (`Ban` icon) merah yang mengotori kapsul input teks; memindahkan aksi interrupt/stop ke header atau floating action non-invasif.
   - Textarea auto-expanding yang halus dan tombol kirim responsif sesuai standar visual Inbox.

3. **Zero Layout Shift (CLS) & Notice Stabilization:**
   - Memindahkan notice *"Menyambungkan ulang. Input yang belum terkirim menunggu sesi terminal ini."* dari dalam alur DOM vertikal terminal ke header status / floating status indicator.
   - Mencegah pergeseran tinggi (naik-turun) kanvas terminal xterm saat WebSocket reconnecting.
   - Mempertahankan buffer layar terminal saat reconnect ke sesi yang sama (`sameSession`) agar riwayat teks tidak hilang misterius akibat `t.reset()`.

4. **Pembersihan False Warning Status:**
   - Menyembunyikan banner merah *"Session needs attention"* saat sesi terminal berstatus aktif (`running`), menjaga fokus dan ketenangan operator.

## 4. Batasan & Risiko
* **Binary Discovery:** Binary agent (`agy`, `commandcode`) berada di PATH host atau direktori instalasi user (`~/.local/bin`, `/usr/local/bin`); resolver wajib mencari di lokasi-lokasi standar sebelum fallback.
* **Non-Destructive Worktree:** Sesi terminal tidak boleh mengubah uncommitted changes atau merusak git status repo.
