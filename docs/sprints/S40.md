# Cuan Sprint 40 — OSS Extensibility & Automation: In-Process Job Scheduler, Non-Developer Update Mechanism, and MCP / Skills Architecture

## Rekomendasi untuk PO (diajukan SM)

**Rekomendasi:** Setujui scope Sprint 40 untuk mempersiapkan fondasi Cuan menuju rilis Open Source Software (OSS) yang ramah bagi pengguna non-developer. Sprint ini membangun tiga kapabilitas esensial:
1. **In-Process Job Scheduler**: Mesin penjadwalan terisolasi di backend Go untuk eksekusi tugas background berulang (pemeliharaan sistem & tugas rutin bisnis/agent).
2. **Mekanisme Update Ramah Non-Developer**: Endpoint inspeksi versi dan antarmuka UI di Pengaturan untuk mengecek rilis terbaru dengan opsi pembaruan otomatis malam hari (*nightly auto-update*).
3. **Fondasi Arsitektur Ekstensibilitas (Skills & MCP)**: Model domain dan spesifikasi integrasi untuk mendukung custom Skills (prompt & script domain) serta Model Context Protocol (MCP) Client untuk koneksi instan ke ekosistem eksternal seperti `tebar.app`.

**Alasan:** Sebagai aplikasi yang ditujukan untuk non-developer, Cuan yang dirilis secara self-hosted OSS tidak boleh menuntut penggunanya memahami terminal, Git, cron syntax, atau migrasi manual. Seluruh pembaruan, otomatisasi rutin, dan ekspansi alat (via MCP & Skills) harus dapat dikelola secara intuitif melalui antarmuka web Cuan.

## Rincian Scope & Deliverables

### 1. S40.1 — In-Process Job Scheduler & Cron Engine (Backend)
- **Paket `internal/scheduler`**:
  - Implementasi scheduler ringan in-process di Go yang hidup berdampingan dengan siklus hidup HTTP server.
  - Mendukung interval ramah manusia (*human-friendly intervals*):
    - Harian pada jam tertentu (misal: "03:00").
    - Mingguan pada hari tertentu (misal: "Senin 09:00").
    - Interval berkala (misal: tiap 30 menit).
  - Isolasi eksekusi dengan `panic recovery`, context timeout terikat, dan pencatatan riwayat eksekusi (`last_run_at`, `last_status`, `error_message`).
  - Job bawaan pertama: `system_update_check` (memeriksa pembaruan aplikasi secara berkala).

### 2. S40.2 — Non-Developer App Update Mechanism (Backend & UI)
- **Backend API (`/api/system/update`)**:
  - `GET /api/system/update`: Mengembalikan informasi versi aktif (`version`, `commit_sha`), ketersediaan rilis baru, catatan rilis (*release notes*), preferensi `auto_update_enabled`, dan `auto_update_time`.
  - `POST /api/system/update/check`: Memicu pengecekan rilis terbaru secara langsung (*on-demand*).
  - `PATCH /api/system/update/settings`: Menyimpan preferensi pembaruan otomatis malam hari (*nightly auto-update*).
- **Frontend UI (Settings > General / Pembaruan)**:
  - Kartu "Pembaruan Aplikasi" (*App Update Card*):
    - Badge versi aktif (misal: `v0.1.0 (dev)`).
    - Tombol "Periksa Pembaruan" (*Check for Updates*) dengan feedback status visual.
    - Sakelar/Toggle: "Pembaruan Otomatis Malam Hari (03:00 WIB)".

### 3. S40.3 — Human-Friendly Scheduled Tasks Management (Frontend)
- **Komponen UI Tugas Terjadwal**:
  - Tampilan visual untuk mengelola rutinitas agent tanpa sintaks cron yang rumit.
  - Dropdown frekuensi: *Harian* / *Mingguan*, pemilih jam yang ramah sentuh (*touch-friendly*).
  - Menghubungkan instruksi rutin agent dengan proyek aktif.

### 4. S40.4 — Arsitektur & Spesifikasi Ekstensibilitas (Skills & MCP Client)
- **Paket & Dokumentasi Domain (`internal/mcp` & Panduan Integrasi)**:
  - Definisi interface MCP Client untuk menghubungkan alat pihak ketiga (seperti `tebar.app` untuk WhatsApp/CRM).
  - Format spesifikasi Skills modular (instruksi markdown + metadata tools).
  - Dokumen panduan: `docs/product/mcp-and-skills-integration.md`.

### 5. S40.5 — Test Suite Gates & Dogfooding Deployment ke `cuan.dojo.cc`
- 100% backend unit test lulus (`go test ./...`).
- 100% frontend test suite lulus (`npm test --prefix web`).
- Build bersih Vite tanpa warning.
- Deploy live ke `cuan.dojo.cc` via `./scripts/deploy.sh` di branch `dev`.
