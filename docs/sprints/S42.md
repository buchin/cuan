# Cuan Sprint 42 — Rebranding Studio ke Chat & Multi-Domain cuan.chat Support

## Outcome Sprint & Rekomendasi untuk PO

**Outcome:** Menghadirkan pengalaman interaksi yang lebih intuitif dan ramah bagi pengguna non-developer dengan mengganti terminologi teknis "Studio" menjadi "Chat" di seluruh antarmuka web Cuan, menyediakan routing `/chat` dengan backward compatibility penuh dari `/studio`, serta menambahkan dukungan konfigurasi multi-domain `cuan.chat` berdampingan dengan `cuan.dojo.cc` pada reverse proxy Caddy dan environment.

**Rekomendasi (diajukan SM):** Setujui backlog Sprint 42 yang mencakup 4 pilar terukur:
1. **S42-T1: Sync Repo & Sprint Doc (S42.md)**: Sinkronisasi git dengan `origin/dev`, inisiasi branch `feature/rename-studio-to-chat`, dan penetapan single source of truth di `docs/sprints/S42.md`.
2. **S42-T2: Rename Studio ke Chat & Route Backward Compatibility**: Pembaruan label UI (sidebar, header, breadcrumbs, document title) menjadi "Chat", pendaftaran route `/chat`, dan penanganan redirect `/studio` ke `/chat`.
3. **S42-T3: Dukungan Domain cuan.chat di Caddyfile & Env**: Penambahan blok domain `cuan.chat` di Caddyfile dan pembaruan berkas template konfigurasi environment.
4. **S42-T4: Quality Gate, Merge ke dev & Deploy**: Eksekusi targeted automated test suite (Go & React), merge branch feature ke `dev`, push ke origin, eksekusi `./scripts/deploy.sh`, dan live smoke test.

---

## Target Market Fit & Value Proposition

- **Target Market**: Pemilik bisnis UMKM, tim operasional non-developer, dan profesional non-teknis yang mengandalkan asisten otonom Cuan untuk mengelola alur kerja, otomasi, dan tugas bisnis.
- **Mengapa Target Market Menyukai Hasil Sprint Ini?**:
  1. **Mengurangi Cognitive Load & Zero Learning Curve**: Kata "Studio" cenderung diasosiasikan dengan IDE pengembangan perangkat lunak, audio/video editing, atau tooling teknis rumit. Kata "Chat" langsung dipahami oleh siapa pun sebagai tempat berdialog, memberi instruksi, dan berkolaborasi bersama agen AI.
  2. **Identitas Domain Relevan & Profesional (`cuan.chat`)**: Memudahkan pengguna mengakses aplikasi secara langsung melalui domain yang deskriptif dan mudah diingat.
  3. **Zero Friction & Backward Compatibility**: Pengguna lama yang menyimpan bookmark URL `/studio` atau menggunakan tautan tersimpan tidak akan mengalami broken link (404), melainkan otomatis dialihkan ke `/chat` secara transparan. Domain eksisting `cuan.dojo.cc` tetap aktif berdampingan tanpa gangguan.

## Quality Gate & Deployment Gates

1. **Automated Testing Gate**:
   - Backend: Targeted unit test `go test ./...` dipastikan 100% PASS.
   - Frontend: `npm test --prefix web` dipastikan 100% PASS.
   - Build Gate: `npm run build --prefix web` sukses tanpa TypeScript compilation error.
2. **Reverse Proxy Syntax Gate**:
   - Konfigurasi `Caddyfile` diperiksa dan dipastikan valid sebelum deployment.
3. **Deployment Gate (Branch & Production Guardrail)**:
   - Sesuai kebijakan `./scripts/deploy.sh`, deployment dilarang keras dijalankan langsung dari temporary working branch (`feature/*`).
   - Seluruh perubahan wajib di-merge ke branch `dev` dan disinkronkan dengan `origin/dev` sebelum eksekusi deployment.
   - Deployment dijalankan menggunakan `./scripts/deploy.sh` yang menerapkan atomic release payload, checksum validation, dan live `/healthz` commit verification.

- **Tidak Mengubah Core AI Reasoning / Backend Handlers**: Alur orkestrasinya tetap stabil; perubahan berfokus pada visual UI, client routing, dan ingress domain.
- **Tidak Ada Migrasi Skema Database**: Sprint 42 tidak memerlukan penambahan tabel atau perubahan kolom pada PostgreSQL (`000029_...` tetap skema terkini).
- **Tidak Mematikan Domain `cuan.dojo.cc`**: Domain lama tetap aktif dan dilayani penuh secara simultan.
- **Tidak Menghapus Komponen Fungsional Obrolan**: Fitur obrolan, eksekusi tugas, lampiran, dan riwayat obrolan tetap utuh, hanya representasi label dan URL default yang diperbarui dari Studio ke Chat.
