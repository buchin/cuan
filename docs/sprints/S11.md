## Sprint goal dan demo outcome

### Sprint Goal
Mengembangkan Cuan menjadi **"Modular Workspace OS"** yang fleksibel dan zero-friction, sekaligus membuka pintu pasar masif bagi pengguna/kreator yang membeli script/source code online namun kesulitan menginstal, mengonfigurasi, dan men-deploy:
1. **AI Script Onboarding (New Project from ZIP):** Pengguna cukup mengunggah file `.zip` script (misal dibeli dari CodeCanyon/Envato/GitHub). AI Inspector secara otomatis menganalisis berkas, mendeteksi tech stack (Laravel, Node, Python, dsb.), mengekstrak konfigurasi `.env`, mendeteksi skema database `.sql`, dan menghasilkan task setup pipeline di Kanban yang didampingi agen.
2. **Modular Workspace OS & Dynamic Navigation:** Tiap project memiliki menu navigasi dan sidebar dinamis sesuai modul yang aktif (`enabled_modules`), bebas dari UI bloatware. Modul dapat diaktifkan/dinonaktifkan kapan saja melalui modal *Add Modules* / Project Settings.
3. **Creator Publishing Hub (CMS Publishing Engine & Teleprompter):** Draft konten hasil kerja agen di Task Kanban dapat langsung dipublikasikan ke WordPress REST API (status draft/publish) dengan 1-klik, serta diekspor ke berbagai format atau dibaca langsung pada layar Teleprompter fullscreen untuk produksi video.
4. **Sinkronisasi Dokumen SSOT & Panduan Mandiri:** Menjaga kejelasan visi produk di `docs/product-vision.md`, `README.md`, dan menyusun panduan operasional mandiri di `docs/guides/modular_and_zip_onboarding_guide.md` berstandar diagram D2 TALA.

### Demo Outcome
1. Pengguna membuka Studio Dashboard dan memilih opsi **"New Project from ZIP"**.
2. Pengguna men-drag-and-drop file ZIP berisi script web application (misal: script Laravel atau Node.js) ke dalam dropzone.
3. Backend AI Inspector mengekstrak ZIP di sandbox terisolasi (terproteksi zip-slip), menganalisis signature file, mengekstrak variabel `.env.example`, dan mendeteksi kebutuhan skema database `.sql`.
4. Cuan secara atomik membuat Project baru bertipe `source_type: "zip"` dengan modul yang relevan aktif (`tasks`, `discussions`, `servers`, `repos`), serta menyusun setup pipeline otomatis pada Kanban board.
5. Sidebar dan Navbar Cuan secara reaktif beradaptasi menampilkan hanya menu modul yang aktif untuk project tersebut.
6. Pada task drafting konten (misal di project Blog), pengguna memilih opsi **Publish to WordPress**, memasukkan Application Password terenkripsi AES-256-GCM, dan menekan **Publish** — draft artikel langsung terbit di website WordPress tujuan dengan zero credential leakage.
7. Pada task skrip video, pengguna menekan tombol **Teleprompter View**, membuka modal fullscreen dengan auto-scroll kecepatan terkontrol untuk rekaman video tanpa hambatan.
8. Verifikasi staging drill (port 8081) dan live rilis produksi di `cuan.dojo.cc` membuktikan seluruh alur berjalan mulus dengan 100% data retention Sprint 1–10 utuh.

## Target market dan pertimbangan kepuasan DoD (§4)

### Persona Target Market
1. **Pembeli Script Online / Solopreneur Non-Tech:** Sering membeli script web/aplikasi di CodeCanyon, Envato, atau GitHub marketplace, namun script mengendap di hard disk karena bingung cara setup environment `.env`, impor database `.sql`, memasang dependencies (`composer`/`npm`), dan deploy ke VPS. Mereka membutuhkan asisten AI yang membedah file ZIP dan menyusun langkah instalasi terpandu.
2. **Kreator Konten & Blogger (Multi-CMS Publishers):** Mengelola blog WordPress mandiri. Membutuhkan alur kerja tanpa friksi di mana artikel hasil generate agen AI langsung dikirim ke WordPress REST API sebagai draft tanpa copy-paste manual.
3. **Video Creators & YouTubers:** Membutuhkan kemudahan membaca naskah hasil generate agen secara langsung di antarmuka Studio dengan fitur Teleprompter yang responsif saat proses perekaman video.
4. **SaaS Builders & Micro-Agency Owners:** Mengelola portofolio proyek beragam (beberapa butuh server & repo, beberapa hanya butuh task & diskusi). Membutuhkan antarmuka modular yang bersih tanpa menu yang tidak relevan.

### Pertimbangan Kepuasan Target Market (DoD Focus)
- **Zero-Friction Script Onboarding:** Drop file ZIP langsung menghasilkan project terstruktur dan panduan instalasi konkret.
- **Dynamic & Clean Workspace:** Sidebar adaptif menghilangkan distraction dan UI clutter.
- **Secure 1-Click Publishing:** Integrasi CMS aman dengan enkripsi AES-256-GCM untuk kredensial Application Password WordPress.
- **Strict Data Retention (100% Data Integrity):** Skema database murni aditif non-destruktif; seluruh data dari Sprint 1 hingga Sprint 10 tetap 100% utuh tanpa regresi.

## Detail backlog tasks (S11.1 - S11.5)

### S11.1 — Database Migration 000016, Modular Workspace Models, Dynamic Modules & SSOT Alignment
- **Scope:**
  - Migrasi database 000016 (`000016_modular_workspaces_and_publishing.up.sql` dan `down.sql`):
    - Kolom baru pada tabel `projects`:
      - `enabled_modules JSONB NOT NULL DEFAULT '["tasks", "discussions"]'::jsonb`
      - `source_type VARCHAR(64) NOT NULL DEFAULT 'blank'` (pilihan: `blank`, `template`, `zip`)
      - `source_metadata JSONB NOT NULL DEFAULT '{}'::jsonb`
    - Tabel baru `project_integrations` (`id VARCHAR(64) PRIMARY KEY`, `project_id VARCHAR(64) NOT NULL REFERENCES projects(id) ON DELETE CASCADE`, `integration_type VARCHAR(64) NOT NULL`, `config_encrypted TEXT NOT NULL DEFAULT ''`, `status VARCHAR(32) NOT NULL DEFAULT 'active'`, `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`).
    - Kolom baru pada tabel `project_tasks`:
      - `scheduled_at TIMESTAMP WITH TIME ZONE NULL`
      - `published_at TIMESTAMP WITH TIME ZONE NULL`

## Ketergantungan dan risiko

| Risiko | Dampak | Respons / Mitigasi |
| --- | --- | --- |
| Zip Slip / Malicious ZIP File | Potensi overwrite file sistem di luar workspace | Sanitasi jalur relatif berkas (`filepath.Clean`) dan kuota ekstraksi (maks 150MB) |
| Script Tanpa Dokumentasi Jelas | AI gagal mendeteksi stack atau konfigurasi `.env` | Heuristik scanning bertingkat dan AI fallback prompt yang memindai struktur direktori |
| WordPress REST API Timeout / Bad Credentials | Kegagalan publikasi konten ke WordPress | Validasi koneksi pre-flight, feedback error deskriptif, dan isolasi token via AES-256-GCM |
| Integritas Database Pasca-Migrasi | Kerusakan data dari Sprint terdahulu | Skema migrasi 000016 murni aditif non-destruktif dengan nilai default aman untuk menjamin 100% data Sprint 1–10 |
