## Sprint goal dan demo outcome

### Sprint Goal
Mewujudkan pengalaman rekayasa perangkat lunak mandiri (*pure in-browser cloud development*) pada Cuan dengan mengintegrasikan ekosistem **Native Agent Hub** dan **In-Browser Interactive Terminal (PTY)**:
1. Mengimplementasikan skema database migrasi 000014 (`agents`, `agent_connections`) dengan retensi data 100% utuh dari Sprint 1–8.
2. Membangun model entitas Go, DTO tersanitasi (*zero credential leakage*), interface repositori, implementasi PostgreSQL dan thread-safe in-memory store.
3. Mengembangkan engine koneksi akun AI (Google Gemini Pro OAuth web-flow & API key) dengan enkripsi credentials di server Cuan tanpa perlu konfigurasi terminal lokal.
4. Mengembangkan WebSocket Pseudo-Terminal Engine (`/api/tasks/{id}/terminal`) berbasis `github.com/creack/pty` yang menghubungkan workspace Git task langsung ke stream terminal interaktif di browser (Watch Mode & Interactive Take-Over Mode).
5. Menghadirkan antarmuka visual Agents Hub (`/studio/agents`) dan Task Terminal (`TaskTerminal.tsx` berbasis `@xterm/xterm` + addon-fit) di Web UI.
6. Melaksanakan staging E2E drill pembuktian nyata "Develop Cuan Pake Cuan 100% In-Browser" dari pembuatan task, penugasan agent, hingga intervensi terminal langsung, serta rilis stabil di `cuan.dojo.cc`.

### Demo Outcome
1. Pengguna membuka Studio Dashboard dan mengakses tab baru "Agents" (`/studio/agents`).
2. Pengguna menghubungkan akun Google Gemini Pro via web form (API key/OAuth) yang tersimpan terenkripsi di server Cuan.
3. Pengguna mengonfigurasi persona agent (nama, avatar, role, system prompt, model selector).
4. Pengguna membuka Discussion Room dan menugaskan Agent ke suatu Task atau `@mention` agent dalam diskusi.
5. Pada kartu detail task di Kanban board, pengguna membuka modal Terminal (`TaskTerminal.tsx`).
6. Terminal menampilkan stream PTY real-time aktivitas pengerjaan kode oleh agent (*Watch Mode*).
7. Pengguna dapat langsung mengambil alih terminal (*Interactive Take-Over Mode*) dengan mengetikkan perintah shell (misal: `ls -la`, `git status`, `go test ./...`) langsung dari keyboard browser ke workspace Git task.
8. Staging drill dan rilis produksi di `cuan.dojo.cc` membuktikan seluruh alur berjalan mulus dengan 100% data retention Sprint 1–8 utuh.

## Target pengguna dan nilai produk

### Persona Target Market
1. **Solo Developer & Indie Hackers:** Mengembangkan dan mengelola aplikasi dari perangkat apa saja (laptop, tablet, iPad, Chromebook) tanpa perlu menyiapkan environment lokal yang rumit.
2. **AI-Assisted Engineering Teams:** Berkolaborasi langsung dengan agen AI di mana agen mengeksekusi perintah shell dan developer dapat memantau atau mengintervensi seketika.
3. **Multi-Project Operators:** Menguji perubahan kode atau debugging langsung di terminal task terisolasi tanpa khawatir merusak workspace proyek lain.

### Pertimbangan Kepuasan Target Market (DoD Focus)
- **Zero Local Client Footprint:** Tidak perlu clone repo ke laptop, install Go compiler, install database, atau setup SSH key manual. Semua pengerjaan dan intervensi terminal bisa dilakukan 100% di browser.
- **Zero Credential Leakage:** API key LLM tersimpan aman terenkripsi di server; DTO tidak pernah membocorkan kredensial ke frontend (`has_credentials` boolean flag).
- **Fluid Low-Latency PTY Terminal:** Terminal xterm.js responsif dengan resize support via WebSocket binary/text frame.
- **100% Data Retention Guarantee:** Skema database murni aditif non-destruktif; seluruh data dari Sprint 1 hingga Sprint 8 tetap utuh.

## Fondasi teknis dan arsitektur

- **Backend:** Go (Golang) menggunakan router `chi/v5`, `gorilla/websocket`, `creack/pty`, dan `database/sql` PostgreSQL 16.
- **Database Schema (`migrations/000014_agent_hub_terminal.up.sql`):**
  - Tabel `agents`:
    - `id VARCHAR(64) PRIMARY KEY`
    - `name VARCHAR(255) NOT NULL`
    - `avatar VARCHAR(512) NOT NULL DEFAULT ''`
    - `role VARCHAR(128) NOT NULL DEFAULT ''`
    - `system_prompt TEXT NOT NULL DEFAULT ''`
    - `model_id VARCHAR(128) NOT NULL DEFAULT 'gemini-1.5-pro'`
    - `provider VARCHAR(64) NOT NULL DEFAULT 'google'`
    - `status VARCHAR(64) NOT NULL DEFAULT 'active'`
    - `created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
    - `updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
    - Indeks pada `(status)`, `(provider)`.
  - Tabel `agent_connections`:
    - `id VARCHAR(64) PRIMARY KEY`
    - `user_id VARCHAR(64) NOT NULL`
    - `provider VARCHAR(64) NOT NULL DEFAULT 'google'`
    - `credentials_encrypted TEXT NOT NULL DEFAULT ''`
    - `plan_hint VARCHAR(128) NOT NULL DEFAULT ''`
    - `status VARCHAR(64) NOT NULL DEFAULT 'active'`
    - `created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
    - `updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
    - Indeks pada `(user_id)`, `(provider)`.
- **Repository Layer (`internal/db/agent.go` & `internal/db/db.go`):**
  - Entitas `Agent`, `AgentConnection`, DTO `AgentDTO`, `AgentConnectionDTO`, DTO Inputs `CreateAgentInput`, `UpdateAgentInput`, `CreateAgentConnectionInput`, `UpdateAgentConnectionInput`, Filters `AgentFilter`, `AgentConnectionFilter`.
  - Interface `AgentRepository` dengan implementasi `SQLAgentRepository` dan thread-safe `MemoryAgentRepository`.
  - Registrasi terpusat pada container `db.Repositories` dan `server.Server`.
- **Auth & AI Connection Engine (`internal/agent/`):**
  - Google Gemini Pro API / OAuth token exchange, encrypted key vault storage, model selector, dan kuota health check.
- **PTY Terminal Engine (`internal/terminal/`):**
  - WebSocket handler `/api/tasks/{id}/terminal`, binding ke workspace Git per task, creack/pty process session management, input/output streaming, dan terminal window resize protocol.
- **Frontend Agents Hub & Terminal:** React + TypeScript + Tailwind CSS + shadcn/ui di `web/src/components/studio/` (`AgentHubView.tsx`, `AgentConnectionModal.tsx`, `TaskTerminal.tsx`).

## Out of scope eksplisit

- Multi-tenant terminal isolation via Docker container per connection (terminal diisolasi per proses worktree host OS tanpa overhead containerization berat).
- Editor code visual WYSIWYG Monaco Editor di browser (fokus pada terminal interaktif PTY + xterm.js yang mendukung editor terminal seperti nano/vim).
- Billing pay-per-token di dalam Cuan (kredensial API Gemini menggunakan kuota akun milik pengguna langsung via BYOK — Bring Your Own Key).

## Risiko dan respons

| Risiko | Dampak | Respons / Mitigasi |
| --- | --- | --- |
| Kebocoran API key Gemini Pro pengguna | Penyalahgunaan kuota atau pelanggaran keamanan | Enkripsi AES-256-GCM via KeyVault di sisi server; DTO tidak pernah memuat plaintext kredensial |
| Orphaned PTY processes pada host saat tab browser ditutup tiba-tiba | Resource leak (file descriptor & CPU/RAM) | Context timeout, heartbeat WebSocket berkala (15s), dan defer `pty.Close()` saat websocket disconnect |
| Konflik port WebSocket pada reverse proxy Caddy | Gagal koneksi WebSocket upgrade | Konfigurasi caddy router eksplisit untuk path `/api/tasks/*/terminal` dengan HTTP/1.1 WebSocket forwarding |
