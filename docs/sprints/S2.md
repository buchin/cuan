## Sprint goal dan demo outcome

### Sprint Goal
Membangun Landing Page framework PAS di root (`/`), integrasi Waiting List ke Dojo, Thank You bridge ke `/sponsor` (Pay-What-You-Want min Rp 10.000 via Dojo), Leaderboard Top Backers dinamis (`ORDER BY amount DESC, paid_at ASC`), Panel kurasi anti-judol bagi Owner di dashboard Cuan, serta sinkronisasi otomatis `README.md` repositori GitHub dan direktori publik `/sponsors`.

### Demo Outcome
1. Pengunjung non-login mengakses root `/`, membaca landing page beralur PAS (Problem - Agitation - Solution), lalu mendaftarkan email ke Waiting List.
2. Email tersimpan di PostgreSQL Cuan dan dikirim ke webhook/API Dojo untuk memicu autoresponder Welcome & Thank You Email.
3. Setelah submit, muncul Thank You state/modal yang menjembatani calon backer untuk menjadi Founding Sponsor di `/sponsor`.
4. Calon sponsor mengisi profil (Nama Brand, URL Website, Slogan, Logo, Kontak WA/Email), memilih nominal Pay-What-You-Want (min Rp 10.000), lalu dialihkan ke halaman checkout Dojo.
5. Dojo mengirimkan webhook sukses pembayaran ke `/api/webhooks/dojo`. Cuan memvalidasi secret webhook, memverifikasi idempotency `dojo_order_id`, dan mencatat sponsor dalam status `pending_review`.
6. Owner membuka dashboard `/admin/sponsors`, memeriksa detail brand dan preview logo. Owner mengeklik tombol **Approve** (atau **Reject** dengan alasan jika melanggar etika anti-judol).
7. Sponsor yang disetujui seketika tampil di Leaderboard live `/sponsor` (Top 5 lebih dominan) dan runner otomatis mensinkronisasikan seksi `## Backers & Sponsors` pada `README.md` repositori GitHub serta arsip direktori publik `/sponsors`.

## Target pengguna dan nilai produk

### Persona Target Market
1. **Solo Developer & Indie Hacker (Pengguna Potensial):** Ingin solusi deployment mandiri yang tidak ribet, mendukung WordPress dan ZIP upload tanpa cPanel/FTP, serta memiliki kepastian progress.
2. **Founding Backers & Sponsor (Pembeli/Donatur):** Founders, agensi, dan tech company lokal/global yang ingin mendukung kelangsungan open-source Cuan sembari mendapatkan exposure brand bernilai tinggi (link dofollow, logo di README GitHub, leaderboard permanen).

### Pertimbangan Kepuasan Target Market (DoD Focus)
- **Zero-Friction Intake:** Formulir sponsor tidak menuntut registrasi akun rumit; checkout terhubung langsung ke Dojo payment gateway lokal (QRIS, VA, E-Wallet).
- **Kepastian Posisi Leaderboard:** Aturan ranking transparan dan adil: nominal tertinggi di atas (`ORDER BY amount DESC`), dan jika nominal sama maka yang bayar lebih cepat mendapat posisi lebih tinggi (`paid_at ASC`).
- **Reputasi Brand Terjaga (Etika Anti-Judol Ketat):** Sponsor yang sah tidak mau logonya bersanding dengan situs judi online, pornografi, atau scam. Moderasi kurasi owner dan karantina status `pending_review` wajib 100% kedap kebocoran ke halaman publik.
- **Keamanan Aset (Anti-XSS SVG Sanitization):** Calon sponsor sering mengunggah logo SVG demi ketajaman visual. Sistem wajib membersihkan script berbahaya, event handler, dan link `javascript:` agar tidak membahayakan pengunjung atau owner.

## Fondasi teknis dan arsitektur

- **Backend:** Go (Golang) menggunakan `net/http` dan router `chi/v5`.
- **Database:** PostgreSQL dengan migrasi berversi non-destructive (`000007_sponsorship.up.sql`), menjaga 100% kompatibilitas data Sprint 1 (`owners`, `projects`, `tasks`, `task_attempts`, `agent_logs`).
- **Frontend:** React + Vite + TypeScript + Tailwind CSS + shadcn/ui.
- **Integrasi Payment:** Dojo Checkout PWYW (min Rp 10.000) dan Webhook Receiver `/api/webhooks/dojo`.
- **Keamanan Upload Logo:** Validasi MIME type biner (SVG, PNG, WebP maks 2MB), isolasi direktori `data/sponsors/logos/`, dan parser sanitasi SVG ketat anti-XSS.
- **Otomasi Git:** Helper sinkronisasi `README.md` dengan marker HTML idempotent `<!-- SPONSORS:START -->` dan `<!-- SPONSORS:END -->`, diautentikasi atas nama human author `Buchin <buchin@dropsugar.com>`.

## Risiko dan respons

| Risiko | Dampak | Respons / Mitigasi |
| --- | --- | --- |
| Sponsor judi online / pornografi menyusup lewat checkout | Reputasi Cuan dan sponsor sah rusak | Status default `pending_review`, tidak tampil di publik sebelum approved oleh Owner, klausul no-refund untuk pelanggaran etika |
| File SVG logo mengandung payload XSS (`<script>`, event handler) | Kompromi browser pengunjung atau owner | Parser sanitasi SVG ketat: hapus skrip, atribut `on*`, tag `<foreignObject>`, dan URI `javascript:` |
| Webhook Dojo diterima berulang kali (network retry) | Duplikasi record order atau status flapping | Idempotency guard di database via unique constraint `dojo_order_id` dan pengecekan state sebelum transisi |
| Migrasi database mengganggu tabel task/attempt Sprint 1 | Sistem down / data hilang | Migrasi bersifat murni aditif (`CREATE TABLE IF NOT EXISTS`), foreign key terisolasi, diuji pada staging sebelum stable |
| Sinkronisasi README merusak format markdown dokumen | Tampilan README GitHub berantakan | Marker komentar regex idempotent (`<!-- SPONSORS:START -->`) dengan unit test template markdown |
