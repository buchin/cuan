# Cuan Sprint 32 — Studio Agent Selector Modernization & Connection Expiry Bug Fix

## Rekomendasi untuk PO (diajukan SM)

**Rekomendasi:** Approve scope S32 di bawah ini — menyelesaikan akar masalah bug degradasi status agen AGY menjadi "Not checked" setiap 5 menit yang melumpuhkan seleksi agen di Studio, memodernisasi komponen pemilih agen di Studio menjadi *Compact Pill Selector* modern di dalam footer composer (sejajar dengan tombol lampiran), serta melengkapi opsi dengan badge peran yang ramah non-developer (Fast vs Deep Thinking) dan indikator status koneksi yang akurat.

**Alternatif:** Hanya menghapus baris pengecekan 5 menit di `connection.ts` tanpa merapikan UI Studio — bug fungsional teratasi tetapi tampilan Studio tetap kaku dengan dropdown `<select>` selebar layar yang merusak kesederhanaan landing page.

## Tujuan Sprint

1. **Fix Connection Expiry Bug (`web/src/features/agents/connection.ts`):**
   - Menghapus aturan artifisial degradasi 5 menit (`verified + 5 * 60_000 <= now`) yang secara keliru menurunkan status agen `verified` menjadi `unknown` ("Not checked").
   - Memastikan agen dengan kredensial aktif tetap berstatus `verified` (*Connected* / *Terhubung*) secara konsisten di seluruh antarmuka.
2. **Koreksi Aturan Seleksi Agen di Studio (`web/src/features/inbox/StudioView.tsx`):**
   - Menghapus pembatasan keliru `disabled={state.state !== 'verified' && agent.provider !== 'commandcode'}`.
   - Agen hanya boleh di-disable jika akunnya secara eksplisit nonaktif (`disabled`) atau belum pernah terhubung (`login_required`). Agen AGY dan provider lain yang aktif 100% dapat dipilih.
3. **Modernisasi UI/UX Studio Agent Selector:**
   - Menghapus dropdown form `<select>` selebar layar yang kaku di bawah textarea.
   - Mengintegrasikan pemilih agen sebagai tombol **Pill Selector kompak** di footer composer (berdampingan dengan tombol `AttachmentPicker`).
   - Menyertakan label peran yang manusiawi (misal: *⚡ Auto / Disarankan*, *🚀 Cepat*, *🧠 Penalaran Tinggi*) dan indikator visual (titik hijau aktif, badge Vision).
4. **Verifikasi & Deploy Produksi:**
   - Menambahkan pengujian otomatis Vitest untuk seleksi agen Studio.
   - Build produksi sukses dan deploy ke `https://cuan.dojo.cc` tanpa regresi.
