## Sprint goal dan demo outcome

### Sprint Goal
Membangun kapabilitas Bring Your Own Domain (BYOD) dan On-Demand TLS pada Cuan: memungkinkan pengguna menghubungkan domain atau subdomain pribadi kustom mereka (seperti `app.clientbrand.com`, `myproject.io`) ke aplikasi yang telah di-deploy (baik local sandbox maupun remote BYOS VPS), melakukan verifikasi kepemilikan domain otomatis via DNS resolver (CNAME & TXT record check) yang aman dan tangguh, mengintegrasikan Caddy Server Dynamic On-Demand TLS reverse proxy dengan ask-endpoint (`/api/domains/check-ask`) untuk penerbitan sertifikat SSL Let's Encrypt / ZeroSSL otomatis tanpa downtime dan tanpa reload server, menyediakan antarmuka manajemen Custom Domains di Studio Dashboard dengan instruksi DNS yang interaktif dan informatif, serta staging E2E drill dan release gate dengan 100% data retention Sprint 1–4.

### Demo Outcome
1. Pengguna membuka Studio Dashboard di tab "Projects" atau "Deployments", memilih deployment aktif, dan masuk ke menu "Custom Domains".
2. Pengguna memasukkan nama domain kustom (misal `app.startupku.id`) dan mengeklik "Add Domain".
3. Sistem membuat entitas `custom_domains` dengan token verifikasi unik dan menampilkan panduan konfigurasi DNS yang jelas (CNAME record mengarah ke host Cuan atau TXT record untuk verifikasi).
4. Pengguna mengeklik tombol "Verify Domain": DNS verification engine secara instan mengecek resolusi DNS publik. Jika propagasi valid, status DNS berubah menjadi `verified`.
5. Caddy reverse proxy menerima request HTTPS pertama ke `https://app.startupku.id`, menghubungi endpoint `/api/domains/check-ask?domain=app.startupku.id` (status HTTP 200), lalu menerbitkan sertifikat TLS On-Demand secara instan dan mengarahkan trafik ke internal port / runner aplikasi deployment yang sesuai.
6. Pengguna membuka `https://app.startupku.id` di browser dan aplikasi terbuka dengan koneksi aman (gembok TLS hijau / valid HTTPS certificate) tanpa restart backend Cuan.

## Target pengguna dan nilai produk

### Persona Target Market
1. **Solo Developer & Indie Hackers:** Ingin meluncurkan produk SaaS, micro-app, atau landing page dengan custom brand domain mereka sendiri agar terlihat profesional di mata calon pembeli/investor, tanpa terikat pada subdomain bawaan platform (`*.cuan.id`).
2. **Freelance & Digital Agencies:** Mengelola puluhan aplikasi web untuk berbagai klien bisnis. Setiap klien menuntut website berjalan di domain resmi perusahaan klien (`client.co.id`, `shop.client.com`). Kemampuan Cuan mengelola multi-tenant custom domains dengan zero SSL management overhead adalah *selling point* utama.
3. **Founding Backers & Growth Hackers:** Membutuhkan kemudahan A/B testing dan setup domain cepat untuk kampanye pemasaran tanpa friksi konfigurasi Nginx/Caddy manual atau renew certbot manual.

### Pertimbangan Kepuasan Target Market (DoD Focus)
- **Zero-Friction DNS Setup & Guidance:** Panduan konfigurasi DNS (tipe CNAME atau TXT, host/name, target value, dan copyable token) ditampilkan dengan format interaktif yang siap disalin (*1-click copy*).
- **Automated Instant SSL (Zero-Maintenance):** Tidak perlu setup Certbot, Cronjob, atau port forwarding SSL manual. Caddy On-Demand TLS menerbitkan dan memperbarui sertifikat otomatis saat request pertama masuk.
- **Keamanan Anti-Abuse (Ask Endpoint Protection):** Endpoint `/api/domains/check-ask` mencegah eksploitasi DoS sertifikat TLS liar dengan memastikan hanya domain yang telah terdaftar dan diverifikasi di database Cuan yang diizinkan memperoleh sertifikat Let's Encrypt.
- **Multi-domain per Deployment:** Satu deployment aplikasi dapat memiliki beberapa custom domain (misalnya domain utama + alias subdomain).

## Fondasi teknis dan arsitektur

- **Backend:** Go (Golang) menggunakan `net/http` dan router `chi/v5`.
- **Database:** PostgreSQL dengan skema aditif migrasi `000010_custom_domains.up.sql`:
  - Tabel baru `custom_domains` (`id`, `deployment_id`, `domain`, `dns_status`, `ssl_status`, `verification_token`, `last_checked_at`, `created_at`, `updated_at`).
  - Foreign key `deployment_id REFERENCES deployments(id) ON DELETE CASCADE`.
  - Unique constraint pada kolom `domain`.
  - Index pada `deployment_id` dan `domain`.
  - Menjamin 100% retensi data Sprint 1 (`owners`, `projects`, `tasks`), Sprint 2 (`sponsors`, `sponsorship_orders`), Sprint 3 (`deployments`, `deployment_logs`), dan Sprint 4 (`servers`).
- **Domain Store & Repository (`internal/db/domain.go`):**
  - Model `CustomDomain` dan `CustomDomainDTO` dengan sanitasi token.
  - Implementasi `SQLDomainRepository` dan `MemoryDomainRepository` untuk keperluan testing mock.
  - Validasi ketat nama domain (format RFC 1123 / RFC 952, lowercase, penolakan scheme, port, atau path).
- **DNS Verification Engine (`internal/domain/resolver.go`):**
  - Menggunakan DNS resolver Go (`net.LookupCNAME`, `net.LookupTXT`, `net.LookupIP`).
  - Verifikasi CNAME ke canonical host Cuan atau TXT record `_cuan-challenge.<domain>` berisi `verification_token`.
- **Caddy Dynamic On-Demand TLS & Ask Endpoint (`internal/deployer/caddy.go` & `/api/domains/check-ask`):**
  - Integrasi Caddy On-Demand TLS policy dengan filter ask endpoint.
  - Caddy query ke backend Cuan: jika domain terdaftar dan berstatus aktif/verified, backend mengembalikan status HTTP 200 OK; jika tidak dikenal, HTTP 403 Forbidden untuk mencegah sertifikat diterbitkan secara liar.
- **Frontend Studio UI (`web/src/components/studio/CustomDomainsModal.tsx`):**
  - Komponen React + TypeScript + Tailwind CSS + shadcn/ui.
  - Daftar domain terhubung, status badge (Pending / Verified / Failed), instruksi DNS, tombol "Verify DNS", dan aksi hapus domain.

## Infrastruktur, routing, dan staging gate

1. **Host & Port:**
   - Stable: Port `8080` (reverse proxy Caddy HTTPS).
   - Staging: Port `8081` (Compose project terisolasi, database terpisah).
   - Caddy Ingress: Port `80` (HTTP ACME challenge & redirect) dan Port `443` (HTTPS TLS termination).
2. **Data Retention & Compatibility Gate:**
   - Migrasi `000010_custom_domains.up.sql` murni aditif dan foreign key `deployment_id` menggunakan `ON DELETE CASCADE`.
   - Data deployments dari Sprint 3 dan servers dari Sprint 4 tetap beroperasi normal tanpa interupsi.
   - Rollback migrasi `000010_custom_domains.down.sql` wajib membersihkan tabel `custom_domains` dan index terkait tanpa merusak skema tabel Sprint 1–4.
3. **Audit Keamanan & Anti-Abuse Gate:**
   - Ask endpoint `/api/domains/check-ask` hanya merespons status `200` jika domain telah terdaftar dan valid, mencegah denial-of-wallet / rate-limiting serangan ACME Let's Encrypt.
   - Format domain dibersihkan dan divalidasi ketat untuk mencegah DNS poisoning atau SSRF injection.

## Out of scope eksplisit

- Penjualan domain registrar / domain purchase API (e.g. integrasi API Namecheap/GoDaddy untuk beli domain baru dari dashboard) — pengguna membawa domain sendiri yang sudah dimiliki (*Bring Your Own Domain*).
- DNS Management / Nameserver Hosting (Cuan bukan NS provider / DNS authority seperti Cloudflare).
- Wildcard SSL (*.domain.com) melalui DNS-01 API integration ke registrar pihak ketiga (Sprint 5 berfokus pada On-Demand TLS HTTP-01 / ALPN-01 per specific hostname).
- Email hosting atau MX record configuration untuk custom domains.

## Risiko dan respons

| Risiko | Dampak | Respons / Mitigasi |
| --- | --- | --- |
| Serangan Certificate Exhaustion / DoS melalui hostname liar | Let's Encrypt rate-limit tercapai, server kehabisan sertifikat | Strict Caddy ask endpoint (`/api/domains/check-ask`) yang hanya menyetujui domain terverifikasi di database |
| Propagasi DNS lambat di resolver pengguna | Verifikasi domain gagal padahal user sudah input DNS | Dual check (CNAME + TXT), status `pending` dengan retry non-blocking, panduan TTL rendah di UI |
| Input domain format invalid atau mengandung payload berbahaya | SQL injection atau host header injection | Validasi ketat format domain (RFC 1123 regex), penolakan karakter ilegal, lowercase sanitization |
| Regresi migrasi database terhadap data Sprint 1–4 | Data deployment atau server terganggu | Skema murni aditif tabel baru `custom_domains` dengan FK `deployments(id)` ON DELETE CASCADE |
