## 1. Sprint Goal dan Demo Outcome

### Sprint Goal
1. Mentransformasi arsitektur layout Cuan agar 100% responsif dan nyaman di perangkat mobile (< md / 360px–414px): mengeliminasi rail samping sempit 48px di HP, menghadirkan Mobile Bottom Navigation Bar untuk 4 tab utama (Inbox, Projects, Agents, Team), serta menerapkan alur Single-View WhatsApp/Telegram (daftar kontak full width <-> chat viewport full width dengan tombol Back `<`) sehingga tidak ada lagi penjepitan layout 3-tier atau teks chat terpotong 72px.
2. Menggantikan modal pembuatan task lama yang kaku dan berlapis dengan **Minimalist Task Creation Form (Model Fural)**: zero-friction, autofocus title, deskripsi opsional, project selector instan, shortcut Enter untuk langsung submit (Ctrl/Cmd+Enter di Description), dan pembuatan tugas tuntas dalam < 3 detik.
3. Mempertahankan backward-compatibility penuh (19 migrasi PostgreSQL utuh, zero database regression, live chat widget `/chat/widget.js` tetap prima), uji staging drill emulasi mobile pada port 8081, deploy ke `https://cuan.dojo.cc`, dan publikasi panduan mandiri berdiagram D2 TALA.

### Demo Outcome
1. **Mobile Responsive Shell & Bottom Navigation Bar (S19.1):**
   - Rail samping 48px tersembunyi secara otomatis di mobile (`hidden md:flex`).
   - Bottom Navigation Bar (`md:hidden`) terpasang rapi di bagian bawah layar dengan 4 tab navigasi utama: Inbox, Projects, Agents, Team, lengkap dengan padding bawah konten yang pas (`pb-16 md:pb-0`).
   - Akses theme toggle (Light/Dark) dan profil pengguna (User Avatar & Logout/Change Password) dapat diakses dengan 1 ketukan langsung di top bar header mobile.
2. **WhatsApp/Telegram Mobile Single-View Navigation (S19.2):**
   - Di mobile (`< md`), Inbox beroperasi dalam mode Single-View:
     * State List: Daftar kontak tampil 100% lebar layar HP tanpa terhimpit panel chat.
     * State Chat: Saat kontak diklik, antarmuka berganti ke Chat Stream 100% lebar layar HP dengan tombol Back (`<`) di header untuk kembali ke daftar kontak.
   - Di desktop (`>= md`), tata letak split view berdampingan (subpanel 240px + main chat viewport) tetap dipertahankan 100%.
   - Eliminasi tuntas masalah layout 3-tier terjepit (48px + 240px + 72px).
3. **Minimalist Task Creation Form — Model Fural (S19.3):**
   - Form pembuatan task ramping, bersih, dan cepat.
   - Input judul autofocus seketika modal dibuka dengan placeholder `"Apa yang ingin dikerjakan?..."`.
   - Textarea deskripsi opsional.
   - Dropdown project otomatis terisi project yang sedang aktif.
   - Shortcut keyboard: Tekan Enter pada title langsung submit; Ctrl+Enter atau Cmd+Enter pada description langsung submit; Esc untuk batal.
   - Sangat nyaman digunakan di layar HP tanpa scroll vertikal berlebih.
4. **Staging Mobile E2E Drill, Zero-Regression & Production Launch (S19.4):**
   - Pengujian otomatis staging pada port 8081 menguji emulasi viewport mobile (360px–414px), alur single-view WhatsApp/Telegram, dan pembuatan task kilat Fural model.
   - 19 migrasi database PostgreSQL utuh tanpa regresi data.
   - Live chat widget `/chat/widget.js` tetap berfungsi normal dengan CORS terbuka.
   - Bundle produksi dikompilasi via `npm run build` dan server Go dikompilasi.
   - Rilis sukses dideploy ke produksi `https://cuan.dojo.cc` via SSH `DOJO_TERMAPI_VPS`.
   - Public smoke test: `/healthz`, `/readyz`, `/api/info`, `/chat/widget.js`, root SPA 200 OK.

## 2. Target Market dan Pertimbangan Kepuasan DoD (§4)

### Target Market
* **Solopreneur & Pengelola Bisnis Mandiri (Dojo Creators On-The-Go):** Sering mengakses Cuan melalui smartphone saat bepergian untuk memantau agen, membalas chat pembeli, atau mencatat ide tugas secara cepat.
* **Operator & Support Team:** Membutuhkan pengalaman chat yang familiar seperti WhatsApp/Telegram di genggaman tangan tanpa hambatan navigasi desktop yang rumit.

### Mengapa Target Market Bakal Senang dengan DoD Ini?
* **Zero Layout Frustration di Mobile:** Tidak ada lagi tombol atau teks chat yang terpotong menjadi 72px karena terhimpit rail 48px dan panel samping 240px. Balon chat dan daftar kontak memanfaatkan 100% lebar layar ponsel.
* **Navigasi Jempol Alami (Bottom Bar):** Berpindah antar modul utama (Inbox, Projects, Agents, Team) cukup menggunakan jempol tangan bawah dengan Bottom Navigation Bar.
* **Pencatatan Tugas Kilat (< 3 Detik):** Modal task lama yang membutuhkan pengisian 6 form beruntun digantikan dengan formulir minimalis Fural: ketik ide tugas, tekan Enter, tugas langsung tercatat!

## 5. Detail Backlog Tasks (S19.1 – S19.4)

### S19.1 — Mobile Responsive Shell & Bottom Navigation Bar
- **Scope:**
  - `web/src/components/layout/AppShell.tsx`:
    * Sembunyikan primary rail samping 48px di layar mobile (`hidden md:flex`).
    * Hadirkan Bottom Navigation Bar fixed di bawah (`md:hidden`, h-16) untuk navigasi 4 tab: Inbox, Projects, Agents, Team.
    * Sediakan padding bawah yang tepat pada container utama (`pb-16 md:pb-0`) agar konten tidak tertutup bottom bar.
    * Letakkan tombol theme toggle dan avatar/menu profil pengguna di top bar header mobile agar mudah diakses.
- **DoD:**

## 8. Risiko & Mitigasi

| Risiko | Dampak | Mitigasi |
| :--- | :--- | :--- |
| **Bottom Bar Menutupi Form / Chat Input di Mobile** | Pengguna kesulitan mengetik pesan di HP | Menerapkan `pb-16 md:pb-0` pada container utama dan menata z-index bottom bar di bawah modal |
| **State Desync Antara Mobile View & Desktop View** | Chat tidak terbuka saat beralih orientasi | Menggunakan state tersentralisasi di `App.tsx` dan `InboxView` yang adaptif terhadap viewport |
| **Enter Menghasilkan Newline alih-alih Submit** | Pengguna harus menekan tombol manual | Menambahkan handler `onKeyDown` spesifik pada input Title untuk langsung memanggil submit form |
