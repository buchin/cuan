## Outcome Sprint & Kesepakatan PO & SM

**Outcome:** Meningkatkan efisiensi kerja dan kejelasan identitas pelanggan di `/inbox` bagi pengguna UMKM dengan menyajikan email customer langsung di header obrolan yang dilengkapi tombol 1-klik salin (*One-Click Copy*) dan *visual feedback* yang *touch-friendly*, serta memperkuat keandalan backend runner eksekusi task (`taskprocess.Supervisor`) dengan *hard execution timeout* (20 menit default dengan terminasi bertahap graceful SIGTERM lalu SIGKILL) dan *background zombie reaper* / reconciler otomatis agar sistem bebas dari proses orphan yang menggantung (*zero-hung runners*).

1. **Visibilitas Identitas Pelanggan Cepat di Header Inbox**:
   - Memetakan field `Email` pada model dan payload kontak obrolan (`ChatContact`) di backend dari data pengunjung CRM (`crm_contacts`).
   - Menyajikan email pelanggan tepat di samping nama pelanggan pada header aktif percakapan `/inbox` (`InboxView.tsx`).
2. **Aksi 1-Klik Salin (One-Click Copy) & Touch-Friendly Standard**:
   - Menyediakan tombol salin cepat 1-klik langsung di samping email pada header obrolan dengan *feedback* visual instan ("Disalin!" / "Copied!").
   - Memenuhi standar interaksi ramah sentuhan (*touch-friendly*, target sentuh minimum tinggi 44px / `min-h-11`) untuk kenyamanan penggunaan di smartphone atau tablet tanpa risiko salah ketuk.
3. **Task Runner Resilience (Hard Execution Timeout 20 Menit)**:
   - Mencegah proses eksekusi agen atau terminal task berjalan tanpa batas (*runaway / hung process*) dengan menerapkan batas waktu eksekusi tegas (*hard execution timeout*) 20 menit pada `internal/taskprocess/supervisor.go`.
   - Menggunakan mekanisme terminasi bertahap: pengiriman sinyal graceful `SIGTERM` dengan tenggat waktu toleransi sebelum eskalasi ke sinyal tegas `SIGKILL` untuk memastikan pelepasan file lock OS.
4. **Automated Zombie Reaper & Task Reconciler**:
   - Menyediakan background reconciler / zombie reaper berkala di server Cuan untuk mendeteksi *task attempt* atau proses *launch* yang berstatus orphan atau ditinggalkan akibat crash server.
   - Memulihkan status task secara aman, melepaskan lock file, dan mencegah kebocoran resource memori atau CPU di server VPS produksi.

## Kesesuaian Target Market (UMKM, Pemilik Toko Online & Solopreneur)

Target market utama Cuan adalah pemilik bisnis UMKM, admin toko online, dan solopreneur non-developer di Indonesia yang mengoperasikan percakapan penjualan dan layanan pelanggan melalui Cuan:

1. **Pencocokan Cepat Data Pelanggan (Fast CRM / Order Matching)**:
   - Pemilik toko online seringkali menerima obrolan dari calon pembeli yang menanyakan status pesanan atau konfirmasi pembayaran.
   - Dengan menampilkan email pelanggan langsung di header obrolan aktif tanpa perlu membuka tab atau modal terpisah, pemilik toko dapat seketika mengenali identitas pembeli dan mencocokkannya dengan mutasi bank atau data order.
2. **Efisiensi Aksi Salin 1-Klik (Zero Typing Friction)**:
   - Menyalin alamat email pembeli ke formulir pengiriman, invoice, atau email follow-up kini cukup dengan 1 kali klik.
   - Umpan balik visual yang jelas ("Disalin!") memberi kepastian psikologis langsung bahwa teks telah tersimpan di clipboard tanpa perlu verifikasi manual berulang.
3. **Pengalaman Mobile Ramah Jari (Touch-Friendly min-h-11)**:
   - Sebagian besar pengusaha UMKM memantau toko mereka melalui smartphone saat beraktivitas di luar.
   - Tombol salin dan area interaksi header dirancang dengan target sentuh minimal 44px (`min-h-11`) untuk mencegah frustrasi akibat salah sentuh (*misclick*) di layar sentuh ponsel.
4. **Stabilitas Server Mandiri Tanpa Intervensi Teknis (Self-Healing Runner)**:
   - Pengguna non-developer tidak memahami konsep proses background Linux, lockfile, atau perintah `kill -9`.
   - Ketika ada task background yang menggantung karena kendala eksternal, mekanisme *hard timeout* (20 menit) dan *zombie reaper* secara otomatis membersihkan sistem tanpa memerlukan campur tangan teknis dari pemilik toko.

## Risiko, Batasan & Mitigasi

1. **Risk: Terminasi Prematur pada Task Panjang yang Sah**:
   - *Dampak:* Task yang memang membutuhkan komputasi lama (misal scraping besar atau instalasi dependensi) dapat terbunuh secara keliru oleh timeout 20 menit.
   - *Mitigasi:* Nilai batas 20 menit adalah durasi yang sangat longgar untuk pekerjaan standar task runner di Cuan. Jika diperlukan di masa depan, timeout dapat dikonfigurasi melalui environment variable atau parameter task tanpa menurunkan batas default.
2. **Risk: Data Email Pelanggan Kosong atau Tidak Valid**:
   - *Dampak:* Tampilan header terlihat berantakan jika data email kosong (misalnya muncul tanda baca titik gantung atau tombol salin kosong).
   - *Mitigasi:* Frontend menerapkan kondisional rendering ketat: teks titik pemisah dan tombol salin hanya dirender jika `activeContact.email` bernilai truthy dan bukan string kosong setelah di-trim.
3. **Risk: Pembatasan Izin Clipboard API di Browser Mobile/Non-HTTPS**:
   - *Dampak:* Pemanggilan `navigator.clipboard.writeText` dapat gagal jika browser membatasi izin clipboard atau konteks keamanan tidak terpenuhi.
   - *Mitigasi:* Sediakan mekanisme fallback tangguh menggunakan elemen `textarea` tersembunyi dengan perintah `document.execCommand('copy')` agar fungsionalitas salin tetap bekerja di seluruh jenis peramban.
