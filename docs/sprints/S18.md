## 1. Sprint Goal dan Demo Outcome

### Sprint Goal
Mentransformasi kanal komunikasi Cuan menjadi **Direct Messenger Hub & Dojo Live Chat Replacement** bergaya WhatsApp/Telegram yang modern, hening, dan mandiri dengan **Neutral Theme** (standar shadcn/ui zinc/slate dark & light). Menghilangkan friksi pembuatan thread/topik yang kaku, menyediakan manajemen kontak langsung (Internal Agents & Dojo Customers), mengintegrasikan skrip widget live chat drop-in mandiri berbasis Shadow DOM (`/chat/widget.js`) dengan backward-compatibility 100% terhadap kontrak Dojo & Crisp shims, serta mempertahankan zero database regression (19 migrasi PostgreSQL utuh).

### Demo Outcome
1. **Neutral Theme Migration (shadcn/ui Zinc/Slate):**
   - Eliminasi total seluruh token warna Tokyo Night (`#1a1b26`, `#eaeef6`, `#1f2335`, `#24283b`, `#7aa2f7`, dsb.).
   - Penerapan tema standar shadcn/ui (zinc/slate) yang adaptif untuk mode terang (*light*) maupun gelap (*dark*).
2. **Direct Messenger Hub (WhatsApp/Telegram-Style):**
   - **Sub-Panel Kontak (Kiri):** Daftar kontak dengan tab filter (*All*, *Agents*, *Customers*), pencarian cepat, indikator online, badge pesan belum dibaca (*unread count*), cuplikan pesan terakhir, dan timestamp.
   - **Main Viewport (Kanan):** Header kontak aktif, aliran balon percakapan modern (*bubble stream*), kartu aksi eksekusi 1-klik (*1-click execution cards*) untuk pesan Agent, dan badge produk untuk Customer/Visitor.
   - **Modern Composer (Bawah):** Textarea yang membesar otomatis (*auto-expanding*), shortcut Enter untuk mengirim pesan (Shift+Enter untuk baris baru), tanpa form input judul topik.
3. **Dojo Drop-In Live Chat Widget JS (`/chat/widget.js`):**
   - Skrip Vanilla JS mandiri berkinerja tinggi berbasis Shadow DOM tanpa polusi CSS ke website induk.
   - Sepenuhnya kompatibel dengan atribut `data-product`, `data-api-base`, telemetri URL/halaman, dan retensi `guest_uuid`.
   - Menyediakan shim `window.$crisp` dan `window.$dojoChat` sehingga aksi konfirmasi pembayaran dan pemanggilan widget dari `dojo.cc` tidak mengalami error.
   - Header CORS terbuka (`Access-Control-Allow-Origin: *`) untuk kemudahan embed lintas-domain.
4. **Staging Drill, Zero-Regression Verification & Production Launch:**
   - Uji otomatis staging E2E pada port 8081 (percakapan internal langsung + widget visitor live chat).
   - Zero DB regression (19 migrasi database PostgreSQL tetap utuh dan data lama dipertahankan 100%).
   - Deploy sukses ke host produksi `DOJO_TERMAPI_VPS` (`https://cuan.dojo.cc`).
   - Smoke tests publik: `/healthz`, `/readyz`, `/api/info`, `/chat/widget.js` (200 OK) dan root SPA.
   - Panduan mandiri `docs/guides/livechat_dojo_replacement_guide.md` dengan diagram D2 TALA.
   - Berkas audit lengkap di `docs/sprints/evidence/S18/s18_4_production_launch_verified.txt`.

## 2. Target Market dan Pertimbangan Kepuasan DoD (§4)

### Target Market
* **Solopreneur & Pengelola Bisnis Mandiri (Dojo Creators):** Membutuhkan antarmuka percakapan langsung yang gesit (*fast & low cognitive load*) tanpa harus memikirkan "judul topik" setiap kali ingin berinteraksi dengan worker agent atau membalas pertanyaan pembeli.
* **Calon Pembeli & Pelanggan Produk Dojo (Visitors):** Menginginkan widget live chat yang ringan, cepat terbuka, tidak merusak styling website penjual, dan pesan tersampaikan secara andal ke pemilik produk.

### Mengapa Target Market Bakal Senang dengan DoD Ini?
* **Zero Barrier to Chat:** Tidak ada lagi modal popup pengisian judul topik atau thread yang membingungkan. Klik kontak atau agen, ketik pesan, tekan Enter, langsung terkirim.
* **Familiar Direct Messenger UX:** Tata letak dan perilaku balon chat mengadopsi standar emas perpesanan modern (WhatsApp & Telegram), lengkap dengan visualisasi status dan aksi 1-klik.
* **Drop-in Live Chat yang Bersih:** Widget Shadow DOM dapat dipasang di landing page mana pun (seperti `dojo.cc`, `arsae`, `shuriken`) dengan 1 tag script saja tanpa konflik CSS.
* **Neutral Theme yang Tenang:** Palet warna zinc/slate hening dan profesional, nyaman di mata untuk penggunaan jangka panjang di siang maupun malam hari.

## 5. Detail Backlog Tasks (S18.1 – S18.4)

### S18.1 — Neutral Theme Migration & Direct Chat Core API (No Topic)
- **Scope:**
  - Membersihkan dan mengganti seluruh tema Tokyo Night (`#1a1b26`, `#eaeef6`, `#1f2335`, `#24283b`, `#7aa2f7`, dsb.) di Tailwind config, CSS, dan seluruh komponen web dengan tema netral standar shadcn/ui zinc/slate (light & dark).
  - Menghilangkan kewajiban field `title` dan `topic` pada alur percakapan backend maupun frontend.
  - Mendefinisikan entitas `ChatContact` (`type`: `agent` | `customer`, `name`, `avatar`, `status`, `product`, `guest_uuid`) dan `ChatConversation`.
  - Menyediakan REST API internal:
    * `GET /api/v1/chat/contacts` (Daftar kontak agen dan customer dengan pencarian dan filter).
    * `GET /api/v1/chat/conversations/{id}/messages` (Histori percakapan kontak).
    * `POST /api/v1/chat/conversations/{id}/messages` (Mengirim pesan langsung ke kontak).
  - Menyediakan Visitor API yang kompatibel dengan kontrak live chat Dojo:
    * `POST /api/chat/session` (Inisialisasi sesi visitor baru atau resume sesi via `guest_uuid`/`session_uuid`).
    * `GET /api/chat/messages` (Polling pesan baru dengan query `session_uuid` dan `after_id`).
    * `POST /api/chat/messages` (Pengiriman pesan dari visitor).
    * `POST /api/chat/sessions/{uuid}/page` (Telemetri URL halaman aktif & update data session).
    * `POST /api/chat/receipts` (Acknowledge status delivery dan read message).
  - Backward-compatibility: percakapan S17 dimapping secara otomatis ke kontak default Scrum Master. Skema 19 migrasi database PostgreSQL tetap utuh 100%.
- **DoD:**
  1. Tailwind CSS dan antarmuka web bersih dari warna spesifik Tokyo Night, mengadopsi standar neutral shadcn zinc/slate.
  2. Endpoint internal `/api/v1/chat/contacts` dan `/api/v1/chat/conversations/{id}/messages` berfungsi mulus.
  3. Endpoint visitor `/api/chat/session`, `/api/chat/messages`, dan `/api/chat/sessions/{uuid}/page` lulus uji kontrak API dengan format response JSON valid.
  4. Skema database 19 migrasi utuh tanpa modifikasi destruktif.
  5. Audit pack `docs/sprints/evidence/S18/s18_1_neutral_theme_core_api_verified.txt` terbit, commit author Buchin & push `origin/main`.

### S18.3 — Dojo Drop-In Live Chat Widget JS (`/chat/widget.js`)
- **Scope:**

## 8. Risiko & Mitigasi

| Risiko | Dampak | Mitigasi |
| :--- | :--- | :--- |
| **Konflik Styling Widget di Situs Eksternal** | Tampilan chat berantakan di landing page induk | Menggunakan Shadow DOM terisolasi penuh sehingga CSS widget mandiri 100% dari CSS luar |
| **CORS Block pada Live Chat API** | Widget gagal memanggil endpoint Cuan dari domain luar | Memasang middleware CORS terbuka (`Access-Control-Allow-Origin: *`) pada seluruh rute `/api/chat/*` dan `/chat/widget.js` |
| **Kehilangan Riwayat Sesi Pengunjung** | Pengunjung refresh halaman dan pesan hilang | Menyimpan dan membaca `guest_uuid` serta `session_uuid` di localStorage & cookie browser |
| **Regresi Thread Lama S17** | Data percakapan sebelumnya tidak dapat diakses | Otomatis memetakan seluruh thread legacy ke kontak Scrum Master di sub-panel Messenger |
