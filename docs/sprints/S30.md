# Cuan Sprint 30 — Scrum Master Dynamic Project Intelligence & In-Chat Inspection Tooling

## Rekomendasi untuk PO (diajukan SM)

**Rekomendasi:** Approve scope S30 di bawah ini — mengimplementasikan paket terpadu kapabilitas Scrum Master (`@sm`) berupa *Injected Dynamic Project Intelligence* (diff git commit terkini, katalog rute API backend, dan peta komponen UI `web/src` dinamis langsung di konteks project tanpa latency), panduan perancangan *Layout Wireframing & Advisory Simulation* (ASCII mockup & pertimbangan UX/WCAG 44px) di `coordinator.md`, serta verifikasi integritas read-only tools inspection.

**Alternatif:** Hanya mengandalkan native read tools CLI tanpa injeksi peta arsitektur — SM akan lambat dan menghabiskan kuota tool calls (12 calls) hanya untuk mencari letak folder komponen UI dan rute API, atau berisiko salah menduga letak tombol/komponen.

**Alasan:** Sesuai arahan PO ("Gas semua"), pendekatan hybrid (injeksi intelijen proyek dinamis + panduan layout wireframing terstruktur di chat) memberikan zero-latency intelligence kepada SM sehingga mampu menjawab pertanyaan arsitektur, letak komponen, dan perubahan kode terkini secara instan, akurat, dan ramah pengguna non-developer tanpa memicu pemaksaan task/approval.

## Tujuan Sprint

1. **Injected Dynamic Project Intelligence (`internal/server/inbox_project.go`):**
   - Injeksi diff commit terkini (`git show --stat --oneline -n 1 HEAD`) ke dalam `projectContext` agar SM langsung memahami berkas yang baru saja diubah developer.
   - Injeksi peta komponen UI (`web/src/features/` dan `web/src/components/layout/`) dinamis sehingga SM mengetahui letak pasti komponen (seperti `InboxSubPanel.tsx`, `ChatArea.tsx`, `TaskBoard.tsx`, `Navbar.tsx`).
   - Injeksi katalog rute API backend (`internal/server`) agar SM memahami endpoints yang sudah ada (Chat, Item Preferences, Tasks, Projects, Providers, Auth).
2. **Layout Wireframing & Advisory UI Simulation (`internal/workflow/coordinator.md` & `inbox_coordinator_response.go`):**
   - Menambahkan panduan eksplisit bagi SM untuk menyajikan simulasi tata letak visual (ASCII wireframe / diagram blok) ketika PO berkonsultasi mengenai penempatan elemen UI di chat.
   - Menyertakan analisis trade-off UX (aksesibilitas WCAG touch target min 44x44px, unread sync, hierarki visual).
3. **Automated Verification & Zero Regression:**
   - Menambahkan unit test targeted untuk dynamic project intelligence di `internal/server/inbox_project_test.go`.
   - Memperbaiki test assertion sandbox prompt pada `TestInboxProjectCLIUsesWorkspaceAndRetainsProfile`.
   - Memastikan seluruh targeted backend & frontend tests lulus 100% dan deploy ke produksi `https://cuan.dojo.cc` terverifikasi sehat.

## Definisi Selesai (DoD) Setiap Task

### T1 — Injected Dynamic Project Intelligence (`inbox_project.go`)
- `internal/server/inbox_project.go`:
  - Ditambahkan fungsi helper `inspectRecentGitChanges(ctx, dir)` yang menyertakan commit hash, summary, dan diffstat berkas terbaru (`git show --stat --oneline -n 1 HEAD`).
  - Ditambahkan fungsi helper `inspectUIArchitecture(dir)` yang mendeteksi `web/src` dan menyusun ringkasan terstruktur direktori fitur (`features/inbox`, `features/tasks`, `features/projects`, dll.) beserta berkas komponen utamanya dan komponen layout shell (`Navbar`, `Sidebar`).
  - Ditambahkan fungsi helper `inspectAPIRoutesCatalog(dir)` yang menyusun ringkasan terstruktur grup API endpoint backend Cuan.
  - Snapshot konteks proyek mengintegrasikan ketiga komponen ini dalam batas memori/karakter yang aman (bounded).

### T2 — Layout Wireframing & UI Advisory Guidance
- Di `internal/workflow/coordinator.md` dan `internal/server/inbox_coordinator_response.go`:
  - Ditambahkan instruksi panduan bahwa ketika PO menanyakan opsi tata letak UI atau letak komponen baru:
    - SM menyajikan visualisasi tata letak ASCII wireframe yang rapi di dalam chat.
    - SM menjelaskan pertimbangan hierarki visual, kenyamanan pengguna, dan standar aksesibilitas WCAG (touch target min 44x44px).
    - SM tetap berada di mode Advisory (`action: null`) tanpa memaksakan approval card atau kartu tiket task kecuali PO meminta perubahan kode/eksekusi.

### T3 — Targeted Unit Tests & Regression Verification
- Di `internal/server/inbox_project_test.go`:
  - Diperbarui assertion regex/string pada `TestInboxProjectCLIUsesWorkspaceAndRetainsProfile` agar selaras dengan wording instruksi koordinasi terkini (`terminal execution`).
  - Ditambahkan unit test baru `TestInboxProjectContextDynamicIntelligence` yang memverifikasi bahwa diffstat git terkini, peta komponen UI, dan katalog rute API terinjeksi dengan benar dalam snapshot proyek.
  - Targeted unit tests lulus 100%. Frontend test `npm test --prefix web` dan build `npm run build --prefix web` lulus 100%.
