## Sprint goal dan demo outcome

### Sprint Goal
Mentransformasi antarmuka Cuan melalui **"UI Radical Simplification: Strict Minimalist Scope"** sesuai instruksi eksplisit PO Buchin (*"Ui sekarang masih terlalu kompleks. Hilangkan semuanya dulu dari ui kecuali yang ane sebut di sprint tadi"*), yang mengeliminasi seluruh elemen pemasaran, tautan sponsorship, toggle runtime overhead, dan sub-grup menu yang mengacaukan konsentrasi pengguna.

Aplikasi difokuskan secara murni pada **sembilan (9) pilar utama**:
1. **Auth Gatekeeper:** Login mandatory (default admin: `admin` / `whosyourdaddy`), rute terproteksi penuh tanpa bypass publik yang tidak perlu.
2. **Design System Tokyo Night:** Palet Dark/Light standar `#1a1b26` / `#eaeef6`, border radius `0rem`, kontras tinggi nyaman di mata.
3. **6 Menu Global Sidebar:** Tepat enam menu utama di navigasi global: `Dashboard`, `Tasks`, `Projects`, `Discussions`, `Agents`, dan `Team`.
4. **NavUser Footer:** Panel ringkas di footer sidebar menampilkan identitas admin aktif, modal ubah password, dan tombol logout aman.
5. **Contextual Project Sidebar:** Saat berada di konteks proyek, sidebar bertransisi menyajikan modul proyek aktif (`Overview`, `WordPress Cloud`, `Repos`, `Deployments`, `Telemetry`, `Studio Rooms`, `Settings`) lengkap dengan tombol navigasi kembali ke global workspace.
6. **Dashboard Empty State:** Edukatif dan bersih saat instance belum memiliki proyek, menampilkan panduan singkat dan tombol interaktif *Create New Project*.
7. **Breadcrumb Switcher Navbar model Jean:** Format `Dashboard / [Project Switcher Dropdown] / [Modul]` dengan fitur pencarian cepat, penyembunyian proyek arsip, dan 1-klik alih workspace.
8. **Project Archiving:** Pemisahan tab *Active Projects* vs *Archived Projects* di direktori proyek, proyek terarsip otomatis tidak muncul di switcher navbar.
9. **Multi-Project Task Linking:** Dropdown checkbox multi-proyek pada modal task, relasi `task_projects` di database, dan badge proyek pada kartu Kanban.

### Demo Outcome
1. Pengguna membuka URL aplikasi di browser (`/`):
   - Jika **unauthenticated**: Langsung disambut oleh **Tokyo Night Auth Gatekeeper** (Login Screen), tidak ada landing page promosi.
   - Jika **authenticated**: Langsung diarahkan ke **Dashboard Workspace** tanpa perantara marketing atau banner aktivasi mode.
2. Shell aplikasi bersih dan fokus:
   - Header navbar hanya memuat `SidebarTrigger`, Breadcrumb Switcher model Jean, dan tombol Tokyo Night Theme Toggle (tidak ada tombol toggle mode runtime `Mode: studio/marketing` atau tombol 'Beranda').
   - Sidebar global hanya memuat 6 menu utama tanpa sub-grup "Infrastruktur & Admin" atau menu moderasi sponsor.
3. Alih konteks proyek instan:
   - Memilih proyek pada Breadcrumb Switcher langsung memuat modul kontekstual proyek dengan visual indicator yang konsisten.
   - Tombol '← Navigasi Global' pada header sidebar mengembalikan pengguna ke dashboard global secara mulus.
4. Manajemen Proyek & Task:
   - Dashboard menampilkan ringkasan operasional esensial atau empty state edukatif jika 0 proyek.
   - Direktori proyek menyajikan tab *Active* vs *Archived* yang bersih.
   - Pembuatan dan pengeditan task memungkinkan penautan ke beberapa proyek sekaligus.

## Target market dan pertimbangan kepuasan DoD (§4)

### Persona Target Market
1. **Digital Solopreneur & Solo Coder:**
   - Mengelola portofolio aplikasi, website WordPress, dan microservices mandiri dalam satu instalasi VPS pribadi.
   - *Kebutuhan:* Antarmuka kerja yang hening (*zero clutter*), langsung ke fungsionalitas inti (*app-first*), tanpa gangguan brosur pemasaran atau banner yang tidak relevan bagi pemilik server.
2. **Technical Lead & Agency Developer:**
   - Membutuhkan sistem navigasi yang cepat dan deterministik untuk memantau status repositori, deployment container, dan log agen AI lintas proyek klien.
   - *Kebutuhan:* Kemudahan berpindah konteks proyek via breadcrumb switcher model Jean, filter arsip proyek lama, dan task board terpadu.

### Pertimbangan Kepuasan Target Market (DoD Focus)
- **Zero Marketing Friction:** Tidak ada landing page publik, banner promosi, tombol toggle mode, atau formulir sponsorship yang mengaburkan fokus platform kerja.
- **Instant App Access:** Akses langsung ke login atau dashboard tanpa jeda navigasi tambahan.
- **Consistent Visual Focus:** Tema Tokyo Night Dark/Light dengan radius 0rem menciptakan pengalaman kerja yang profesional, rapi, dan minim kelelahan mata.
- **100% Data Retention:** Seluruh data historis Sprint 1–14 di database PostgreSQL tetap utuh 100% dan backward-compatible.

## Risiko & Mitigasi

| Risiko | Dampak | Mitigasi |
| :--- | :--- | :--- |
| **Akses Konfigurasi Server & Domain Tersembunyi** | Pengguna kesulitan mengonfigurasi BYOS/Domain jika sub-grup sidebar dihapus | Fitur tetap dapat diakses melalui modul *Settings* proyek atau direct route tanpa mengotori navigasi global utama |
| **Regresi terhadap Rute Deep Link** | Tautan bookmark lama memicu error 404 pada SPA | Fallback routing otomatis mengarahkan rute yang tidak dikenal ke Dashboard terproteksi atau Login Screen |
| **Regresi Terhadap Fitur Sprint 1–14** | Kerusakan fungsionalitas runner, docker deployer, atau WordPress cloud | Targeted tests Go dan TypeScript checks dijalankan ketat pada setiap task untuk menjamin 0 regresi |
