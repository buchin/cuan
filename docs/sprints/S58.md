## Outcome Sprint & Kesepakatan PO & SM

**Outcome:** Menghadirkan arsitektur orkestrasi tugas cerdas yang lean, independen, dan berkinerja kilat melalui ekstraksi dua modul mikro mandiri (*micro-packages*) berstandar pustaka murni Go (*zero external dependencies*):
1. **`pkg/taskfsm` (State Machine Engine)**: Mengelola siklus status lifecycle tugas (`planning → approved → running → review → completed`, `canceled`, `blocked`) dengan guardrails pencegahan transisi ilegal dan pencatatan riwayat audit lengkap.
2. **`pkg/dodeval` (Definition of Done Evaluator)**: Mengurai checklist markdown dan acceptance criteria secara otomatis serta menganalisis kesenjangan (*gap analysis*) antara kriteria vs bukti laporan penyelesaian tugas agen.
3. **Integrasi Cuan Runner & Live Deployment**: Integrasi clean import ke dalam daemon worker `cuan-runner` (`internal/runner`), pengujian kompatibilitas mundur 100% lulus, serta deployment rilis produksi terverifikasi pada endpoint `/healthz`.

## Rincian Tiap Fase (Multi-Phase Agentic Scrum)

### Phase 1: `pkg/taskfsm` (State Machine Engine)
- **Implementasi**: Pure Go standard library murni tanpa paket eksternal pihak ketiga (`sync`, `time`, `errors`, `fmt`, `strings`).
- **Siklus Lifecycle**: Mendukung transisi sah `planning → approved → running → review → completed`, penanganan pembatalan `canceled`, serta penanganan hambatan `blocked`.
- **Guardrails**: Mencegah transisi ilegal (misal langsung melompat dari `planning` ke `running` atau `completed` tanpa approval PO).
- **Hasil Pengujian**: 100% unit tests lulus dalam waktu **<10ms** (terukur 0.007s - 0.010s pada AMD EPYC 9754, benchmark throughput ~3,263 ns/op).

### Phase 2: `pkg/dodeval` (Definition of Done Evaluator)
- **Implementasi**: Pure Go standard library murni (`regexp`, `strings`, `math`, `fmt`).
- **Parser Markdown**: Mampu mengekstrak checklist `- [ ]`, `- [x]`, `* [ ]`, `1. [ ]` serta blok seksi `## Acceptance Criteria` atau `### Definition of Done`.
- **Gap Analyzer**: Memfilter stop words, mengekstrak token signifikan, menghitung persentase kepatuhan (*compliance rate*), mendeteksi celah bukti verifikasi, dan menandai kontradiksi kegagalan.
- **Hasil Pengujian**: 100% unit tests mandiri lulus dalam waktu **<10ms** (terukur 0.005s - 0.012s, benchmark throughput ~55 µs/op).

### Phase 3: Integrasi Cuan & Live Deployment
- **Clean Import**: Diintegrasikan langsung ke `internal/runner/dod_evaluator.go` dan `internal/runner/service.go`.
- **Backward Compatibility**: Seluruh 272 pengujian frontend Vitest dan seluruh pengujian backend Go (`./internal/runner/...`, `./internal/auth/...`, `./internal/db/...`) lulus 100%.
- **Dokumentasi & Landing Page**: Dokumentasi teknis dibuat di `docs/guides/task_orchestration_and_dod_evaluator_guide.md`, Landing Page diperbarui di `web/src/features/landing/LandingPage.tsx` dengan fitur micro-modular task orchestration.
- **Live Deployment Gate**: Merge ke branch `dev`, build binary Go, bundle frontend produksi Vite (0 error), atomic symlink swap ke `/opt/cuan/releases/`, dan verifikasi smoke test `/healthz` HTTP 200 OK.
