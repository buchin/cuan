## Outcome Sprint & Kesepakatan PO

**Outcome:** Menghadirkan kapabilitas **Modular Apps & Skills Ecosystem** berbasis **MCP (Model Context Protocol) Foundation** dan **Vision Receipt Extractor** pada platform Cuan. Platform Cuan kini memungkinkan agen AI bisnis mengeksekusi integrasi aplikasi eksternal (Apps) dan keterampilan khusus (Skills) secara modular, terisolasi, aman, dan tanpa friksi teknis bagi pengguna non-developer (UMKM & solopreneur). Dilengkapi fondasi backend Go MCP Client Engine (runtime lifecycle, tool registry & discovery, safe execution wrapper, zero ambient credential leak), built-in connector Google Sheets & Skill Vision Extractor untuk ekstraksi otomatis struk belanja/transfer, internal tools untuk co-pilot chat (`list_apps`, `list_skills`, `toggle_agent_skill`), antarmuka Settings -> Apps & Skills (`/settings/apps-skills`) dengan koneksi 1-klik, per-agent skill toggle di EditAgentModal, dan kartu interaktif Receipt Extraction Preview Card di Inbox dengan tombol "Konfirmasi & Catat" (*Human-in-the-Loop*).

## Target Market Fit & Value Proposition

- **Target Market**: Pemilik warung makan, kafe, toko kelontong, pedagang e-commerce/dropshipper, solopreneur, dan staf administrasi UMKM di Indonesia yang setiap hari menerima puluhan hingga ratusan foto bukti transfer bank/e-wallet dan struk belanja barang dagangan melalui chat WhatsApp/Telegram/Web.
- **Mengapa Target Market Sangat Membutuhkan & Menyukai Hasil Sprint Ini?**:
  1. **Eliminasi Entri Data Manual Struk yang Melelahkan (*Zero-Friction Bookkeeping*)**:
     Sebelumnya, staf atau pemilik toko harus mengetik ulang nominal belanja dari struk kertas kusut ke spreadsheet atau buku kas. Dengan Skill Vision Receipt Extractor, foto struk yang dikirim ke Inbox langsung dianalisis, menghasilkan nominal, nama vendor, dan daftar barang belanja secara otomatis dalam hitungan detik.
  2. **Kontrol Penuh Tetap di Tangan Pengusaha (*Human-in-the-Loop Confidence*)**:
     Pelaku UMKM sangat berhati-hati terhadap keakuratan pencatatan keuangan. Keberadaan kartu "Konfirmasi & Catat" di Inbox memberikan rasa aman: pengguna dapat meninjau hasil bacaan AI sebelum menekan satu tombol untuk menyimpannya ke pembukuan atau lembar Google Sheets.
  3. **Koneksi Aplikasi 1-Klik Tanpa Membuka Terminal Developer (*Zero Developer Friction*)**:
     Pengusaha non-developer tidak memahami API keys, JSON configuration, atau webhook setup. Halaman Apps & Skills menghadirkan tombol "Hubungkan" 1-klik yang mudah dipahami, dengan status koneksi visual yang jelas.
  4. **Ekstensibilitas Modular Berstandar MCP**:
     Dengan fondasi MCP di sisi backend, Cuan siap dihubungkan ke berbagai tool bisnis masa depan (ekspedisi pengiriman, sinkronisasi stok marketplace, dsb.) secara modular tanpa mengubah arsitektur agen inti.

## Risks & Mitigations

1. **Risk: Latensi Ekstraksi Model Vision pada Gambar Struk Resolusi Tinggi**
   - *Dampak:* Pembacaan foto struk berukuran besar (5–10 MB) dapat memakan waktu beberapa detik dan menimbulkan persepsi sistem macet.
   - *Mitigasi:* Gunakan asynchronous processing atau indikator status visual "Menganalisis struk belanja..." pada kartu Inbox. Berikan batas timeout eksekusi ketat (15 detik) agar runtime agen tidak tertahan.
2. **Risk: Salah Baca Karakter OCR pada Struk Kertas Kusut / Pudar**
   - *Dampak:* AI salah mendeteksi angka total atau nama merchant (misal Rp 150.000 terbaca Rp 15.000).
   - *Mitigasi:* Terapkan prinsip *Human-in-the-Loop* secara mutlak. AI hanya menyajikan draft pada Receipt Extraction Preview Card. Data tidak pernah langsung dibukukan tanpa persetujuan eksplisit pengguna via tombol "Konfirmasi & Catat", di mana pengguna juga dapat mengoreksi data sebelum konfirmasi.
3. **Risk: Kegagalan atau Timeout Eksekusi MCP Tool Eksternal**
   - *Dampak:* Jika server tool eksternal mengalami kendala jaringan atau down, eksekusi agen terancam terhenti mendadak (*crash*).
   - *Mitigasi:* Bungkus seluruh eksekusi MCP client dengan safe execution wrapper (recover dari panic, context with timeout 10 detik, dan graceful fallback error message yang ramah pengguna non-developer).
4. **Risk: Kebocoran Kredensial Pengembang (Ambient Credentials Leak)**
   - *Dampak:* Agen tidak sengaja membaca token atau kredensial host developer saat mengeksekusi integrasi tools.
   - *Mitigasi:* Patuhi pedoman `docs/product/integration-principles.md`: Jalankan integrasi dengan private account profile terisolasi dan allowlisted environment variabel. Jangan pernah mewariskan kredensial ambient sandbox host.

## Out-of-Scope Eksplisit

- **Third-Party App Store / Marketplace Billing**: Cuan tidak menyediakan sistem penagihan langganan pihak ketiga untuk aplikasi eksternal; manajemen tagihan akun Google / external app dikelola pengguna di penyedia masing-masing.
- **Custom OCR Model Training**: Cuan memanfaatkan fondasi vision model LLM multimodal yang didukung platform; tidak melakukan pelatihan (*custom training/fine-tuning*) bobot model OCR secara mandiri.
- **Non-Sandboxed OS Command Execution via MCP**: MCP tools dibatasi secara ketat pada kemampuan terdaftar; tidak mengizinkan eksekusi shell command arbitrary di server host.
- **Multi-Currency Complex Ledger Engine**: Pencatatan transaksi struk difokuskan pada mata uang operasional (IDR) dan model transaksi kas masuk/keluar standar Cuan.
