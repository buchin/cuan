## 1. Sprint Goal dan Demo Outcome

### Sprint Goal
Mentransformasi navigasi dan cara kerja harian Cuan menjadi **Agentic Scrum Command Center** berbasis pola antarmuka **shadcn `sidebar-09`** (dual-tier rail & sub-panel), dengan menyederhanakan menu global menjadi 4 pilar esensial: **Inbox**, **Projects**, **Agents**, dan **Team**. Pengguna cukup menyampaikan ide, bug, atau kebutuhan pekerjaan ke dalam **Inbox**, di mana AI Manager (Scrum Master) secara otonom menganalisis masalah, merumuskan Definition of Done (DoD), menautkan project, dan mendelegasikan eksekusi ke worker agent yang memiliki limit memadai (Antigravity pool).

### Demo Outcome
1. **shadcn `sidebar-09` Navigation Shell:**
   - **Primary Rail (Kiri):** Ikon navigasi minimalis untuk `Inbox`, `Projects`, `Agents`, `Team`, switcher tema Tokyo Night, dan profil user di bagian bawah.
   - **Sub-Panel (Tengah):** Panel samping kontekstual (daftar pesan/thread Inbox dengan badge status, daftar project, atau daftar agent).
   - **Main Viewport (Kanan):** Area konten utama tempat diskusi thread berlangsung, kartu project, atau detail agent.
2. **Conversational Inbox Workflow:**
   - Pengguna membuat pesan baru via **Inbox → New Thread**.
   - Menjelaskan masalah/ide secara natural kepada Agent Manager (Scrum Master).
3. **Autonomous Scrum Master Triage:**
   - SM menganalisis pesan di balik layar, membalas dengan ringkasan masalah, checklist **Definition of Done (DoD)** konkret, serta rekomendasi worker agent yang limitnya masih longgar.
   - Sekali disetujui (1-Click "Mulai Kerjakan"), task otomatis terdaftar di project terkait dan progress eksekusi agent dapat dipantau langsung di thread tersebut.
4. **Agents & Team Visibility:**
   - Menu **Agents** menampilkan pool akun worker (Antigravity accounts, limit token, status aktif).
   - Menu **Team** menampilkan hierarki peran: Product Owner (manusia), Scrum Master (manager agent), dan Development Team (worker agents).
5. **Zero-Regression & Production Ready:**
   - Seluruh backend Go, 19 migrasi PostgreSQL, dan bundle frontend tetap stabil dan live di `https://cuan.dojo.cc`.

## 2. Target Market dan Pertimbangan Kepuasan DoD (§4)

### Target Market
* **Solopreneur & Creator Teknis:** Tidak ingin direpotkan membuat kanban board atau task manual satu per satu. Cukup "curhat" masalah atau ide di Inbox, biarkan SM yang merapikan menjadi sprint backlog dan DoD.
* **Agency / Engineering Lead:** Butuh visibilitas instan atas antrean pekerjaan, kapasitas kuota agent (Antigravity accounts), dan pembagian peran tim tanpa overhead manajemen yang rumit.

### Mengapa Target Market Bakal Senang dengan DoD Ini?
* **Zero Cognitive Overload:** Hilang semua istilah rumit. Hanya ada 4 menu: *Inbox*, *Projects*, *Agents*, *Team*.
* **Natural Workflow:** Alur kerja menyerupai berkirim pesan ke Scrum Master profesional. Pengguna fokus pada *outcome*, SM fokus pada *DoD dan pelaksanaan teknis*.
* **Snappy Two-Tier UI (shadcn `sidebar-09`):** Navigasi super cepat ala Linear/Slack tanpa reload halaman penuh.

## 5. Detail Backlog Tasks (S17.1 – S17.5)

### S17.1 — shadcn `sidebar-09` Navigation Shell & Dual-Tier Layout
- **Scope:**
  - Membangun arsitektur navigasi dua tingkat (*two-tier rail and sub-panel*) sesuai spesifikasi `sidebar-09`.
  - **Left Rail (48px / 64px):** Ikon aktif untuk `Inbox`, `Projects`, `Agents`, `Team`, Quick Add, toggle theme Tokyo Night, dan profil avatar pengguna.
  - **Middle Sub-Panel (240px - 280px):** Menampilkan daftar item kontekstual berdasarkan tab aktif dengan tombol collapse/expand cepat.
  - Menghilangkan struktur sidebar monolit lama dan mempertahankan integrasi aman tanpa exception runtime.
- **DoD:**
  1. Navigasi dual-tier berfungsi mulus di layar desktop dan tablet (responsif).
  2. Klik pada rail mengganti konten sub-panel secara instan tanpa reload halaman.
  3. Komponen `NavUser` dan `ThemeToggle` terpasang rapi di bagian bawah rail.
  4. Audit pack `docs/sprints/evidence/S17/s17_1_sidebar09_shell_verified.txt` terbit, commit author Buchin & push `origin/main`.

### S17.2 — Conversational Inbox Engine & Thread Management (API & UI)
- **Scope:**
  - Menyediakan endpoint REST API terpadu untuk inbox:
    * `GET /api/v1/inbox` (Daftar seluruh thread dengan filter status: `all`, `unread`, `in_progress`, `done`).
    * `POST /api/v1/inbox` (Membuat thread baru dengan judul dan pesan pembuka).
    * `GET /api/v1/inbox/{id}` (Mengambil detail thread beserta histori percakapan dan status task).
    * `POST /api/v1/inbox/{id}/messages` (Mengirim pesan balasan ke dalam thread).
  - Tampilan Sub-Panel Inbox: Daftar thread dengan badge status warna-warni, cuplikan pesan terakhir, dan timestamp.
  - Tampilan Main Viewport: Header thread, riwayat balon pesan (pengguna vs Scrum Master vs worker agent), dan textarea composer modern.
- **DoD:**
  1. Pengguna dapat membuat thread baru, membaca daftar pesan, dan mengirim balasan secara interaktif.
  2. Pesan tersimpan persisten di database menggunakan relasi `project_rooms` dan `project_messages`.
  3. Desain chat hening, tipografi monospaced Tokyo Night, dan auto-scroll ke pesan terbaru.
  4. Audit pack `docs/sprints/evidence/S17/s17_2_inbox_engine_verified.txt` terbit, commit author Buchin & push `origin/main`.

### S17.3 — Scrum Master Triage & DoD Distiller (Agentic Scrum Bot)
- **Scope:**
  - Menghadirkan bot Manager / Scrum Master (SM) yang merespons pesan pengguna secara cerdas:
    * Menganalisis intent (apakah ide fitur baru, laporan bug, atau permintaan optimasi).
    * Merumuskan **Problem Statement**, **Rencana Eksekusi**, dan checklist **Definition of Done (DoD)** konkret.
    * Memilih worker agent terbaik berdasarkan kuota limit (Antigravity accounts).
  - Balasan SM di thread menampilkan kartu interaktif:
    * Checklist DoD yang dapat diedit atau langsung disetujui.
    * Tombol **"Setujui & Jalankan Sprint"** (1-Click Approval).
  - Saat disetujui, sistem secara otomatis:
    * Membuat atau memperbarui `project_tasks` terkait di database.
    * Menjalankan worker agent via runner API (`/api/v1/tasks/{id}/run`).
    * Memposting progress log eksekusi secara live ke dalam thread Inbox.
- **DoD:**
  1. SM merespons pesan pembuka dengan format Agentic Scrum (Outcome, Scope, DoD, Worker Agent terpilih).
  2. Tombol 1-click approval berhasil men-spawn task dan memicu runner agent.
  3. Progress eksekusi task tercermin di timeline thread pesan.
  4. Audit pack `docs/sprints/evidence/S17/s17_3_scrum_master_triage_verified.txt` terbit, commit author Buchin & push `origin/main`.

### S17.4 — Agents Pool & Team Directory Views
- **Scope:**
  - Membangun tampilan **Agents Hub**:
    * Daftar agent terdaftar (contoh: Antigravity Accounts / Models, status `idle`/`running`/`offline`).
    * Indikator kuota limit token (menunjukkan agent mana yang masih memiliki kuota terbanyak).
    * Modal ringkas untuk menambah/mengonfigurasi akun agent baru.
  - Membangun tampilan **Team Directory**:
    * Daftar anggota organisasi dan hierarki peran Agentic Scrum:
      - **Product Owner (PO):** Menentukan visi, prioritas, dan menyetujui sprint.
      - **Scrum Master (SM Agent):** Mengatur delegasi, triage pesan, dan verifikasi DoD.
      - **Development Team (Worker Agents):** Menulis kode, menjalankan test, dan deploy.
- **DoD:**
  1. Tab `Agents` menampilkan daftar worker agent dengan status live dan visualisasi kuota/limit.
  2. Tab `Team` menampilkan pembagian peran organisasi secara transparan dan rapi.
  3. UI konsisten dengan tema Tokyo Night dan arsitektur `sidebar-09`.
  4. Audit pack `docs/sprints/evidence/S17/s17_4_agents_team_verified.txt` terbit, commit author Buchin & push `origin/main`.

## 7. Out of Scope Eksplisit
* Mengubah skema database migrasi yang sudah stabil (tetap non-destruktif dan backward-compatible).
* Menghubungkan provider AI berbayar eksternal baru selain akun runner Antigravity yang sudah didukung.
* Menambahkan voice chat atau video call pada inbox (fokus murni pada teks & status eksekusi terstruktur).

## 8. Risiko & Mitigasi

| Risiko | Dampak | Mitigasi |
| :--- | :--- | :--- |
| **Kompleksitas Respons SM** | SM lambat merespons pesan pengguna | Menyediakan template triage cepat (*deterministic structured parser*) yang mengekstrak ringkasan dan DoD instan saat pesan diterima |
| **Koneksi Runner Asinkron** | Status eksekusi agent tidak terupdate di chat | Polling ringan (3-5 detik) atau WebSocket event saat thread aktif dibuka untuk memperbarui progress secara mulus |
| **Regresi Tampilan Lama** | Pengguna lama kehilangan akses ke Projects | Menu `Projects` tetap menjadi pilar utama di sidebar rail dengan fitur Dual View (Grid/List) yang sudah stabil |
