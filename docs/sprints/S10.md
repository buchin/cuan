## Sprint goal dan demo outcome

### Sprint Goal
Mewujudkan Cuan secara utuh sebagai **"Agentic Project Management for Creators"** dari etalase depan (Landing Page) hingga ke ruang eksekusi Studio:
1. **Landing Page Overhaul:** Penyelarasan total pesan, pain points (to-do list mati, overwhelmed, tools terpecah), dan solusi Cuan untuk target market creator (Blogger, YouTuber, Olshop, Affiliate).
2. **Creator Blueprint & Project Templates:** Template proyek instan siap pakai dengan pipeline alur kerja nyata (Blog Publisher, YouTube Channel, Online Shop, Affiliate Site).
3. **Pre-configured Agent Personas:** Agen AI khusus (SEO Specialist, YouTube Scriptwriter, Copywriter) yang terikat langsung pada pipeline creator.
4. **In-Task Agentic Execution:** Task Kanban tidak lagi menjadi to-do list mati, melainkan dapat langsung dieksekusi oleh AI Agent untuk menghasilkan draft konten, skrip, dan copywriting siap pakai di Task Detail drawer.
5. **Sinkronisasi Dokumen SSOT Repositori:** Memperbarui `docs/product-vision.md` dan `README.md` dengan positioning resmi *"Agentic Project Management for Creators"*.

### Demo Outcome
1. Pengunjung membuka `cuan.dojo.cc` dan disambut Landing Page hero section bertema *"Agentic Project Management for Creators"* yang langsung mengarahkan pengguna ke Studio.
2. Pengguna membuka Studio Dashboard dan memilih template dari Creator Project Wizard (misal: YouTube Channel atau Blog Publisher).
3. Cuan secara atomik membuat project baru lengkap dengan room diskusi, task pipeline terstruktur, dan agent persona yang sesuai.
4. Pada kartu task di Kanban board, pengguna menekan tombol *"Run with Agent"*.
5. In-Task Agentic Execution engine membaca prompt task dan DoD, mengeksekusi konten via Google Gemini Pro Key Vault, menyimpan hasil draft di kolom `agent_output`, memposting progress ke discussion room, dan otomatis mencentang checklist DoD.
6. Pengguna membuka Task Detail drawer dan melihat tab *"Agent Output"* dengan tampilan render Markdown dan tombol One-Click Copy to Clipboard.
7. Staging E2E drill dan rilis produksi di `cuan.dojo.cc` membuktikan seluruh alur berjalan mulus dengan 100% data retention Sprint 1–9 utuh.

## Target market dan pertimbangan kepuasan DoD (§4)

### Persona Target Market
1. **Blogger & Web Publisher:** Mengelola blog AdSense/niche. Membutuhkan riset kata kunci, perancangan topik pilar, dan drafting artikel otomatis oleh agent tanpa merancang prompt dari nol.
2. **YouTube & Video Creators:** Mengelola channel YouTube. Membutuhkan pipeline produksi video terstruktur (*Ideasi → Hook/Title → Full Scriptwriting → Description & Tagging*) dengan agent scriptwriter siap pakai.
3. **Online Shop & Digital Product Creators:** Mengembangkan dan menjual produk digital / e-commerce. Membutuhkan funnel peluncuran (*Sales Page Copywriting → 3-Part Email Nurture Sequence → FAQ & Objection Handling*).
4. **Affiliate Marketers:** Membutuhkan workflow komparasi produk, review fitur mendalam, dan drafting ulasan dengan konversi tinggi.

### Pertimbangan Kepuasan Target Market (DoD Focus)
- **Zero-Friction Instantiation:** Satu klik untuk membuat seluruh pipeline proyek kreator lengkap dengan task terstruktur dan agent persona.
- **Active In-Task Content Generation:** Menghilangkan "to-do list mati" — task langsung menghasilkan deliverable nyata berupa draft artikel/skrip/copy yang bisa langsung dipakai.
- **Seamless Markdown & Export:** Hasil kerja agent tersaji dalam format Markdown bersih dengan tombol salin instan satu klik.
- **Strict Data Retention (100% Data Integrity):** Seluruh skema database bersifat aditif non-destruktif; seluruh data dari Sprint 1 hingga Sprint 9 tetap 100% utuh.

## Evaluasi DoD

Scrum Master mengevaluasi bukti vs DoD setelah AgentSession melapor:
- **Lulus:** nyatakan selesai & JALANKAN task BERIKUTNYA (WAJIB).
- **Belum lulus (agent-fixable):** perbarui arahan & lanjutkan AgentSession.
- **Tidak agent-fixable:** catat blocker, dampak, bukti & opsi di dokumen sprint untuk Sprint Review.

## Out of scope eksplisit

- Direct publishing API ke YouTube/TikTok/WordPress (fokus pada perancangan, drafting konten & pipeline proyek di Cuan; integrasi API eksternal dapat dipertimbangkan di sprint berikutnya).
- Video rendering engine di server (agen menghasilkan outline, visual cues, dan skrip suara; rendering tetap dilakukan oleh software video editing kreator).

## Ketergantungan dan risiko

| Risiko | Dampak | Respons / Mitigasi |
| --- | --- | --- |
| Eksekusi LLM artikel panjang mengalami timeout | Task gagal atau output terpotong | Konfigurasi timeout adaptif (60s+), model terarah (`gemini-1.5-flash` untuk outline/research, `gemini-1.5-pro` untuk artikel), dan background execution |
| Kebocoran API key Gemini Pro saat eksekusi task | Pelanggaran keamanan kuota | Akses kredensial terenkripsi via KeyVault di sisi server; API response task detail tidak pernah memuat API key |
| Inkonsistensi format JSONB metadata antar blueprint | Kesalahan parsing data di frontend | Skema DTO standar dengan `json.RawMessage` dan fallback default `{}` |
